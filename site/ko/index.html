오른쪽 버튼을 누르고.
한 획 그리세요.

Mousetroke는 Windows와 Mac의 모든 창에 마우스 제스처를 더합니다. 오른쪽 버튼을 누른 채 끌면 ←는 뒤로, ↓→는 탭 닫기, ↙는 창 최소화. 그냥 오른쪽 클릭은 여느 때처럼 메뉴를 엽니다.

데모 영역에서 ←는 뒤로, →는 앞으로, →↓는 새 탭, ↓→는 탭 닫기, ←↑→는 새로 고침, ↙는 최소화, ↗는 최대화입니다. 아래 버튼으로 각 제스처를 재생할 수 있습니다.

이렇게 그리면, 이렇게 됩니다

탐색·편집·창 관리를 아우르는 약 50개의 제스처가 기본 제공됩니다. 무엇이든 바꾸거나 끄거나 지울 수 있고, 설정에서 한 번 그리면 새 제스처로 기록됩니다.

모서리로 밀기

버튼이 필요 없습니다. 커서를 모서리로 밀거나, 가장자리를 따라 둔 채 휠·가운데 클릭·위아래로 문지르세요. 모서리는 벗어났다 돌아와야 다시 발동하므로 실수로 반복되지 않습니다.

비켜야 할 땐 비켜 줍니다

원격 데스크톱과 3D·디자인 앱은 오른쪽·가운데 버튼 끌기를 직접 사용합니다. 처음 실행할 때 Mousetroke가 설치된 앱을 찾아 주니, 체크하면 그 안에서는 제스처가 꺼집니다.Mac에서는 Windows App, 화면 공유, Parallels Desktop, Blender 등 원격 데스크톱·가상 머신·3D 앱에서 제스처가 기본으로 꺼져 있습니다. 설정에서 바꿀 수 있습니다.

  • 오른쪽 클릭은 그대로그리지 않고 누르면 상황 메뉴가 평소처럼 열리고, 잠시 멈춰 있으면 보통의 오른쪽 끌기가 됩니다.
  • 전체 화면에서는 일시 정지전체 화면 게임·동영상·발표 중에는 제스처도 모서리도 발동하지 않습니다.

  • 앱 추가는 간단exe나 바로 가기를 설정 창에 끌어다 놓거나, “창 지정”을 누르고 그 앱의 창을 클릭하세요.설정에서 .app을 선택하거나, ‘창 선택’을 누른 뒤 해당 앱의 창을 클릭하세요.

있는 듯 없는 듯

제스처 엔진은 Rust로 작성되어 Windows와 직접 통신합니다. 브라우저 엔진도 런타임도 없습니다. 설정 창은 필요할 때만 여는 별도 프로세스입니다.네이티브 제스처 엔진은 Rust로 작성했습니다. Mac에서는 AppKit과 CGEventTap을 사용하며, 설정 창은 시스템 WebKit을 사용하므로 WebView2가 필요 없습니다.

자주 묻는 질문

Mousetroke를 써도 오른쪽 클릭 메뉴가 되나요?

네. 드래그하지 않은 오른쪽 클릭은 그대로 시스템에 전달되어 평소처럼 메뉴가 열립니다. 설정한 대기 시간(기본 0.5초, 변경 가능)을 넘겨 움직이지 않고 누르면 일반 오른쪽 드래그로 처리합니다.

게임이나 원격 데스크톱에서 오작동하지 않나요?

Windows: 전체 화면 게임·동영상·발표 중에는 제스처가 자동으로 일시 정지됩니다. 원격 데스크톱, AnyDesk, Blender, AutoCAD처럼 오른쪽·가운데 끌기를 직접 쓰는 프로그램은 처음 실행할 때 클릭 한 번으로 제외할 수 있습니다. Win+Esc로 언제든 정지할 수 있습니다.Mac: 전체 화면 게임·동영상·프레젠테이션 중에는 제스처가 자동으로 일시 정지됩니다. 설정에서 원격 데스크톱·가상 머신·3D 앱을 제외할 수 있습니다. 기본 일시 정지 단축키는 ⌃⌥⌘P이며 바꿀 수 있습니다.

어떤 운영 체제를 지원하나요?

Windows: Windows 10 1809 이상과 Windows 11, 64비트입니다. 제스처 엔진은 런타임 의존성이 없고, 설정 창은 Microsoft Edge WebView2를 사용합니다(Windows 11에 기본 포함, 대부분의 Windows 10 PC에는 Edge와 함께 있음).Mac: Apple silicon 및 Intel의 macOS 11 이상을 지원합니다. 네이티브 엔진은 AppKit과 CGEventTap, 설정 창은 시스템 WebKit을 사용합니다. 처음 열 때 손쉬운 사용과 입력 모니터링을 허용하세요.

Mousetroke는 무료인가요?

네. MIT 라이선스의 오픈 소스이며 광고나 계정이 없습니다. 하루에 한 번 GitHub에 새 버전이 있는지 확인합니다(환경 설정에서 끌 수 있음). 그 외에는 아무 정보도 보내지 않으며 텔레메트리도 없습니다.

메모리와 CPU를 얼마나 쓰나요?

Windows: 상주 엔진은 작업 집합 약 19 MB(전용 약 10 MB)를 쓰고 유휴 시 CPU는 쓰지 않습니다. 설정 창은 열려 있는 동안만 도는 별도 프로세스입니다.Mac: 상주 엔진의 물리 메모리 사용량은 활성 상태 보기에서 약 13 MB이며, 대기 중에는 CPU를 쓰지 않습니다. 설정은 메뉴 막대 메뉴에서 엽니다.

제스처를 직접 만들 수 있나요?

네. 설정에서 새 제스처를 만들고 편집기 패드에 한 번 그리면 됩니다. 마우스 버튼·휠·키·화면 가장자리를 조합하거나 앱마다 따로 제스처를 정할 수도 있습니다.

설정은 어디에 저장되고, 어떻게 백업하나요?

Windows: %APPDATA%\mousetroke\config.json에 있습니다. 설정 창에 가져오기·내보내기가 있습니다. 저장한 변경은 다시 시작하지 않아도 약 1초 안에 적용됩니다.Mac: 설정은 ~/Library/Application Support/mousetroke/config.json, 로그는 ~/Library/Logs/mousetroke/에 저장됩니다. 설정 창의 가져오기·내보내기로 백업할 수 있습니다.

어떻게 제거하나요?

Windows: 기본 설정에서 Windows 시작 시 실행을 끄고, 트레이 아이콘 메뉴에서 종료를 고른 뒤 mousetroke.exe와 %APPDATA%\mousetroke 폴더를 지우세요. 다른 흔적은 남지 않습니다.Mac: 메뉴 막대에서 종료하고 Mousetroke.app, ~/Library/Application Support/mousetroke 및 ~/Library/Logs/mousetroke를 삭제한 뒤 시스템 설정에서 Mousetroke 로그인 항목을 제거하세요.

Mousetroke 다운로드

설치 프로그램이 없습니다. 알림 영역에 아이콘이 나타나며, 왼쪽 클릭은 설정, 오른쪽 클릭은 일시 정지나 종료입니다. 처음 실행할 때 4단계 안내가 함께합니다.메뉴 막대 메뉴에서 설정을 열거나 일시 정지·종료할 수 있습니다. 로그인 시 실행은 시스템 설정에서 관리합니다.

Mac에서 처음 열기

Mousetroke를 응용 프로그램으로 드래그하고 거기서 여세요. 이 베타는 공증되지 않았습니다. macOS가 차단하면 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기를 선택하세요 (이전 macOS는 오른쪽 클릭 → 열기). 그런 다음 손쉬운 사용과 입력 모니터링을 허용하세요.
