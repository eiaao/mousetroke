Mousetroke は Windows のすべてのウィンドウにマウスジェスチャを加えます。右ボタンを押したまま動かす：← で戻る、↓→ でタブを閉じる、↙ で最小化。ただの右クリックなら、これまでどおりメニューが出ます。

Windows 版をダウンロード 12.9 MB Mac 版をダウンロード（ベータ） @@MAC_DMG_SIZE@@ ジェスチャを見る
  • 無料・オープンソース（MIT）
  • Windows 10 / 11
  • メモリ約 19 MB

デモエリアでは ← で戻る、→ で進む、→↓ で新しいタブ、↓→ でタブを閉じる、←↑→ で更新、↙ で最小化、↗ で最大化。下のボタンで各ジェスチャを再生できます。

右ボタンを押したままここで描く（指でも可）
‹›↻
スクロール、または右ボタンを押したまま下へ描く

閲覧・編集・ウィンドウ操作をカバーする約 50 種類のジェスチャを内蔵。どれでも変更・オフ・削除でき、設定で一度描けば新しいジェスチャを登録できます。

描いている間、画面の下の方にジェスチャ名が表示されます。認識しないものは何も起こりません。同じジェスチャでも、エクスプローラー・ターミナル・デスクトップで違う動作にできます。

隅へ押し付ける

ボタンは不要：カーソルを隅に押し付ける、または端に沿わせてホイール・中クリック・上下にこする。隅は離れるまで再発動しないので、うっかり連発しません。

ショートカット以上

各ジェスチャは 8 種類の動作のいずれかを実行します。動作には変数が使えます：%MS_SELECTED_TEXT% は選択テキスト、%MS_PID% はカーソル下のプロセス。

キーを送る
Ctrl+Shift+T など、任意のショートカットやキー列。
ウィンドウ操作
カーソル下またはアクティブなウィンドウの最小化・最大化・常に手前・閉じる・強制終了。
アプリを開く
notepad.exe のように、引数付きで任意のプログラムやファイルを起動。
URL を開く
既定のブラウザで。選択テキストを付けられます：https://www.bing.com/search?q=%MS_SELECTED_TEXT%
コマンド実行
taskkill /F /PID %MS_PID% など、任意のコマンドライン。
メディアとシステム
音量、ミュート、再生 / 一時停止、前後トラック、画面の輝度。
メニュー表示
一つのジェスチャでカーソル横に動作メニューを出し、クリックで実行。
Lua スクリプト
条件分岐や連続した手順が必要なときは、数行の Lua で。

必要なときだけ引っ込む

リモートデスクトップや 3D・デザイン系アプリは、右・中ボタンのドラッグを自分で使います。初回起動時にインストール済みのものを検出するので、チェックすればその中ではジェスチャがオフになります。

BBlenderblender.exeジェスチャ無効
AAutoCADacad.exeジェスチャ無効
CGoogle Chromechrome.exeジェスチャ有効
  • 右クリックはそのまま描かずに押せば普段どおりメニューが出ます。少し止まれば通常の右ドラッグになります。
  • 全画面では一時停止全画面のゲーム・動画・プレゼンではジェスチャも隅も発動しません。
  • いつでも一時停止Win + Esc で停止 / 再開。トレイアイコンが灰色になります。
  • アプリの追加は簡単exe やショートカットを設定ウィンドウにドロップ、または「ウィンドウを指定」してその窓をクリック。

ほとんど存在しない

ジェスチャエンジンは Rust で書かれ、Windows と直接やり取りします。ブラウザエンジンもランタイムも不要。設定画面は必要なときだけ開く別プロセスです。

よくある質問

右クリックのメニューは今までどおり使えますか？

はい。ドラッグしない右クリックはそのまま Windows に返されるので、コンテキストメニューは普通に出ます。しばらく動かずに押し続けても（初期値 0.5 秒、調整可）、通常の右ドラッグになります。

ゲームやリモートデスクトップで誤発動しませんか？

全画面のゲーム・動画・プレゼンではジェスチャが自動で一時停止します。リモートデスクトップ、AnyDesk、Blender、AutoCAD など右・中ドラッグを自分で使うプログラムは、初回起動にワンクリックで除外できます。Win+Esc でいつでも停止できます。

対応する Windows のバージョンは？

Windows 10 1809 以降と Windows 11 の 64 ビットです。ジェスチャエンジンにランタイム依存はありません。設定画面は Microsoft Edge WebView2 を使います（Windows 11 に標準搭載、ほとんどの Windows 10 には Edge と共にあります）。

Mousetroke は無料ですか？

はい。MIT ライセンスのオープンソースで、広告やアカウントはありません。1 日 1 回 GitHub に新しいバージョンがあるか確認します（環境設定でオフにできます）。それ以外の情報は送信せず、テレメトリもありません。

メモリと CPU の使用量は？

常駐エンジンはワーキングセット約 19 MB（プライベート約 10 MB）、アイドル時の CPU はゼロです。設定画面は開いている間だけ動く別プロセスです。

自分でジェスチャを作れますか？

はい。設定で新規ジェスチャを作り、エディタのパッドに一度描くだけ。マウスボタン・ホイール・キー・画面の端を組み合わせたり、アプリごとに別々のジェスチャを設定したりもできます。

設定はどこに保存されますか？バックアップは？

%APPDATA%\mousetroke\config.json です。設定画面にインポート・エクスポートがあります。保存した変更は再起動なしに約 1 秒で反映されます。

アンインストールの方法は？

設定で Windows 起動時の実行をオフにし、トレイアイコンのメニューから終了を選び、mousetroke.exe と %APPDATA%\mousetroke フォルダーを削除するだけです。他には何も残りません。

Mac 版をアンインストールするには？

メニューバーから終了し、Mousetroke.app、~/Library/Application Support/mousetroke、~/Library/Logs/mousetroke を削除して、システム設定で Mousetroke のログイン項目を取り除きます。

ダウンロードして、ダブルクリック、以上

インストーラー不要。通知領域にアイコンが現れます：左クリックで設定、右クリックで一時停止や終了。初回は 4 ステップのガイドが付いてきます。

Mac で初めて開く

Mousetroke をアプリケーションにドラッグし、そこから開きます。このベータ版は未公証です。macOS にブロックされた場合は、システム設定 → プライバシーとセキュリティ → このまま開く（古い macOS では右クリック → 開く）を選び、アクセシビリティと入力監視を許可してください。
