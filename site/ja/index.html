右ボタンを押して。
一筆描く。

Mousetroke は Windows と Mac のあらゆるウィンドウで使えるマウスジェスチャーツールです。右ボタンを押したまま動かす：← で戻る、↓→ でタブを閉じる、↙ で最小化。ただの右クリックなら、これまでどおりメニューが出ます。

ボタンは不要：カーソルを隅に押し付ける、または端に沿わせてホイール・中クリック・上下にこする。隅は離れるまで再発動しないので、うっかり連発しません。

ショートカット以上

各ジェスチャは 8 種類の動作のいずれかを実行します。動作には変数が使えます：%MS_SELECTED_TEXT% は選択テキスト、%MS_PID% はカーソル下のプロセス。

キーを送る
Ctrl+Shift+T⌘⇧T など、任意のショートカットやキー列。
ウィンドウ操作
カーソル下またはアクティブなウィンドウの最小化・最大化・常に手前・閉じる・強制終了。
アプリを開く
アプリやファイルを開けます。必要に応じて起動引数も指定できます。
URL を開く
既定のブラウザで。選択テキストを付けられます：https://www.bing.com/search?q=%MS_SELECTED_TEXT%
コマンド実行
コマンドを実行します。必要に応じて変数も使えます。
メディアとシステム
音量、ミュート、再生 / 一時停止、前後トラック、画面の輝度。
メニュー表示
一つのジェスチャでカーソル横に動作メニューを出し、クリックで実行。
Lua スクリプト
条件分岐や連続した手順が必要なときは、数行の Lua で。

必要なときだけ引っ込む

リモートデスクトップや 3D・デザイン系アプリは、右・中ボタンのドラッグを自分で使います。初回起動時にインストール済みのものを検出するので、チェックすればその中ではジェスチャがオフになります。Mac では、Windows App、画面共有、Parallels Desktop、Blender などのリモートデスクトップ・仮想マシン・3D アプリで、初期設定からジェスチャーを無効にしています。設定で変更できます。

  • 右クリックはそのまま描かずに押せば普段どおりメニューが出ます。少し止まれば通常の右ドラッグになります。
  • 全画面では一時停止全画面のゲーム・動画・プレゼンではジェスチャも隅も発動しません。
  • いつでも一時停止Win + Esc で停止 / 再開。トレイアイコンが灰色になります。⌃ + ⌥ + ⌘ + P で一時停止・再開できます。ショートカットは設定で変更でき、メニューバーのメニューからも一時停止できます。
  • アプリの追加は簡単exe やショートカットを設定ウィンドウにドロップ、または「ウィンドウを指定」してその窓をクリック。設定で .app を選ぶか、「ウィンドウを選択」を押して対象アプリのウィンドウをクリックします。

ほとんど存在しない

ジェスチャエンジンは Rust で書かれ、Windows と直接やり取りします。ブラウザエンジンもランタイムも不要。設定画面は必要なときだけ開く別プロセスです。ネイティブのジェスチャーエンジンは Rust 製です。Mac では AppKit と CGEventTap を直接使用し、設定画面にはシステムの WebKit を使います。WebView2 は不要です。

よくある質問

右クリックのメニューは今までどおり使えますか？

使えます。ドラッグせずに右クリックすると、そのクリックがそのままシステムに渡り、通常どおりメニューが開きます。設定した待機時間（初期値 0.5 秒、変更可能）を超えて動かさずに押し続けると、通常の右ドラッグになります。

ゲームやリモートデスクトップで誤発動しませんか？

Windows: 全画面のゲーム・動画・プレゼンではジェスチャが自動で一時停止します。リモートデスクトップ、AnyDesk、Blender、AutoCAD など右・中ドラッグを自分で使うプログラムは、初回起動にワンクリックで除外できます。Win+Esc でいつでも停止できます。Mac: 全画面のゲーム・動画・プレゼン中は自動で一時停止します。リモートデスクトップ・仮想マシン・3D アプリは設定で除外できます。一時停止の初期ショートカットは ⌃⌥⌘P で、変更も可能です。

対応する OS は？

Windows: Windows 10 1809 以降と Windows 11 の 64 ビットです。ジェスチャエンジンにランタイム依存はありません。設定画面は Microsoft Edge WebView2 を使います（Windows 11 に標準搭載、ほとんどの Windows 10 には Edge と共にあります）。Mac: macOS 11 以降の Apple silicon・Intel Mac に対応します。ネイティブエンジンは AppKit と CGEventTap、設定画面はシステムの WebKit を使用します。初回起動時にアクセシビリティを許可してください。古い macOS でガイドに求められた場合のみ、入力監視も有効にしてください。

Mousetroke は無料ですか？

はい。MIT ライセンスのオープンソースで、広告やアカウントはありません。1 日 1 回 GitHub に新しいバージョンがあるか確認します（環境設定でオフにできます）。それ以外の情報は送信せず、テレメトリもありません。

メモリと CPU の使用量は？

Windows: 常駐エンジンはワーキングセット約 19 MB（プライベート約 10 MB）、アイドル時の CPU はゼロです。設定画面は開いている間だけ動く別プロセスです。Mac: 常駐エンジンの物理メモリ使用量はアクティビティモニタで約 13 MB。待機中は CPU を使いません。設定はメニューバーのメニューから開けます。

自分でジェスチャを作れますか？

はい。設定で新規ジェスチャを作り、エディタのパッドに一度描くだけ。マウスボタン・ホイール・キー・画面の端を組み合わせたり、アプリごとに別々のジェスチャを設定したりもできます。

設定はどこに保存されますか？バックアップは？

Windows: %APPDATA%\mousetroke\config.json です。設定画面にインポート・エクスポートがあります。保存した変更は再起動なしに約 1 秒で反映されます。Mac: 設定は ~/Library/Application Support/mousetroke/config.json、ログは ~/Library/Logs/mousetroke/ に保存されます。設定画面のインポート・エクスポートでバックアップできます。

アンインストールの方法は？

Windows: 設定で Windows 起動時の実行をオフにし、トレイアイコンのメニューから終了を選び、mousetroke.exe と %APPDATA%\mousetroke フォルダーを削除するだけです。他には何も残りません。Mac: メニューバーから終了し、Mousetroke.app、~/Library/Application Support/mousetroke、~/Library/Logs/mousetroke を削除して、システム設定で Mousetroke のログイン項目を取り除きます。

Mousetroke をダウンロード

インストーラー不要。通知領域にアイコンが現れます：左クリックで設定、右クリックで一時停止や終了。初回は 4 ステップのガイドが付いてきます。設定・一時停止・終了はメニューバーのメニューから。ログイン時の起動はシステム設定のログイン項目で管理します。

Mac で初めて開く

Mousetroke をアプリケーションにドラッグして開きます。未公証のベータ版のためブロックされた場合：システム設定 → プライバシーとセキュリティ → このまま開く。設定ガイドに沿ってアクセシビリティを許可し、「準備完了」が表示されたら使えます。入力監視はガイドで求められた場合のみ有効にしてください。 以降は「情報」の「今すぐ更新」で「このまま開く」を繰り返さずに更新できます。手動ダウンロードも利用できます。
