Rechte Taste halten.

Mousetroke bringt Mausgesten in jedes Fenster von Windows. Rechte Taste halten und ziehen: ← geht zurück, ↓→ schließt den Tab, ↙ minimiert das Fenster. Ein einfacher Rechtsklick öffnet weiterhin das Menü.

In der Demofläche ← für Zurück zeichnen, → für Vorwärts, →↓ für einen neuen Tab, ↓→ um den Tab zu schließen, ←↑→ zum Aktualisieren, ↙ zum Minimieren, ↗ zum Maximieren. Die Schaltflächen unten spielen jede Geste ab.

Das zeichnen, das bekommen

Etwa fünfzig Gesten sind eingebaut und decken Surfen, Bearbeiten und Fensterverwaltung ab. Ändern, ausschalten oder löschen Sie jede davon, oder zeichnen Sie in den Einstellungen einmal eine neue, um sie aufzuzeichnen.

Während Sie zeichnen, erscheint der Gestenname unten am Bildschirm; was nicht erkannt wird, bewirkt nichts. Dieselbe Geste kann im Datei-Explorer, im Terminal und auf dem Desktop Unterschiedliches tun.

In eine Ecke stoßen

Ohne Taste: den Cursor in eine Ecke stoßen, oder entlang einer Kante und dann scrollen, mittlklicken oder auf und ab reiben. Eine Ecke löst erst erneut aus, nachdem man sie verlassen hat — kein versehentliches Wiederholen.

Mehr als Kurzschlüssel

Jede Geste führt eine von acht Aktionsarten aus. Aktionen können Variablen nutzen: %MS_SELECTED_TEXT% ist der markierte Text und %MS_PID% der Prozess unter dem Cursor.

Tasten senden
Beliebiger Kurzschlüssel oder Tastenfolge, etwa Strg+Umschalt+T.
Fensteraktionen
Minimieren, maximieren, nach vorne halten, das Fenster unter dem Cursor oder das aktive schließen oder beenden.
App öffnen
Beliebiges Programm oder Datei mit Argumenten starten, etwa notepad.exe.
URL öffnen
Im Standardbrowser, wahlweise mit dem markierten Text: https://www.bing.com/search?q=%MS_SELECTED_TEXT%
Befehl ausführen
Beliebige Befehlszeile, etwa taskkill /F /PID %MS_PID%.
Medien und System
Lautstärke, stumm, Wiedergabe / Pause, vorheriger / nächster Titel, Bildschirmhelligkeit.
Menü anzeigen
Eine Geste öffnet ein Aktionsmenü neben dem Cursor; eines anklicken, um es auszuführen.
Lua-Skript
Ein paar Zeilen Lua, wenn Bedingungen oder mehrere Schritte nacheinander nötig sind.

Hält sich zurück, wenn es soll

Fernwartung sowie 3D- und Design-Apps brauchen Rechts- und Mittelziehen für sich. Beim ersten Start findet Mousetroke die installierten; kreuzen Sie sie an, um die Gesten darin zu deaktivieren.

Kaum vorhanden

Die Gesten-Engine ist in Rust geschrieben und spricht Windows direkt an — ohne Browser-Engine, ohne Runtime. Das Einstellungsfenster ist ein eigener Prozess, der nur bei Bedarf offen ist.

Fragen

Funktioniert das Rechtsklick-Menü mit Mousetroke weiterhin?

Ja. Ein Rechtsklick ohne Ziehen wird unverändert an Windows zurückgegeben, das Kontextmenü öffnet sich wie immer. Stillhalten über die Zieh-Wartezeit (standardmäßig 0,5 Sekunden, einstellbar) wird ebenfalls ein normales Rechtsziehen.

Fehlauslösungen in Spielen oder bei Fernwartung?

Vollbildspiele, Video und Präsentationen pausieren die Gesten automatisch. Programme, die Rechts- oder Mittelziehen selbst brauchen — etwa Remotedesktop, AnyDesk, Blender oder AutoCAD — lassen sich beim ersten Start mit einem Klick ausschließen. Win+Esc pausiert jederzeit.

Welche Windows-Versionen werden unterstützt?

Windows 10 ab 1809 und Windows 11, 64-Bit. Die Gesten-Engine hat keine Laufzeitabhängigkeiten; das Einstellungsfenster nutzt Microsoft Edge WebView2, das Windows 11 beiliegt und auf den meisten Windows-10-PCs mit Edge kommt.

Ist Mousetroke kostenlos?

Ja. Es ist Open Source unter der MIT-Lizenz, ohne Werbung oder Konto. Einmal täglich wird GitHub nach einer neuen Version gefragt (in den Einstellungen abschaltbar). Sonst wird nichts gesendet; es gibt keine Telemetrie.

Wie viel Speicher und CPU?

Die residente Engine braucht etwa 19 MB Working Set (rund 10 MB privat) und im Leerlauf keine CPU. Das Einstellungsfenster ist ein eigener Prozess, der nur läuft, während er offen ist.

Kann ich eigene Gesten erstellen?

Ja. Legen Sie in den Einstellungen eine Geste an und zeichnen Sie sie einmal auf dem Feld des Editors. Sie können auch Maustasten, Rad, Tasten und Bildschirmkanten kombinieren und Gesten pro App getrennt festlegen.

Wo liegen die Einstellungen, und wie sichere ich sie?

In %APPDATA%\mousetroke\config.json. Die Einstellungen haben Import und Export. Gespeicherte Änderungen greifen in etwa einer Sekunde, ohne Neustart.

Wie deinstalliere ich es?

Windows-Start in den Einstellungen ausschalten, im Menü des Tray-Symbols Beenden wählen, dann mousetroke.exe und den Ordner %APPDATA%\mousetroke löschen. Es bleibt nichts weiter zurück.

Wie deinstalliere ich die Mac-Version?

Beende Mousetroke über die Menüleiste, lösche Mousetroke.app, ~/Library/Application Support/mousetroke und ~/Library/Logs/mousetroke und entferne den Mousetroke-Anmeldeeintrag in den Systemeinstellungen.

Herunterladen, doppelklicken, fertig

Kein Installationsprogramm. Im Infobereich erscheint ein Symbol: Linksklick öffnet die Einstellungen, Rechtsklick pausiert oder beendet. Eine Anleitung in vier Schritten begleitet den ersten Start.

Erster Start auf dem Mac

Ziehe Mousetroke in Programme und öffne es dort. Diese Beta ist nicht notarisiert: Wenn macOS sie blockiert, wähle Systemeinstellungen → Datenschutz & Sicherheit → Dennoch öffnen (unter älterem macOS: Rechtsklick → Öffnen). Erlaube dann Bedienungshilfen und Eingabeüberwachung.
