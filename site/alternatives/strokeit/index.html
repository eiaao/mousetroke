按你的需求选择

适合选择 Mousetroke 的情况

你需要明确支持 Windows 11 的 MIT 开源工具，以及屏幕边角和按程序设置。

适合选择 StrokeIt 的情况

你已有稳定工作的 StrokeIt 配置，或依赖它的插件与 Professional 版 Lua 工作流。

实际使用中的差别

StrokeIt 官网仍列出 0.9.7，并提到修复 Win95 至 Win7 的问题。这不足以证明它不能运行于 Windows 11，也不能用来承诺新系统兼容性。先在自己的应用中验证原配置，再决定是否迁移。

StrokeIt 的 Professional 版提供 Lua 脚本；许多插件以 MIT 开源不代表整个产品采用 MIT。Mousetroke 则以 MIT 发布完整项目，支持方向与形状手势、按程序规则及全屏自动暂停。两者脚本和配置不能据此视为直接兼容。

常见问题

Windows 11 上有什么好的 StrokeIt 替代工具？

如果你主要用鼠标，需要全局手势、屏幕边角和可查看的 MIT 源码，可以考虑 Mousetroke。若需求是深度宏编辑、原生多指触控或只在浏览器内操作，请结合本页的选择建议评估。

Mousetroke 免费且开源吗？

是，采用 MIT 许可证，没有广告或账号，无遥测。默认每天向 GitHub 检查一次更新，可在偏好设置中关闭。

Windows 下载会出现 SmartScreen 提示吗？

可能会。exe 尚未代码签名，首次运行 SmartScreen 可能警告；README 的操作是“更多信息 → 仍要运行”。请从官方发布页下载并核对 SHA-256。
