按你的需求选择

适合选择 Mousetroke 的情况

你主要用鼠标，需要 MIT 开源、屏幕边角，并希望在 Windows 与 Mac 测试版使用相似操作。

适合选择 GestureSign / GestureSignv2 的情况

你优先使用触屏，或需要社区 GestureSignv2 明确提供的触控板、多指 TipTap 和触控边缘交互。

实际使用中的差别

GestureSign 的官方说明以 Windows 平板为对象，支持用手指或鼠标画手势。其发布页最新列出 v8.1（2022-02-03）；单凭这个日期不能推断所有维护活动已经结束。

GestureSignv2 是基于原项目、面向 Windows 11 的社区重构，明确列出触控板、触屏、鼠标与 TipTap。两个项目都列出 GPL-2.0。Mousetroke 的文档以鼠标按键手势为主，原生多指触控能力未验证，不能用网页演示的触屏交互代替产品支持说明。

常见问题

Windows 11 上有什么好的 GestureSign 替代工具？

如果你主要用鼠标，需要全局手势、屏幕边角和可查看的 MIT 源码，可以考虑 Mousetroke。若需求是深度宏编辑、原生多指触控或只在浏览器内操作，请结合本页的选择建议评估。

Mousetroke 免费且开源吗？

是，采用 MIT 许可证，没有广告或账号，无遥测。默认每天向 GitHub 检查一次更新，可在偏好设置中关闭。

Mousetroke 能替代原生多指触控手势吗？

目前不能这样承诺。已核实的主要输入方式是按住鼠标键画手势。触控板或触屏优先时，请先评估明确列出这些输入方式的工具，并在自己的硬件上测试。
