实际使用中的差别

StrokesPlus.net 的旧站保留论坛和最终下载归档。原作者的后继应用 Input.Observer 提供 C 风格脚本、无代码步骤、宏录制，还能调用 AutoHotkey v2。经常编排多步操作的话，这些工具值得优先试用。

StrokesPlus.net 的 JavaScript 不能直接在后继应用中运行。导入器会转换能处理的内容，其余部分需要手动调整。选择 Mousetroke 时，可以从最常用的几个手势开始，用内置动作或 Lua 重新配置；需要宏录制和文本扩展时，优先考虑 Input.Observer。

常见问题

Windows 11 上有什么好的 StrokesPlus.net 替代工具？

如果你主要用鼠标，需要全局手势、屏幕边角和可查看的 MIT 源码，可以考虑 Mousetroke。若需求是深度宏编辑、原生多指触控或只在浏览器内操作，请结合本页的选择建议评估。

Mousetroke 免费且开源吗？

是，采用 MIT 许可证，没有广告或账号，无遥测。默认每天向 GitHub 检查一次更新，可在偏好设置中关闭。

从旧脚本迁移到 Mousetroke，怎么开始？

先挑几个最常用的操作，用内置动作或 Lua 重新配置，再逐个测试。若你每天都需要宏录制和带补全的脚本编辑器，可以先试用 Input.Observer。
