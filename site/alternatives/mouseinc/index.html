按你的需求选择

适合选择 Mousetroke 的情况

你需要可审阅的 MIT 源码、免安装 Windows exe、Mac 测试版，以及手势和边角的直接设置。

适合选择 MouseInc / Aitiy 的情况

原有 MouseInc 配置在你的电脑上稳定工作；或你愿意评估 Aitiy 的截图、OCR、Lua 动作和桌面工具。

实际使用中的差别

MouseInc 旧产品地址本次指向其设置界面仓库，该仓库标记为归档。设置界面的归档不足以确认核心程序的最终版本、许可证或停止维护的时间，因此表格没有把这些信息写成事实。

MouseInc 用户也可了解 Aitiy：官网确认 Windows 与 macOS、个人用途免费、Lua、截图和 OCR。关于两者是否存在正式后继关系，本次官方资料未验证；也不承诺配置兼容。Mousetroke 以 MIT 开源，适合主要想配置鼠标手势、边角和按程序规则的人。

常见问题

Windows 11 上有什么好的 MouseInc 替代工具？

如果你主要用鼠标，需要全局手势、屏幕边角和可查看的 MIT 源码，可以考虑 Mousetroke。若需求是深度宏编辑、原生多指触控或只在浏览器内操作，请结合本页的选择建议评估。

Mousetroke 免费且开源吗？

是，采用 MIT 许可证，没有广告或账号，无遥测。默认每天向 GitHub 检查一次更新，可在偏好设置中关闭。

Mac 测试版首次打开需要什么？

DMG 中的应用需拖入“应用程序”。测试版自签名且未公证；被拦截时，按 README 到“系统设置 → 隐私与安全性 → 仍要打开”，再跟随引导授予辅助功能权限。仅在引导要求时开启输入监控。

后退、关标签页、管理窗口，或从屏幕边角执行动作。Windows 常驻约 19 MB，Mac 约 13 MB。
