按你的需求选择

适合选择 Mousetroke 的情况

你需要完整 MIT 源码、Windows 与 Mac 测试版，以及方向手势、形状手势和屏幕边角。

适合选择 FastGestures 的情况

你在 Windows 上优先使用触控板或触屏，尤其需要官方列出的三指拖动与边缘滚动。

实际使用中的差别

FastGestures 支持 Windows 7/8/10/11，提供触控板三指拖动、触屏手势和边缘滚动。习惯用触控板拖窗口，或在屏幕边缘调音量、亮度的话，这些功能很贴近日常操作。下载时留意版本：主页标注 2.2.73，官方发布页已有 2.2.75。

Mousetroke 适合主要用鼠标、想自己设置手势和查看 MIT 源码的用户，Windows 版下载后即可运行，也有 Mac 测试版。换用时，先为常用手势绑定按键或窗口动作，再添加屏幕边角和按程序规则。若你最依赖的是三指拖动，可优先试用 FastGestures。

常见问题

Windows 11 上有什么好的 FastGestures 替代工具？

如果你主要用鼠标，需要全局手势、屏幕边角和可查看的 MIT 源码，可以考虑 Mousetroke。若需求是深度宏编辑、原生多指触控或只在浏览器内操作，请结合本页的选择建议评估。

Mousetroke 免费且开源吗？

是，采用 MIT 许可证，没有广告或账号，无遥测。默认每天向 GitHub 检查一次更新，可在偏好设置中关闭。

需要触控板三指拖动，选哪款更合适？

FastGestures 列有触控板三指拖动，建议先在自己的硬件上试用。Mousetroke 主要用鼠标按键画手势，也提供屏幕边角动作。
