Choose for your needs

Choose Mousetroke if…

You want the same mouse habits across a browser, file manager and other apps, plus screen corner actions.

Choose Gesturefy / CrxMouse if…

You only need web-page and tab actions, and prefer a Firefox or Chrome add-on without a separate desktop gesture app.

Differences in daily use

Gesturefy is a Firefox mouse gesture add-on with commands including user scripts. It explicitly says it is not suited to touchpads and cannot operate on restricted pages such as about:addons. Check those boundaries before choosing a browser-only workflow.

CrxMouse confirms desktop Chrome, tab controls and custom gestures on its official site. This page does not assume compatibility with every Chromium browser. Mousetroke handles mouse strokes at the system level with per-app rules; first use also involves desktop-app signing prompts and permission setup.

Frequently asked questions

What is a good Gesturefy alternative for Windows 11?

Consider Mousetroke if you mainly use a mouse and want system-wide gestures, screen corners and inspectable MIT source. For deep macro editing, native multi-finger input or browser-only use, follow the choices on this page.

Is Mousetroke free and open source?

Yes. It uses the MIT license, with no ads, account or telemetry. It checks GitHub for updates once a day by default; turn that off in Preferences if you prefer.

Do I need a system-wide app just for browser gestures?

Not necessarily. A browser extension may be the better fit if you only act on web pages. Consider Mousetroke for a file manager, other desktop apps or screen corners, and exclude apps where gestures conflict.
