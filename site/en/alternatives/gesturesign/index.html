Choose for your needs

Choose Mousetroke if…

You mainly use a mouse and want MIT source, screen corners and similar workflows on Windows and Mac beta.

Choose GestureSign / GestureSignv2 if…

Touchscreen input comes first, or you need the community GestureSignv2 project's touchpad, TipTap and touch edge interactions.

Differences in daily use

GestureSign is built for Windows tablets, with gestures drawn by finger or mouse. The community rebuild, GestureSignv2, targets Windows 11 and supports touchpads, touchscreens, mice and TipTap. Those inputs are useful if you often work away from a mouse.

GestureSignv2 offers an MSI and a portable ZIP, with matching .NET 10 and Windows App Runtime installations required. Mousetroke provides a portable Windows exe and a Mac beta, centered on strokes drawn while holding a mouse button. Set up your usual shortcuts and window actions first, then add per-app rules and screen corners. For multi-finger workflows, try the community rebuild first.

Frequently asked questions

What is a good GestureSign alternative for Windows 11?

Consider Mousetroke if you mainly use a mouse and want system-wide gestures, screen corners and inspectable MIT source. For deep macro editing, native multi-finger input or browser-only use, follow the choices on this page.

Is Mousetroke free and open source?

Yes. It uses the MIT license, with no ads, account or telemetry. It checks GitHub for updates once a day by default; turn that off in Preferences if you prefer.

Which tool should I try for a touchpad or touchscreen?

Start with GestureSignv2 for touchpad, touchscreen and TipTap input, or FastGestures for touch input and three-finger dragging. For mouse use, Mousetroke offers mouse-button strokes and screen corners.
