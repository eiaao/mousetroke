Choose for your needs

Choose Mousetroke if…

You mainly use a mouse and want MIT source, screen corners and similar workflows on Windows and Mac beta.

Choose GestureSign / GestureSignv2 if…

Touchscreen input comes first, or you need the community GestureSignv2 project's touchpad, TipTap and touch edge interactions.

Differences in daily use

GestureSign describes itself as software for Windows tablets, with gestures drawn using fingers or a mouse. Its latest listed release is v8.1, dated 2022-02-03; that date alone does not establish that all maintenance has ended.

GestureSignv2 is a community rebuild based on the original project and focused on Windows 11. It explicitly lists touchpad, touchscreen, mouse and TipTap support. Both projects list GPL-2.0. Mousetroke's documentation centers on mouse-button strokes; native multi-finger input is unverified, and the website's touch demo is not evidence of product support.

Frequently asked questions

What is a good GestureSign alternative for Windows 11?

Consider Mousetroke if you mainly use a mouse and want system-wide gestures, screen corners and inspectable MIT source. For deep macro editing, native multi-finger input or browser-only use, follow the choices on this page.

Is Mousetroke free and open source?

Yes. It uses the MIT license, with no ads, account or telemetry. It checks GitHub for updates once a day by default; turn that off in Preferences if you prefer.

Can Mousetroke replace native multi-finger touch gestures?

That is not established. The verified primary input is drawing while holding a mouse button. For touchpad or touchscreen use, first evaluate a tool that explicitly documents those inputs and test it on your hardware.
