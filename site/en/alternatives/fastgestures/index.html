Choose for your needs

Choose Mousetroke if…

You want MIT-licensed source, Windows and Mac beta, directional and shape gestures, and screen corners.

Choose FastGestures if…

You prioritize Windows touchpad or touchscreen input, especially the documented three-finger dragging and edge scrolling.

Differences in daily use

FastGestures supports Windows 7/8/10/11 with three-finger touchpad dragging, touchscreen gestures and edge scrolling. Those features suit dragging windows from a touchpad or adjusting volume and brightness at the screen edge. Check the version when downloading: the home page labels 2.2.73, while the official releases list 2.2.75.

Mousetroke suits mouse users who want to configure strokes and inspect MIT-licensed source. Its Windows exe runs without installation, and a Mac beta is also available. Start by binding your usual strokes to shortcuts or window actions, then add screen corners and per-app rules. If three-finger dragging is your priority, try FastGestures first.

Frequently asked questions

What is a good FastGestures alternative for Windows 11?

Consider Mousetroke if you mainly use a mouse and want system-wide gestures, screen corners and inspectable MIT source. For deep macro editing, native multi-finger input or browser-only use, follow the choices on this page.

Is Mousetroke free and open source?

Yes. It uses the MIT license, with no ads, account or telemetry. It checks GitHub for updates once a day by default; turn that off in Preferences if you prefer.

Which tool should I try for three-finger touchpad dragging?

FastGestures lists three-finger touchpad dragging, so try it on your hardware first. Mousetroke centers on mouse-button strokes and screen corner and edge actions.
