Choose for your needs

Choose Mousetroke if…

You value open source, Windows plus Mac beta, and direct setup for mouse gestures and screen corners.

Choose StrokesPlus.net / Input.Observer if…

You need macro recording, text expansion and script completion, or want to use Input.Observer's importer and adjust the parts it cannot translate.

Differences in daily use

The StrokesPlus.net site keeps its forums and final downloads in an archive. The original author's successor, Input.Observer, offers C-like scripts, no-code steps, macro recording and AutoHotkey v2 handoff. Those tools suit workflows with many steps.

StrokesPlus.net JavaScript does not run unchanged in the successor. Its importer converts what it can; the rest needs manual adjustment. For a move to Mousetroke, rebuild your most-used gestures with built-in actions or Lua. Choose Input.Observer if macro recording and text expansion are central to your day.

Frequently asked questions

What is a good StrokesPlus.net alternative for Windows 11?

Consider Mousetroke if you mainly use a mouse and want system-wide gestures, screen corners and inspectable MIT source. For deep macro editing, native multi-finger input or browser-only use, follow the choices on this page.

Is Mousetroke free and open source?

Yes. It uses the MIT license, with no ads, account or telemetry. It checks GitHub for updates once a day by default; turn that off in Preferences if you prefer.

How do I move my scripted actions to Mousetroke?

Start with your most-used actions. Set them up with built-in actions or Lua, then test each one. Try Input.Observer first if you use macro recording and a script editor with completion every day.
