按住右键，
画一笔。

Mousetroke 是 Windows 上的鼠标手势工具。在任何窗口里按住右键拖一下：← 后退，↓→ 关标签页，↙ 最小化窗口。只是单击右键时，菜单照常弹出。

  • 免费开源（MIT）
  • Windows 10 / 11
  • 常驻内存约 19 MB

画什么，做什么

推到屏幕边角

不用按任何键：把鼠标推到角落，或者贴着屏幕边缘滚滚轮、点中键、上下来回蹭。离开边角再回来才会再次触发，不会连着误触。

不止发快捷键

每个手势可以绑定八种动作中的一种。动作里能用变量，比如 %MS_SELECTED_TEXT% 是当前选中的文字，%MS_PID% 是鼠标下那个程序的进程号。

发送按键
任意组合键或一串按键，比如 Ctrl+Shift+T。
窗口操作
最小化、最大化、置顶、关闭、结束进程，作用于鼠标下的窗口或当前窗口。
打开程序
带参数启动任意程序或文件，比如 notepad.exe。
打开网址
用默认浏览器打开，可以拼上选中的文字：https://www.bing.com/search?q=%MS_SELECTED_TEXT%
运行命令
执行一条命令行，比如 taskkill /F /PID %MS_PID%。
媒体与系统
音量、静音、播放 / 暂停、上一曲 / 下一曲、屏幕亮度。
弹出菜单
一个手势弹出一组动作，在鼠标旁点选执行。
Lua 脚本
需要判断条件或连续做好几步时，写几行 Lua。

该安静的时候安静

远程桌面、3D 和设计软件自己要用右键或中键拖动。第一次启动时，Mousetroke 会找出电脑上装了的这类程序，勾一下就在它们里面禁用手势。

常见问题

装了 Mousetroke 以后右键菜单还能用吗？

能。只按右键、不拖动时，Mousetroke 会把这次点击原样交还给系统，右键菜单照常弹出。按住不动超过设定时间（默认 0.5 秒，可调）也会当作普通的右键拖拽。

玩游戏或用远程桌面时会误触吗？

全屏的游戏、视频和演示会自动暂停手势。远程桌面、ToDesk、Blender、AutoCAD 等自己要用右键或中键拖动的程序，首次启动时可以一键禁用；也可以随时按 Win+Esc 暂停。

支持哪些 Windows 版本？

Windows 10 1809 及以上和 Windows 11，64 位。手势引擎不依赖任何运行库；设置界面使用 Microsoft Edge WebView2，Windows 11 自带，Windows 10 多数已随 Edge 安装。

Mousetroke 免费吗？

免费，以 MIT 许可证开源，没有广告或账号。默认每天向 GitHub 询问一次是否有新版本，可在偏好设置中关闭。不发送其他信息，无遥测。

占用多少内存和 CPU？

常驻的手势引擎约 19 MB 工作集（私有内存约 10 MB），空闲时不占 CPU。设置界面是单独的进程，打开时才启动，关掉就退出。

能自己定义手势吗？

能。在设置里新建一个手势，用鼠标在编辑面板的画板上画一遍轨迹就记下来了；也可以组合鼠标键、滚轮、键盘键和屏幕边角，并给每个程序单独设置。

配置保存在哪里？怎么备份？

配置在 %APPDATA%\mousetroke\config.json，设置里可以导入和导出。改动保存后约 1 秒内生效，不用重启。

怎么卸载？

在偏好设置里关掉开机自启，右键托盘图标选「退出」，再删除 mousetroke.exe 和 %APPDATA%\mousetroke 文件夹即可，不会留下其他文件。

下载后双击就能用

不用安装。运行后任务栏右下角出现图标，左键打开设置，右键暂停或退出。第一次打开会有一段四步的使用引导。
