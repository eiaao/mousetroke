## 验收

- `cd site; python gen.py; python gen_alternatives.py`：十四个对比页与双语日志正常生成，八种派生语言均为 `0 missed`。重复生成的输出摘要一致。
- `python site/check.py`：严格默认模式通过；覆盖 10 个首页、14 个对比页、2 个日志页、404 的静态链接、所有图片属性及 sitemap。
- `node --check site/assets/site.js`：通过。
- 临时副本的 11 类负向用例：重复标题、重复描述、错误 canonical、错误 hreflang、FAQ 不一致、非法 JSON-LD、失效链接、缺少图片尺寸、sitemap 漏项、sitemap 多项、大小写混合禁用名称（二进制文件）均被正确拒绝；恢复后通过。
- 使用 `tools/uitest` 的 puppeteer-core 25.14 与指定 Edge；服务器为本次 Python 子进程，明确指定 `--directory` 指向仓库外站点副本。只停止该进程。
- 48 组场景：中英 hub / strokeit / browser-extensions × Windows/Mac × 1440/390 宽 × light/dark，全部通过。脚本加载前覆盖 navigator.platform、userAgentData 和 maxTouchPoints，两系统触点数均为 0。页面横向溢出为 0，关键布局无重叠，图片载入成功，首屏/底部下载及备用平台链接均能点击，语言菜单指向对应页。
- 额外检查十四个目录页在 `/mousetroke/` 镜像子路径下的 CSS、品牌首页及语言切换，全部通过。
- 8 组补充场景：首页中英 × 两系统下载箭头，双语无 JS 时 Windows 默认与两平台备用链接，以及两系统触屏菜单，全部通过。
- 审阅 48 张全页截图的六组拼图（首屏、正文中段、底部来源）及中文 StrokeIt 390 浅色、英文扩展页 Mac 390 深色原尺寸细节；标题、16px 手机边距、表格容器、设置截图、FAQ、下载和来源布局正常。
