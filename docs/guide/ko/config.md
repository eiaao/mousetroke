# 설정, 백업과 업데이트

## 파일 위치

| 파일 | Windows | Mac |
|---|---|---|
| 설정 | `%APPDATA%\mousetroke\config.json` | `~/Library/Application Support/mousetroke/config.json` |
| 런타임 로그 | `%APPDATA%\mousetroke\mousetroke.log` | `~/Library/Logs/mousetroke/mousetroke.log` |

로그는 1 MB를 넘으면 `mousetroke.log.old`로 순환합니다. **정보 → 파일 위치**는 실제 경로를 표시합니다. **폴더 열기**는 설정 디렉터리를 열고, **로그 열기**는 런타임 로그를 엽니다. **가져오기와 내보내기** 아래에서 Windows의 **파일 탐색기에서 표시** 또는 Mac의 **Finder에서 보기**는 설정 파일을 표시합니다.

## 내보내기, 가져오기와 복원

**가져오기와 내보내기 → Mousetroke 설정 파일** 아래에서 **내보내기…**를 클릭하고 JSON 백업을 저장하세요. **파일에서 가져오기…**는 Mousetroke 설정 JSON을 읽고 기본 설정을 포함한 현재 설정을 대체합니다. 그 파일을 현재 바인딩에 병합하지는 않습니다. 이 작업 흐름에는 네이티브 설정 병합 옵션이 없습니다. 설정이 열려 있는 동안에는 Windows에서 Ctrl+Z, Mac에서 ⌘+Z로 가져오기를 되돌릴 수 있습니다.

JSON을 직접 편집하기 전에 백업을 내보내세요. 직접 복원하려면 엔진을 종료하고 설정을 닫은 다음, `config.json`을 백업으로 교체하고 Mousetroke를 다시 여세요. 설정을 닫아 두면 자동 저장이 복원된 파일을 덮어쓰는 것을 피할 수 있습니다.

## 다시 불러오기와 초기화

엔진은 설정 파일의 타임스탬프를 감시합니다. Windows는 약 1초마다 확인하고, Mac은 2초마다 예약되는 유지 관리 분기에서 확인합니다. 제스처 도중에 받은 변경 사항은 캡처가 끝난 뒤 적용됩니다. 잘못된 JSON은 이전 활성 설정을 계속 사용하고 로그에 오류를 기록합니다.

현재 설정 UI에는 기본값으로 재설정하는 버튼이 없습니다. 내장 기본값으로 시작하려면 Mousetroke를 종료하고 설정을 닫은 다음, `config.json`을 백업하고 제거하거나 이름을 바꾼 뒤 다시 여세요. 없는 파일은 플랫폼별 기본값으로 초기화됩니다. 잘못된 형식의 파일은 재설정 요청이 아닙니다.

## 업데이트

**기본 설정 → 업데이트 자동 확인**은 기본적으로 켜져 있으며 하루에 한 번 GitHub을 확인합니다. 자동 확인을 멈추려면 거기서 끄세요. 수동 확인은 **정보 → 업데이트 확인**을, 릴리스 노트는 **새로운 기능**을 사용하세요. 새 버전 메뉴 항목도 정보를 엽니다.

Windows에서 **지금 업데이트**는 실행 파일을 다운로드하고, SHA-256을 검증하고, 실행 중인 사본을 교체하고, 다시 시작합니다. 수동 설치에는 **다운로드 페이지 열기**를 사용할 수 있습니다.

Mac에서 **지금 업데이트**는 DMG를 다운로드하고, SHA-256, 번들 식별자, 버전과 서명 요구 사항을 확인하고, 앱을 교체하고, 다시 시작합니다. 이전 번들은 종료 후 휴지통으로 이동하며, 교체나 다시 시작 인계가 실패하면 복원됩니다. 설치 폴더에 쓸 수 없거나 업데이트가 실패하면 **직접 다운로드**를 사용할 수 있습니다. 인앱 업데이트는 브라우저 격리 확인을 다시 받지 않고 권한에 사용된 설치 식별자를 보존합니다. 브라우저로 새로 다운로드한 파일은 **확인 없이 열기**가 다시 필요할 수 있습니다.

## 제거

Windows: 기본 설정에서 **Windows 시작 시 제스처 자동 켜기**를 끄고, 트레이에서 **종료**하고, 설정을 닫은 다음, 설정이나 로그가 더 이상 필요 없으면 실행 파일과 `%APPDATA%\mousetroke`를 삭제하세요.

Mac: 메뉴 막대에서 **종료**하고, 설정을 닫고, `Mousetroke.app`을 삭제하세요. 데이터도 제거하려면 `~/Library/Application Support/mousetroke`와 `~/Library/Logs/mousetroke`를 삭제하세요. 시스템 설정의 로그인 항목에서 Mousetroke를 제거하세요. 다시 설치할 수 있다면 내보낸 백업을 보관하세요.

설정 오류와 없는 로그는 [문제 해결](troubleshooting.md)을 참조하세요.
