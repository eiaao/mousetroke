# 마우스 제스처

## 방향 궤적 기록하기

**모든 앱 → 마우스 제스처 → 새 제스처**를 여세요. 이름을 지은 다음 **시작 방법**을 고릅니다: **오른쪽 버튼을 누른 채로**, **가운데 버튼을 누른 채로**, **측면 버튼 1을 누른 채로**, **측면 버튼 2를 누른 채로**. 측면 버튼은 X1과 X2에 해당합니다.

그리기 영역에서 왼쪽 또는 오른쪽 버튼을 누른 채 그리고 놓으세요. 기록 캔버스는 선택한 트리거와 무관하게 두 버튼을 모두 받습니다. 직선 구간은 `←`나 `↓→` 같은 방향 궤적이 되며, 다시 그리면 바뀝니다. **동작 선택**을 클릭하고 [동작 라이브러리](action-library.md)를 검색하거나 둘러본 뒤, 사전 설정을 선택하고 필요한 매개변수를 입력하세요. 사용자 지정 키, 명령, Lua와 메뉴는 **고급**에서 선택할 수 있습니다. [동작](actions.md)을 참고하세요. 설정 밖에서 실제 트리거 버튼으로 제스처를 시험해 보세요.

## 모양 기록하기

C, O, S 같은 곡선은 모양 제스처입니다. 기록기는 선인지 모양인지를 자동으로 감지합니다. 필요하면 그린 뒤 **모양으로 사용** 또는 **궤적으로 사용**을 클릭하거나, **+ 단계 추가 → 모양 그리기**를 선택하세요.

같은 시작점과 방향을 유지하며 같은 모양을 2~3번 그리세요. 샘플마다 그린 뒤 버튼을 놓습니다. 저장하려면 유효한 샘플이 하나 이상 필요하며, 기록기는 최대 다섯 개의 샘플을 보관하고 개별 샘플을 삭제할 수 있습니다. 일치도와 충돌 메시지를 살펴보세요. 모양 제스처는 트리거 버튼을 놓을 때 실행됩니다.

## 버튼, 휠, 키 추가하기

**그다음** 아래에서 **+ 단계 추가**를 클릭하세요. **궤적 그리기**, **모양 그리기**, **마우스 버튼 클릭** 아래의 마우스 버튼, **휠 굴리기** 아래의 **위로** / **아래로**, 또는 **키 누른 채로**를 추가할 수 있습니다. 마지막 옵션은 누른 키보드 키를 기록합니다.

예를 들어 오른쪽 버튼으로 시작하고 왼쪽 클릭을 추가하거나, 휠 위로를 추가해 트리거를 누른 동안 볼륨 동작을 반복 실행할 수 있습니다. 단계에는 순서가 있습니다. 트리거 버튼을 누른 채 표시된 순서대로 수행하세요. 단계는 × 버튼으로 제거합니다.

방향 제스처에서 **인식되는 즉시 실행**은 놓기를 기다리지 않고 실행합니다. 반복되는 휠 동작에 알맞습니다. 모양은 항상 놓기를 기다립니다. **그리는 동안 제스처 이름 숨기기**는 해당 바인딩의 이름을 숨깁니다.

## 인식과 모양

**기본 설정 → 인식** 아래:

| 설정 | 효과 |
|---|---|
| 움직이지 않고 있을 때 클릭으로 취급하는 시간 | 기본값 500 ms; 슬라이더 150–1500 ms. 이 시간 동안 움직임 없이 누르고 있으면 일반 클릭/끌기로 전달됩니다. |
| 획 감도 | 기본값 30 px; 슬라이더 10–80 px. 값이 작을수록 짧은 궤적도 인식하지만 잘못된 제스처도 생기기 쉽습니다. |
| 제스처가 작용할 대상 | **커서 아래의 창**(기본값) 또는 **활성 창**을 고릅니다. |

**모양** 아래의 **궤적 표시**, **궤적 굵기**, **궤적 색**, **인식되었을 때**, **끝나면 서서히 사라지기**, **그리는 동안 제스처 이름 표시**, **제스처 이름 색**이 피드백을 제어합니다. 여기에는 모양 인식 임계값 슬라이더가 없습니다.

## 찾기, 복제와 끄기

Windows에서는 **Ctrl+F**, Mac에서는 **⌘+F**를 눌러 현재 목록을 이름, 그리기 또는 동작으로 검색합니다. **마우스 제스처** / **화면 가장자리**와 버튼/위치 필터를 사용하세요. **꺼짐**은 비활성화된 항목을 보여 줍니다.

제스처를 선택하고 **복제**를 클릭하면 사본이 만들어집니다(Ctrl+D / ⌘+D). 사본에는 다른 그리기를 지정하세요. 한 범위에 같은 그리기가 있으면 충돌하므로, 목록 순서로 동작을 고르는 방식에 의존하지 마세요. 편집기의 **켜짐** / **꺼짐** 스위치 또는 선택한 목록 행에서 Space를 눌러 삭제하지 않고 끌 수 있습니다. 꺼진 바인딩은 더 이상 트리거를 혼자 점유하지 않습니다.
