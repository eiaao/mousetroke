# 사용자 가이드

Mousetroke는 마우스 버튼을 누른 채 그리거나, 화면 모서리로 밀거나, 화면 가장자리를 사용할 때 동작을 실행합니다. 내장 제스처부터 시작한 다음, 프로그래밍 언어를 배우지 않고도 그 동작을 바꿀 수 있습니다.

이 가이드는 Windows와 macOS를 다룹니다. Mac 지원은 베타이며, 동작이나 스크립트에 영향을 주는 플랫폼 차이는 해당 위치에 표시했습니다. 아래 인터페이스 이름은 한국어 UI를 따릅니다.

## 제스처 시작하기

- [시작하기](getting-started.md): 설치, 첫 실행, 기본 제스처와 일시 정지.
- [마우스 제스처](gestures.md): 궤적과 모양 기록, 버튼이나 키 추가, 제스처 찾기와 편집.
- [화면 모서리와 가장자리](screen-edges.md): 볼륨, 밝기, 클릭과 가장자리 문지르기.
- [동작](actions.md): 선택한 텍스트 웹 검색을 포함해 제스처가 할 일을 고릅니다.
- [앱별 규칙](per-app.md): 재정의, 제외와 전체 화면 동작.

## 단축키 보내기와 스크립트 작성

- [키 보내기 문법](key-sequences.md): 복사해 쓰는 단축키 예제와 전체 키 이름 표.
- [Lua 기초](lua-basics.md): 첫 스크립트, 진입 함수와 디버깅.
- [Lua API](lua-api.md): `ms` 테이블의 모든 함수와 플랫폼 참고 사항.
- [Lua 레시피](lua-examples.md): 텍스트 출력, 클립보드 사용, 검색, 창 제어 등.

## 유지 관리와 문제 해결

- [설정, 백업과 업데이트](config.md): 파일, 복원, 자동 다시 불러오기, 업데이트와 제거.
- [문제 해결](troubleshooting.md): 발동하지 않는 제스처, 권한, 텍스트 입력과 로그.

빠른 성과를 원하면 [첫 제스처를 그려 보세요](getting-started.md#첫-제스처-그리기). 제스처로 텍스트를 입력하려면 [Lua 레시피](lua-examples.md#고정된-텍스트-입력)로 바로 이동하세요.
