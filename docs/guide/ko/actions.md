# 동작

제스처를 선택하거나 만든 뒤 **동작** 아래의 **동작 선택**을 클릭하세요. 원하는 작업을 검색하거나 범주를 둘러보고, 필요한 매개변수를 입력한 다음 **이 동작 사용**을 클릭하세요. [동작 라이브러리](action-library.md)는 텍스트 그대로 입력, 날짜와 시간, 창 배치와 전원 동작을 포함한 모든 사전 설정과 Windows 및 Mac의 사용 가능 여부를 안내합니다.

기존 동작에는 **변경**이 표시됩니다. 편집 가능한 고급 동작에 대응하는 사전 설정은 **고급 동작으로 변환**도 제공합니다. 기본 동작은 변환할 수 없는 이유를 표시합니다. **고급** 범주에서 키 보내기, 명령, Lua와 메뉴를 엽니다. 아래의 기존 편집기는 **동작 유형 변경**을 통해서도 계속 사용할 수 있습니다.

## 키 보내기

[키 시퀀스](key-sequences.md)를 입력하거나, **기록**을 클릭하고 단축키를 누른 뒤 **완료**를 클릭하세요. 예를 들어 `^c`는 Windows에서 복사하고, `#c`는 Mac에서 복사합니다. **문법 도움말**은 문법 가이드를 엽니다.

**먼저 커서 아래 창을 앞으로**는 보내기 전에 제스처 대상을 먼저 활성화합니다. 이 옵션이 없으면 단축키는 키보드 입력을 받는 애플리케이션으로 갑니다. 대상은 **기본 설정 → 제스처가 작용할 대상**도 따릅니다. 텍스트를 그대로 입력하려면 [동작 라이브러리](action-library.md)의 **텍스트 입력**을 선택하거나 Lua를 통해 [텍스트 우선 입력](key-sequences.md#텍스트와-이스케이프)을 사용하세요.

## 창 동작

제스처 대상에 적용할 동작 하나를 고릅니다:

| 동작 | 동작 방식 |
|---|---|
| 최소화 | 창을 최소화합니다. |
| 최대화 / 복원 | 최대화와 복원 크기 사이를 전환합니다. |
| 닫기 | 창에 닫기를 요청합니다. |
| 항상 위 / 해제 | Windows에서 최상위 상태를 전환합니다. Mac 편집기에서는 지원되지 않아 비활성화됩니다. |

Mac 창 제어는 손쉬운 사용을 사용합니다. **최대화 / 복원**은 앱의 Zoom 버튼을 누르므로 결과 크기는 해당 앱의 동작을 따릅니다. 네이티브 전체 화면을 요청하지 않으며 이미 최소화된 창은 건너뜁니다. 애플리케이션마다 노출하는 창 동작이 다를 수 있습니다.

## 앱 열기

**앱**은 Windows에서 실행 파일을 받으며, **찾아보기…**로 선택합니다. Mac에서는 `com.apple.Safari` 같은 앱 번들 ID, `.app` 경로 또는 실행 파일 경로를 사용하세요. **인수**는 선택 사항입니다. Mac에서는 인수를 따옴표 처리와 함께 나누며, 명령줄 실행 파일에는 전체 경로를 사용하세요.

**이미 실행 중일 때**는 **그 창으로 전환** 또는 **하나 더 열기**를 제공합니다. Windows는 **관리자 권한으로 실행**도 제공합니다. Mac은 권한 상승이나 창 필터 실행 옵션을 지원하지 않습니다. 현재 동작 편집기에는 클래스/제목/정규식 필드가 없습니다.

## URL 열기

**URL**을 채우고 필요하면 **브라우저**를 지정하세요. 브라우저를 비워 두면 기본 브라우저를 사용합니다. Windows는 브라우저 실행 파일을 받고, Mac은 브라우저 번들 ID나 앱 경로를 받습니다. **삽입** 버튼은 선택한 텍스트, 클립보드 텍스트, 앱 이름, 프로세스 ID 또는 창 제목 자리 표시자를 추가합니다.

선택한 텍스트 웹 검색은 URL을 다음과 같이 설정하세요:

```text
https://www.google.com/search?q=%MS_SELECTED_TEXT%
```

애플리케이션에서 텍스트를 선택한 다음 제스처를 수행하세요. 선택한 텍스트는 URL 인코딩되어 템플릿에 들어갑니다. 선택한 내용이 주소여도 검색과 번역 템플릿은 지정한 서비스를 계속 사용합니다. URL 입력란에 `%MS_SELECTED_TEXT%`만 있을 때에만 `http://`, `https://` 또는 `www.`로 시작하는 선택한 주소를 바로 열며, `www.`에는 `https://` 접두사가 붙습니다.

## 명령 실행

텍스트 영역에 명령을 입력하세요. **삽입**은 변수를 추가합니다. Windows는 숨겨진 `cmd.exe /C`로 실행하고, Mac은 `/bin/zsh -c`를 사용합니다. 셸 문법이므로 인수를 올바르게 따옴표로 묶으세요. 치환된 텍스트는 셸 이스케이프되지 않으므로, 신뢰할 수 없는 선택 텍스트를 명령에 넣지 마세요.

예를 들어 다음 Windows 명령은 작업 관리자를 엽니다:

```text
taskmgr.exe
```

Mac에서는 대신 **앱 열기**에 `com.apple.ActivityMonitor`를 사용하세요.

## 미디어와 시스템

편집기는 **재생 / 일시 정지**, **다음 트랙**, **이전 트랙**, **볼륨 높이기**, **볼륨 낮추기**, **음소거**, **밝게**, **어둡게**를 제공합니다.

Windows 밝기는 DDC/CI와 WMI 대체 경로로 10퍼센트 포인트씩 조정합니다. Mac 밝기는 내장 화면용 밝기 키를 보내며, 외장 DDC/CI는 지원되지 않습니다. Lua 밝기 함수는 지원되지 않지만 이 Mac 시스템 동작은 사용할 수 있습니다. [화면 가장자리](screen-edges.md)를 참조하세요.

## 메뉴 표시

**+ 메뉴 항목 추가**를 클릭하고 **메뉴 항목 이름**을 입력한 다음 각 항목 안에서 동작을 고르세요. **위로**, **아래로**, **메뉴 항목 삭제**로 정리합니다. 메뉴는 제스처 위치에 나타납니다. 편집기는 열 개수 필드를 노출하지 않으며 항목 안에 다른 메뉴 종류를 제공하지 않습니다. Mac은 단일 열을 지원하며, 여러 열 설정은 지원되지 않는 것으로 표시됩니다.

## Lua 스크립트

`ms_action`을 정의하는 완전한 스크립트를 붙여 넣으세요. 편집기는 [Lua 기초](lua-basics.md), [API 참조](lua-api.md), [예제](lua-examples.md)로 연결됩니다. 텍스트 영역은 Tab을 두 칸 공백으로 받습니다.

## 변수

이 자리 표시자는 **URL 열기 → URL**, **명령 실행**, **앱 열기 → 앱 / 인수**에서 사용하세요. 키 보내기 문자열, Lua 소스, 메뉴 이름, 브라우저에서는 확장되지 않습니다.

| 변수 | 값 |
|---|---|
| `%MS_SELECTED_TEXT%` | 동작에 필요할 때 캡처한 선택 영역. 없으면 비어 있습니다. |
| `%MS_CLIPBOARD_TEXT%` | 필요할 때 캡처한 현재 클립보드 텍스트. |
| `%MS_PID%` | 대상 프로세스 ID. |
| `%MS_EXE%` | 대상 실행 파일 식별자: Windows 경로, Mac 번들 ID 또는 실행 파일 경로. |
| `%MS_APP_NAME%` | 식별자의 파일 이름 부분. Mac에서는 번들 ID일 수 있습니다. |
| `%MS_WID%` | 십진수 텍스트로 된 플랫폼 창 식별자. |
| `%MS_WIN_NAME%` | 대상 창 제목. Mac은 필요할 때 손쉬운 사용을 통해 가져옵니다. |
| `%MS_MOUSE_X%`, `%MS_MOUSE_Y%` | 제스처 시작 화면 좌표. |
| `%MS_MOUSE_Y_FLIP%` | 가상 화면 아래쪽 좌표에서 제스처 시작 Y 좌표를 뺀 값. |
| `%MS_TARGET_MODE%` | 대상 기본 설정에 따라 `UnderCursor` 또는 `Focused`. |

사용할 수 없는 대상 변수는 없을 수 있으며, 알 수 없는 자리 표시자는 그대로 남습니다. 선택한 텍스트만 URL 템플릿에서 자동으로 URL 인코딩됩니다. 다른 치환은 있는 그대로 삽입됩니다. Lua는 자리 표시자 확장 대신 [진입 인수](lua-basics.md#진입-인수)와 `ms` 함수를 사용합니다.
