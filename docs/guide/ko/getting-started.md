# 시작하기

## 설치와 실행

Windows에서는 [최신 릴리스](https://github.com/eiaao/mousetroke/releases/latest)에서 `mousetroke.exe`를 다운로드하세요. 포터블 실행 파일이므로 보관할 위치에 저장하고 두 번 클릭하면 됩니다. 다운로드한 파일의 SHA-256을 해당 릴리스 페이지의 `SHA256SUMS.txt`와 비교해 보세요.

Windows 10 1809 이상과 Windows 11(64비트)을 지원합니다. 설정은 Windows 11에 포함된 Microsoft Edge WebView2를 사용합니다. 실행 파일은 아직 코드 서명되어 있지 않습니다. SmartScreen이 첫 실행을 차단하면 공식 릴리스를 다운로드했는지 확인한 뒤 **추가 정보 → 실행**을 선택하세요.

Mac에서는 `Mousetroke.dmg`를 다운로드해 열고 **Mousetroke**를 **응용 프로그램**으로 드래그하세요. 유니버설 앱으로 macOS 11 이상의 Apple silicon과 Intel을 지원합니다. DMG 안에서 열면 앱이 **응용 프로그램으로 이동**을 제안하고 설치된 사본을 다시 엽니다.

Mac 베타는 자체 서명되어 있으며 공증되지 않았습니다. 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**를 사용하고, 이전 macOS에서는 **오른쪽 클릭 → 열기**를 사용하세요. 설정 화면에서 **허용…**을 클릭하고 **손쉬운 사용**에서 Mousetroke를 켜세요. **준비 완료 — 이제 제스처를 사용할 수 있습니다**가 표시될 때까지 기다리세요. 화면 기록 권한은 필요하지 않습니다. 필요한 시스템에서 여전히 수신이 실패하면 설정 화면이 **입력 모니터링**을 제안하며, 요청될 때 켜면 됩니다.

## 설정을 열고 안내 마치기

Windows에서는 알림 영역 아이콘을 왼쪽 클릭하면 설정이 열립니다. 오른쪽 클릭하면 **설정…**, **제스처 일시 정지** / **제스처 재개**, **자동 시작**, **설정 폴더 열기**, **종료**가 있습니다. 업데이트가 있을 때는 새 버전 항목이 나타날 수도 있습니다.

Mac에서는 메뉴 막대 아이콘으로 **설정…**, 일시 정지/재개 또는 **종료**를 엽니다. 권한과 업데이트 항목은 필요할 때 나타납니다. **Mousetroke에 관하여**는 정보를 엽니다.

첫 실행 안내는 그리기, 화면 가장자리, 앱 제외와 일시 정지를 설명합니다. 마치기 전에 체크된 앱을 확인하세요. 그 앱들에서는 제스처가 꺼집니다. **정보 → 시작 안내 다시 보기**로 다시 열 수 있습니다. 설정의 변경 사항은 자동으로 저장되며, 미완성 궤적은 기록해야 저장할 수 있습니다.

## 첫 제스처 그리기

1. 탐색 기록이 있는 브라우저 페이지를 엽니다.
2. 오른쪽 마우스 버튼을 누른 채 왼쪽으로 움직여 `←`를 그린 다음 놓습니다. 뒤로 이동합니다.
3. 버려도 되는 탭에서 `↓→`를 그려 탭을 닫거나, `↙`로 창을 최소화해 보세요.

내장 동작은 플랫폼을 따릅니다. 브라우저 단축키는 적절한 경우 Windows에서 Ctrl을, Mac에서 Command를 사용합니다. 전체 편집 가능한 목록은 **모든 앱 → 마우스 제스처**에 있습니다. 일부 내장 항목은 꺼져 있으며, 특히 Mac에서 사용할 수 없는 동작이 그렇습니다.

일반 오른쪽 클릭은 여전히 애플리케이션의 컨텍스트 메뉴를 엽니다. 충분히 오래 가만히 누르고 있으면 일반 클릭이나 끌기가 되도록 버튼이 그대로 전달됩니다. 그 시간은 [기본 설정](gestures.md#인식과-모양)에서 조정하세요.

## 일시 정지

Windows에서는 **제스처 일시 정지**를 선택하고, 복구하려면 **제스처 재개**를 선택하세요. Mac에서는 **제스처 일시 정지** 레이블이 그대로 유지되며, 체크 표시가 수동 일시 정지를 나타내고 다시 클릭하면 재개됩니다. 기본 일시 정지/재개 단축키는 Windows에서 **Win+Esc**, Mac에서 **Control+Option+Command+P**입니다. **기본 설정 → 일시 정지 / 재개 단축키**에서 바꿀 수 있습니다.

전체 화면 게임, 동영상, 프레젠테이션은 전면 창이 전체 화면으로 감지되는 동안 제스처를 자동으로 억제합니다. 제외는 [앱별 규칙](per-app.md)을, 아무것도 발동하지 않을 때는 [문제 해결](troubleshooting.md)을 참조하세요.
