# 화면 모서리와 가장자리

## 기본값 사용해 보기

**모든 앱 → 화면 가장자리**에서 모든 모서리와 가장자리 바인딩을 편집할 수 있습니다.

| 트리거 | Windows 기본값 | Mac 기본값 |
|---|---|---|
| 왼쪽 아래 모서리로 밀기 | 시작 메뉴 | Spotlight |
| 오른쪽 아래 모서리로 밀기 | 바탕 화면 표시 | 바탕 화면 표시(F11) |
| 왼쪽 위 모서리로 밀기 | 앱 전환(Alt+Tab) | Mission Control(Control+Up) |
| 오른쪽 위 모서리로 밀기 | 작업 보기(Win+Tab) | 처음에는 바인딩이 꺼져 있음 |
| 위쪽 가장자리에서 휠 굴리기 | 볼륨 높이기/낮추기 | 볼륨 높이기/낮추기 |
| 위쪽 가장자리에서 가운데 클릭 | 음소거 | 음소거 |
| 위쪽 가장자리에서 오른쪽 클릭 | 재생 / 일시 정지 | 재생 / 일시 정지 |
| 아래쪽 가장자리에서 휠 굴리기 | 밝기 높이기/낮추기 | 밝기 바인딩은 처음에 꺼져 있음 |
| 오른쪽 가장자리를 위아래로 두 번 문지르기 | 작업 관리자 바인딩; 먼저 인식되는 즉시 실행을 켜세요 | Activity Monitor |

모서리 동작에는 버튼이 필요 없습니다. 포인터를 모서리로 미세요. 가장자리 스크롤과 클릭은 포인터가 선택한 가장자리에 닿아 있어야 합니다. 문지르기는 휠을 굴리는 대신 기록된 방향으로 가장자리를 따라 움직이는 것입니다.

## 가장자리 트리거 설정하기

1. 원하는 앱 범위 또는 **모든 앱**에서 **화면 가장자리 → 새 가장자리**를 선택합니다.
2. **시작 방법**에서 **화면 가장자리**를 고르고 도식에서 변이나 모서리를 선택합니다.
3. 모서리 동작이면 **그다음**을 비워 두고, **+ 단계 추가**로 휠 위로/아래로, 마우스 클릭 또는 가장자리를 따른 궤적을 추가합니다.
4. [동작](actions.md)을 고릅니다. 볼륨이면 **미디어와 시스템 → 볼륨 높이기** 또는 **볼륨 낮추기**를 고릅니다. 반복 스크롤이나 버튼 없는 문지르기에는 **인식되는 즉시 실행**을 켜세요.

문지르기에는 **궤적 그리기**를 추가하고 번갈아 가는 방향을 기록하세요. 유용한 예는 오른쪽 가장자리에서의 `↑↓↑↓`입니다. 파괴적인 동작을 지정하기 전에 Lua 토스트 같은 무해한 동작으로 시험해 보세요.

## 밝기와 플랫폼 차이

Windows **밝게** / **어둡게**는 커서 아래 모니터부터 시작해 10퍼센트 포인트씩 조정하고 결과를 표시합니다. DDC/CI를 시도한 다음 WMI를 시도합니다. 외장 디스플레이는 DDC/CI를 지원하고 허용해야 합니다. WMI 대체 경로는 보통 내장 패널인 첫 번째 WMI 밝기 장치를 사용하며, 커서의 모니터와 대응되지 않습니다. 두 경로가 모두 실패하면 화면에 메시지가 나타납니다. 더 작은 단계는 [Lua 레시피](lua-examples.md#커서-아래-화면-밝기)를 참조하세요.

Mac **미디어와 시스템 → 밝게** / **어둡게**는 내장 디스플레이용 시스템 밝기 키 이벤트를 보냅니다. 커서 아래 화면을 선택하지 않으며 외장 DDC/CI 디스플레이를 지원하지 않습니다. 아래쪽 가장자리 기본값은 꺼져 있습니다. Lua 밝기 API도 Mac에서는 지원되지 않습니다.

Mac에서 시스템 핫 코너가 설정된 모서리와 겹치면 Mousetroke가 경고합니다. 경쟁하는 동작을 피하려면 한쪽 지정을 바꾸세요. F11이나 Control+Up 같은 시스템 단축키는 macOS 단축키 설정에 따라 달라집니다.

앱 제외와 전체 화면 감지는 가장자리 트리거도 억제합니다. 한 앱에서는 되고 다른 앱에서는 안 될 때는 [앱별 규칙](per-app.md)을 참조하세요.
