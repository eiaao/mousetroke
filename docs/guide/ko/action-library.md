# 동작 라이브러리

사전 설정 동작은 탭 닫기나 창 가운데 배치처럼 하려는 작업을 나타냅니다. Mousetroke는 사전 설정 ID와 매개변수를 저장하고 실행할 때 Windows 또는 Mac 구현을 선택합니다. 브라우저와 편집기 단축키는 입력을 받는 앱에서도 지원해야 합니다.

## 동작 선택하기

1. 제스처를 만들거나 선택한 다음 **동작 선택**을 클릭하세요. 기존 동작에서는 **변경**을 클릭합니다.
2. 이름, 설명, 별칭 또는 단축키 표기로 검색하세요. 예를 들어 Windows에서는 `ctrl+w`, Mac에서는 `cmd+w` / `⌘w`를 쓸 수 있습니다. 검색은 모든 범주를 대상으로 합니다. 검색어가 없으면 **자주 사용**, **브라우저**, **편집**, **문자**, **창**, **데스크톱 및 시스템**, **미디어**, **열기**, **Mousetroke**를 둘러볼 수 있습니다.
3. 결과를 선택하세요. 매개변수가 있는 동작은 입력 양식을 엽니다. 텍스트를 입력하거나 날짜 형식과 검색 서비스를 고르고, URL을 입력하거나 파일, 폴더, 앱을 선택한 다음 **이 동작 사용**을 클릭해 확인하세요. 사용할 수 없는 동작은 비활성화되며 플랫폼 제한이나 2단계 구현 예정이라는 이유가 표시됩니다.
4. 설정 밖에서 제스처를 시험하세요. 제스처 이름이 비어 있으면 선택한 동작 이름을 따릅니다. 메뉴 항목도 같은 선택기를 사용합니다.

선택기가 열리면 검색창에 초점이 놓입니다. 위아래 화살표로 사용할 수 있는 결과 사이를 이동하고 Enter로 선택하세요. Esc는 매개변수 양식을 먼저 닫고 다음에 선택기를 닫습니다. 여러 줄 텍스트 입력란에서는 Ctrl+Enter 또는 Command+Enter로 양식을 확인합니다.

**고급 동작으로 변환**은 사전 설정을 현재 플랫폼에서 편집할 수 있는 키, 창 작업, URL, 앱, 명령 또는 시스템 키로 바꿉니다. 확인 창에서 안내하듯 이 변환은 되돌릴 수 없으며, 결과는 사전 설정의 플랫폼별 또는 언어별 기본값을 더 이상 따르지 않습니다. 기본 창 배치, 전원, 텍스트 그대로 입력, 날짜와 시간, 일반 텍스트 복사, 일시 정지, 설정 동작은 사전 설정 형태를 유지하고 카드에 변환할 수 없는 이유를 표시합니다. 목록 끝의 **고급** 범주에서 키 보내기, 명령, Lua, 메뉴를 사용할 수 있습니다. 기존 편집기는 [고급 동작 설명](actions.md)에서도 다룹니다.

## 텍스트, 창과 전원

- **텍스트 입력**은 공백, 줄바꿈, 중국어, 이모지와 `^+#{ENTER}` 같은 문자를 포함해 텍스트를 그대로 출력합니다. 기본 방법인 **붙여넣은 후 클립보드 복원**은 클립보드를 잠시 사용하고 짧게 기다린 뒤 이전 **텍스트**를 복원합니다. 이미지, HTML, 파일 목록 등 텍스트가 아닌 데이터가 있거나 내용을 확인할 수 없으면 클립보드를 변경하지 않고 직접 입력합니다. `paste_delay_ms`는 `paste`일 때만 표시되며 UI에서 50–5000 ms를 설정할 수 있고 기본값은 150 ms입니다. **문자 입력**은 클립보드를 사용하지 않고 Unicode 입력을 보냅니다. 두 방법 모두 키보드 입력을 받는 앱에 출력합니다.
- **날짜와 시간 입력**은 시스템의 현지 시각과 선택한 출력 방법을 사용합니다. ISO 날짜, 중국식 날짜, 미국식 날짜, 시간, 날짜와 시간을 선택할 수 있습니다. 사용자 지정 패턴은 대소문자를 구분하는 `YYYY`, `MM`, `DD`, `HH`, `mm`, `ss`를 지원합니다. 다른 문자는 그대로 출력하며 작은따옴표로 감싼 텍스트는 문자 그대로 처리하고 `''`는 작은따옴표 하나를 출력합니다. 예를 들어 `YYYY-MM-DD HH:mm:ss`는 날짜와 시간을 출력합니다. 닫히지 않은 따옴표는 거부합니다.
- **선택한 내용을 일반 텍스트로 복사**는 Ctrl+C / Command+C를 보내고 최대 500 ms 동안 클립보드 버전 변경을 기다린 다음 복사한 내용을 텍스트만 남기도록 바꿉니다. 복사가 끝나지 않거나 텍스트가 없으면 실패를 알리고 클립보드 내용을 유지합니다. 사용하기 전에 텍스트를 선택하고 해당 앱에 초점을 유지하세요.
- 배치 동작은 다른 창 동작과 같은 제스처 대상을 사용하며 **기본 설정 → 제스처가 작용할 대상**을 따릅니다. Windows는 기본 창 위치 기능을, Mac은 손쉬운 사용과 화면의 사용 가능한 영역을 사용합니다. 창의 최소 크기나 앱 제한으로 인해 정확히 화면 절반에 맞추지 못할 수 있습니다. Mac에서는 먼저 기본 전체 화면에서 나가세요. **다음 모니터로 이동**은 일정한 순서로 화면을 순환하며 상대 위치와 최대화 상태를 유지합니다. 화면이 하나면 이동하지 않습니다.
- **디스플레이 끄기**로 화면을 끈 뒤에는 입력으로 다시 켤 수 있습니다. **절전 모드**는 일반 시스템 절전을 요청하며 계정이나 시스템 정책에 따라 거부될 수 있습니다. 기본 동작에 실패하면 로그 한 줄을 기록하고 짧은 화면 메시지를 표시합니다. **제스처 일시 중지 / 재개**는 트레이와 단축키와 같은 일시 정지 상태를 사용합니다. 일시 정지 중에는 트레이나 단축키로 재개하세요. **설정 열기**는 평소의 설정 창을 엽니다.
