# Углы и кромки экрана

## Попробуйте значения по умолчанию

В **Все программы → Кромки экрана** каждая привязка угла или кромки доступна для правки.

| Триггер | По умолчанию в Windows | По умолчанию на Mac |
|---|---|---|
| Упереть в левый нижний угол | Меню «Пуск» | Spotlight |
| Упереть в правый нижний угол | Показать рабочий стол | Показать рабочий стол (F11) |
| Упереть в левый верхний угол | Сменить программу (Alt+Tab) | Mission Control (Control+Up) |
| Упереть в правый верхний угол | Переключатель задач (Win+Tab) | Привязка сначала отключена |
| Прокрутка у верхней кромки | Громче/тише | Громче/тише |
| Щелчок средней кнопкой у верхней кромки | Без звука | Без звука |
| Щелчок правой кнопкой у верхней кромки | Воспроизведение / пауза | Воспроизведение / пауза |
| Прокрутка у нижней кромки | Ярче/темнее | Привязки яркости сначала отключены |
| Потереть правую кромку вверх/вниз дважды | Привязка «Диспетчер задач»; сначала включите «Выполнять сразу после распознавания» | Activity Monitor |

Для угловых действий кнопка не нужна: уприте указатель в угол. Прокрутка и щелчки по кромке требуют, чтобы указатель касался выбранной кромки. Трение означает движение вдоль кромки в записанных направлениях, а не прокрутку колеса.

## Настройте срабатывание кромки

1. Выберите **Кромки экрана → Новая кромка** в нужной области программы или в **Все программы**.
2. В **Как начинается** выберите **Кромка экрана** и отметьте сторону или угол на схеме.
3. Оставьте **Потом** пустым для углового действия или через **+ Добавить шаг** добавьте прокрутку вверх/вниз, щелчок мыши или жест вдоль кромки.
4. Выберите [действие](actions.md). Для громкости выберите **Медиа и система → Громче** или **Тише**. Включите **Выполнять сразу после распознавания** для повторной прокрутки или трения без кнопки.

Для трения добавьте **Нарисовать жест** и запишите чередующиеся направления. Удобный пример — `↑↓↑↓` вдоль правой кромки. Сначала опробуйте безобидное действие, например всплывающее сообщение Lua, прежде чем назначать что-то разрушительное.

## Яркость и различия платформ

В Windows **Ярче** / **Темнее** начинает с монитора под курсором, изменяет яркость на 10 процентных пунктов и показывает результат. Сначала пробуется DDC/CI, затем WMI. Внешние дисплеи должны поддерживать и разрешать DDC/CI. Запасной путь WMI использует первое устройство яркости WMI, обычно встроенную панель; оно не сопоставляется с монитором курсора. Если оба пути не срабатывают, появляется сообщение на экране. См. [рецепты Lua](lua-examples.md#яркость-экрана-под-курсором) для меньшего шага.

На Mac **Медиа и система → Ярче** / **Темнее** посылает системные события клавиш яркости для встроенного дисплея. Экран под курсором не выбирается, внешние дисплеи DDC/CI не поддерживаются. Привязки нижней кромки по умолчанию отключены. Lua API яркости на Mac также не поддерживаются.

На Mac Mousetroke предупреждает, если активный угол системы пересекается с настроенным углом. Измените одно из назначений, чтобы действия не конкурировали. Системные сочетания вроде F11 или Control+Up зависят от настроек сочетаний macOS.

Исключения программ и определение полноэкранного режима подавляют и триггеры кромок. См. [правила для программ](per-app.md), если кромка работает в одной программе и не работает в другой.
