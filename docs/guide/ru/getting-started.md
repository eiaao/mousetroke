# Первые шаги

## Установка и запуск

В Windows загрузите `mousetroke.exe` со страницы [последнего выпуска](https://github.com/eiaao/mousetroke/releases/latest). Это переносимый исполняемый файл: сохраните его там, где планируете держать, и дважды щёлкните. Сверьте SHA-256 загрузки с `SHA256SUMS.txt` на той же странице выпуска.

Поддерживаются Windows 10 1809 или новее и Windows 11, 64-разрядные. Для настроек нужен Microsoft Edge WebView2, входящий в состав Windows 11. Исполняемый файл пока не подписан. Если SmartScreen блокирует первый запуск, выберите **Подробнее → Выполнить в любом случае**, убедившись, что загружен официальный выпуск.

На Mac загрузите `Mousetroke.dmg`, откройте его и перетащите **Mousetroke** в **Программы**. Универсальное приложение поддерживает Apple silicon и Intel на macOS 11 или новее. Если открыть его внутри DMG, приложение предлагает **Переместить в Программы** и заново открывает установленную копию.

Бета-версия для Mac самоподписана и не нотаризована. Если её блокируют, используйте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**; в более старых macOS — **правый щелчок → Открыть**. В мастере настройки нажмите **Разрешить…** и включите Mousetroke в разделе **Универсальный доступ**. Дождитесь сообщения **Всё готово — можно пользоваться жестами**. Разрешение «Запись экрана» не требуется. Мастер предлагает **Мониторинг ввода**, если прослушивание по-прежнему не удаётся на системах, где оно нужно; включите его по запросу.

## Откройте настройки и завершите руководство

В Windows щёлкните левой кнопкой значок в области уведомлений, чтобы открыть настройки. Правый щелчок даёт **Настройки…**, **Приостановить жесты** / **Возобновить жесты**, **Автозапуск**, **Открыть папку настроек** и **Выход**. Пункт о новой версии также может появиться, когда доступно обновление.

На Mac значок в строке меню открывает **Настройки…**, приостанавливает/возобновляет жесты или выполняет **Выход**. Пункты про разрешения и обновления появляются по необходимости. **О Mousetroke** открывает сведения о программе.

Руководство первого запуска объясняет рисование, кромки экрана, исключения программ и паузу. Перед завершением просмотрите отмеченные программы: в них жесты будут отключены. Его можно снова открыть через **О программе → Открыть руководство первого запуска**. Изменения в настройках сохраняются автоматически; незавершённый жест нужно записать, прежде чем он сохранится.

## Нарисуйте первый жест

1. Откройте страницу браузера с историей навигации.
2. Удерживайте правую кнопку мыши, проведите влево, чтобы нарисовать `←`, затем отпустите. Это возвращает назад.
3. Попробуйте `↓→` на одноразовой вкладке, чтобы закрыть её, или `↙`, чтобы свернуть окно.

Встроенные действия следуют платформе: сочетания браузера используют Ctrl в Windows и Command на Mac, где это уместно. Полный редактируемый список находится в **Все программы → Жесты мышью**. Некоторые встроенные жесты отключены, особенно действия, недоступные на Mac.

Обычный правый щелчок по-прежнему открывает контекстное меню приложения. Достаточно долгое удержание без движения также пропускает кнопку для обычного щелчка или перетаскивания; это время можно настроить в [Параметрах](gestures.md#распознавание-и-вид).

## Создание жеста

Откройте **Все программы → Жесты мышью → Новый жест**, выберите триггер и запишите рисунок. Нажмите **Выбрать действие**, найдите нужное поиском или просмотром [библиотеки действий](action-library.md), выберите готовое действие и заполните параметры. Изменения сохраняются автоматически, когда жест корректно настроен; проверьте его вне настроек. Подробнее о записи см. [Жесты мышью](gestures.md).

## Пауза

В Windows выберите **Приостановить жесты**, затем **Возобновить жесты**, чтобы вернуть их. На Mac пункт **Приостановить жесты** сохраняет то же название: галочка означает ручную паузу, повторный щелчок возобновляет. Сочетание паузы/возобновления по умолчанию — **Win+Esc** в Windows и **Control+Option+Command+P** на Mac. Измените его в **Параметры → Клавиша паузы / возобновления**.

Полноэкранные игры, видео и презентации автоматически подавляют жесты, пока окно на переднем плане определяется как полноэкранное. См. [правила для программ](per-app.md) про исключения и [устранение неполадок](troubleshooting.md), если ничего не срабатывает.
