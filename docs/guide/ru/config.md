# Конфигурация, резервные копии и обновления

## Расположение файлов

| Файл | Windows | Mac |
|---|---|---|
| Конфигурация | `%APPDATA%\mousetroke\config.json` | `~/Library/Application Support/mousetroke/config.json` |
| Журнал среды выполнения | `%APPDATA%\mousetroke\mousetroke.log` | `~/Library/Logs/mousetroke/mousetroke.log` |

Журналы переходят в `mousetroke.log.old` после превышения 1 МБ. **О программе → Расположение файлов** показывает фактические пути. **Открыть папку** открывает каталог конфигурации; **Открыть журнал** открывает журнал среды выполнения. В **Импорт и экспорт** пункты **Показать в Проводнике** в Windows или **Показать в Finder** на Mac показывают конфигурацию.

## Экспорт, импорт и восстановление

В **Импорт и экспорт → Файл настроек Mousetroke** нажмите **Экспорт…** и сохраните резервную копию JSON. **Импорт из файла…** читает JSON конфигурации Mousetroke и заменяет текущую конфигурацию, включая параметры. Он не объединяет этот файл с текущими привязками. Параметра объединения собственной конфигурации в этом сценарии нет. Импорт можно отменить через Ctrl+Z в Windows или ⌘+Z на Mac, пока настройки открыты.

Перед правкой JSON вручную экспортируйте резервную копию. Для прямого восстановления завершите движок и закройте настройки, замените `config.json` резервной копией, затем снова откройте Mousetroke. Закрытые настройки не дадут автосохранению перезаписать восстановленный файл.

## Перезагрузка и сброс

Движок следит за временной меткой файла конфигурации. Windows проверяет примерно раз в секунду; Mac проверяет в ветке обслуживания, планируемой каждые две секунды. Изменение, полученное во время жеста, применяется после окончания захвата. Неверный JSON оставляет предыдущую активную конфигурацию в работе и записывает ошибку в журнал.

В текущем интерфейсе настроек нет кнопки сброса к значениям по умолчанию. Чтобы начать со встроенных значений по умолчанию, завершите Mousetroke и закройте настройки, сделайте резервную копию и удалите или переименуйте `config.json`, затем откройте снова. Отсутствующий файл инициализируется значениями по умолчанию для платформы. Повреждённый файл — не запрос на сброс.

## Обновления

**Параметры → Проверять обновления автоматически** включено по умолчанию и проверяет GitHub раз в день. Отключите там, чтобы остановить автоматические проверки. Используйте **О программе → Проверить обновления** для ручной проверки и **Что нового** для заметок о выпуске. Пункт меню о новой версии также открывает сведения о программе.

В Windows **Обновить сейчас** загружает исполняемый файл, проверяет его SHA-256, заменяет работающую копию и перезапускает. **Открыть страницу загрузки** доступно для ручной установки.

На Mac **Обновить сейчас** загружает DMG, проверяет SHA-256, идентичность пакета, версию и требование подписи, заменяет приложение и перезапускает. Старый пакет после завершения уходит в Корзину; при неудачной замене или передаче перезапуска он восстанавливается. **Скачать вручную** доступно, если папка установки недоступна для записи или обновление не удалось. Обновления из приложения избегают повторного запроса карантина браузера и сохраняют идентичность установки, используемую для разрешений. Свежая загрузка через браузер может снова потребовать **Всё равно открыть**.

## Удаление

Windows: отключите **Включать жесты вместе с Windows** в Параметрах, выберите **Выход** в области уведомлений, закройте настройки, затем удалите исполняемый файл и `%APPDATA%\mousetroke`, если настройки или журналы больше не нужны.

Mac: **Выход** из строки меню, закройте настройки и удалите `Mousetroke.app`. Чтобы удалить и данные, удалите `~/Library/Application Support/mousetroke` и `~/Library/Logs/mousetroke`. Уберите Mousetroke из объектов входа в Системных настройках. Сохраните экспортированную резервную копию, если можете установить снова.

См. [устранение неполадок](troubleshooting.md) при ошибках конфигурации и отсутствующих журналах.
