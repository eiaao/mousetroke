# Действия

Выберите жест и задайте его действие в разделе **Действие**. Редактор предлагает восемь типов. Большинству задач достаточно простого действия; используйте [Lua](lua-basics.md), когда нужны условия или несколько операций.

## Послать клавиши

Введите [последовательность клавиш](key-sequences.md) или нажмите **Запись**, нажмите сочетание и нажмите **Готово**. Например, `^c` копирует в Windows; `#c` копирует на Mac. **Справка по синтаксису** открывает руководство по синтаксису.

**Сначала активировать окно под курсором** сначала активирует цель жеста. Без этого сочетания идут в то приложение, которое получает клавиатурный ввод. Цель также следует **Параметры → Жесты действуют на**. Переключателя простого текста в этом редакторе нет; [ввод в текстовом режиме](key-sequences.md#текст-и-экранирование) доступен через Lua.

## Действия с окном

Выберите одну операцию, применяемую к цели жеста:

| Операция | Поведение |
|---|---|
| Свернуть | Свернуть окно. |
| Развернуть / восстановить | Переключить между развёрнутым и восстановленным размером. |
| Закрыть | Попросить окно закрыться. |
| Поверх всех / отменить | Переключить режим поверх всех в Windows; на Mac не поддерживается и в редакторе отключено. |

Управление окнами на Mac использует универсальный доступ. **Развернуть / восстановить** нажимает кнопку масштабирования приложения, поэтому итоговый размер следует поведению этой программы; нативный полноэкранный режим не запрашивается, уже свёрнутые окна пропускаются. Приложения могут отличаться тем, какие операции с окном они предоставляют.

## Открыть программу

**Программа** принимает исполняемый файл в Windows; **Обзор…** выбирает его. На Mac укажите ID пакета вроде `com.apple.Safari`, путь к `.app` или путь к исполняемому файлу. **Аргументы** необязательны. На Mac аргументы разделяются с учётом кавычек; для командных исполняемых файлов используйте полные пути.

**Если уже запущена** предлагает **Переключиться на неё** или **Запустить ещё одну**. В Windows также есть **Запуск от имени администратора**. Mac не поддерживает повышение прав и параметры запуска с фильтром окон. Полей класса/заголовка/regex в текущем редакторе действий нет.

## Открыть URL

Заполните **URL** и при необходимости **Браузер**. Оставьте браузер пустым для браузера по умолчанию. Windows принимает исполняемый файл браузера; Mac — ID пакета браузера или путь к приложению. Кнопки **Вставить** добавляют подстановки выделенного текста, текста буфера обмена, имени программы, идентификатора процесса или заголовка окна.

Для поиска в интернете по выделенному тексту задайте URL:

```text
https://www.google.com/search?q=%MS_SELECTED_TEXT%
```

Выделите текст в приложении, затем выполните жест. Выделенный текст кодируется для URL. Если он уже начинается с `http://`, `https://` или `www.`, Mousetroke открывает этот адрес напрямую; к `www.` добавляется префикс `https://`.

## Выполнить команду

Введите команду в текстовое поле. **Вставить** добавляет переменные. Windows выполняет её через скрытый `cmd.exe /C`; Mac использует `/bin/zsh -c`. Это синтаксис оболочки, поэтому заключайте аргументы в кавычки правильно. Подставленный текст не экранируется для оболочки; не передавайте в команды недоверенный выделенный текст.

Например, следующая команда Windows открывает диспетчер задач:

```text
taskmgr.exe
```

На Mac вместо этого используйте **Открыть программу** с `com.apple.ActivityMonitor`.

## Медиа и система

Редактор предлагает **Воспроизведение / пауза**, **Следующий трек**, **Предыдущий трек**, **Громче**, **Тише**, **Без звука**, **Ярче** и **Темнее**.

В Windows яркость меняется на 10 процентных пунктов через DDC/CI с запасным путём WMI. На Mac яркость посылает клавиши яркости для встроенного экрана; внешний DDC/CI не поддерживается. Эти системные действия Mac доступны, хотя функции яркости Lua не поддерживаются. См. [кромки экрана](screen-edges.md).

## Показать меню

Нажмите **+ Добавить пункт меню**, введите **Название пункта меню**, затем выберите действие внутри каждого пункта. Упорядочивайте пункты кнопками **Вверх**, **Вниз** и **Удалить пункт меню**. Меню появляется в позиции жеста. Редактор не показывает поле числа столбцов и не предлагает другой тип меню внутри пункта. Mac поддерживает один столбец; многостолбцовые настройки помечаются как неподдерживаемые.

## Скрипт Lua

Вставьте полный скрипт, определяющий `ms_action`. Редактор ссылается на [основы Lua](lua-basics.md), [справочник API](lua-api.md) и [примеры](lua-examples.md). Текстовое поле принимает Tab как два пробела.

## Переменные

Используйте эти подстановки в **Открыть URL → URL**, **Выполнить команду** и **Открыть программу → Программа / Аргументы**. Они не раскрываются в строках отправки клавиш, исходном коде Lua, именах меню или поле «Браузер».

| Переменная | Значение |
|---|---|
| `%MS_SELECTED_TEXT%` | Выделение, снятое когда действию оно нужно; пусто, если недоступно. |
| `%MS_CLIPBOARD_TEXT%` | Текущий текст буфера обмена, снимаемый по запросу. |
| `%MS_PID%` | Идентификатор целевого процесса. |
| `%MS_EXE%` | Идентичность целевого исполняемого файла: путь Windows; ID пакета Mac или путь к исполняемому файлу. |
| `%MS_APP_NAME%` | Именная часть идентичности, на Mac это может быть ID пакета. |
| `%MS_WID%` | Идентификатор окна платформы в десятичном тексте. |
| `%MS_WIN_NAME%` | Заголовок целевого окна; Mac при необходимости получает его через универсальный доступ. |
| `%MS_MOUSE_X%`, `%MS_MOUSE_Y%` | Экранные координаты начала жеста. |
| `%MS_MOUSE_Y_FLIP%` | Нижняя координата виртуального экрана минус координата Y начала жеста. |
| `%MS_TARGET_MODE%` | `UnderCursor` или `Focused` в соответствии с параметром цели. |

Недоступные целевые переменные могут отсутствовать; неизвестные подстановки остаются без изменений. Автоматическое URL-кодирование в шаблоне URL получает только выделенный текст. Остальные подстановки вставляются как есть. Lua использует [аргументы точки входа](lua-basics.md#аргументы-точки-входа) и функции `ms` вместо раскрытия подстановок.
