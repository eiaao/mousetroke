# 画面の隅と端

## まず既定を試す

**すべてのアプリ → 画面の端**では、隅と端のすべての割り当てを編集できます。

| トリガー | Windows の既定 | Mac の既定 |
|---|---|---|
| 左下隅へ押し付ける | スタートメニュー | Spotlight |
| 右下隅へ押し付ける | デスクトップの表示 | デスクトップの表示（F11） |
| 左上隅へ押し付ける | アプリの切り替え（Alt+Tab） | Mission Control（Control+Up） |
| 右上隅へ押し付ける | タスクビュー（Win+Tab） | 当初は割り当てが無効 |
| 上端でスクロール | 音量を上げる／下げる | 音量を上げる／下げる |
| 上端で中クリック | ミュート | ミュート |
| 上端で右クリック | 再生 / 一時停止 | 再生 / 一時停止 |
| 下端でスクロール | 明るさを上げる／下げる | 明るさの割り当ては当初無効 |
| 右端を 2 回上下にこする | タスク マネージャーの割り当て。先に**認識したらすぐ実行**を有効にする必要があります | アクティビティモニタ |

隅の動作にボタンは不要です。ポインターを隅へ押し付けます。端のスクロールとクリックは、ポインターが選んだ端に触れている必要があります。「こする」は、ホイールを回すのではなく、記録した方向に沿って端をなぞる動作です。

## エッジトリガーを設定する

1. 目的のアプリのスコープまたは**すべてのアプリ**で、**画面の端 → 新規エッジ**を選びます。
2. **始め方**で**画面の端**を選び、図の中から辺か隅を選択します。
3. 隅の動作だけなら**次に**は空のままにします。**+ ステップを追加**でホイールの上下、マウスクリック、端に沿った軌跡を追加できます。
4. [動作](actions.md)を選びます。音量なら**メディアとシステム → 音量を上げる**か**音量を下げる**です。連続スクロールやボタンなしのこすりには**認識したらすぐ実行**をオンにします。

こすりには**軌跡を描く**を追加し、交互の方向を記録します。右端に対する `↑↓↑↓` が実用的な例です。破壊的な動作を割り当てる前に、Lua のトーストのような無害な動作で試してください。

## 明るさとプラットフォームの違い

Windows の**明るさを上げる**／**明るさを下げる**は、まずカーソル下のモニターを対象に 10 パーセントポイント調整し、結果を表示します。まず DDC/CI を試し、次に WMI へフォールバックします。外付けディスプレイは DDC/CI に対応し、許可している必要があります。WMI フォールバックは最初の WMI 明るさデバイス（通常は内蔵パネル）を使い、カーソルのモニターとは照合しません。両方の経路が失敗すると、画面にメッセージが表示されます。より細かい調整は [Lua 使用例](lua-examples.md#カーソル下の画面の明るさ)を参照してください。

Mac の**メディアとシステム → 明るさを上げる**／**明るさを下げる**は、内蔵ディスプレイにシステムの明るさキーイベントを送ります。カーソル下の画面を選択せず、外付け DDC/CI ディスプレイにも対応していません。下端の既定の割り当ては無効です。Lua の明るさ API も Mac では非対応です。

Mac では、システムのホットコーナーが設定済みの隅と重なると警告します。競合する動作を避けるため、どちらかの割り当てを変更してください。F11 や Control+Up などのシステムショートカットは、macOS のショートカット設定に依存します。

アプリの除外とフルスクリーン検出は、エッジトリガーも抑止します。あるアプリでは動いて別のアプリでは動かない場合は、[アプリごとのルール](per-app.md)を参照してください。
