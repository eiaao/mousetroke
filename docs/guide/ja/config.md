# 設定、バックアップ、更新

## ファイルの場所

| ファイル | Windows | Mac |
|---|---|---|
| 設定 | `%APPDATA%\mousetroke\config.json` | `~/Library/Application Support/mousetroke/config.json` |
| ランタイムログ | `%APPDATA%\mousetroke\mousetroke.log` | `~/Library/Logs/mousetroke/mousetroke.log` |

ログは 1 MB を超えると `mousetroke.log.old` へ切り替わります。**このアプリについて → ファイルの場所**に実際のパスが表示されます。**フォルダーを開く**は設定フォルダーを、**ログを開く**はランタイムログを開きます。**インポートとエクスポート**では、Windows の**エクスプローラーで表示**か Mac の**Finder に表示**で設定ファイルを表示できます。

## エクスポート、インポート、復元

**インポートとエクスポート → Mousetroke 設定ファイル**で**エクスポート…**をクリックし、JSON のバックアップを保存します。**ファイルからインポート…**は Mousetroke の設定 JSON を読み込み、環境設定を含む現在の設定を丸ごと置き換えます。ファイルを現在の割り当てへ統合はしません。この流れには設定ファイルの統合オプションはありません。設定画面を開いている間は、Windows では Ctrl+Z、Mac では ⌘+Z でインポートを元に戻せます。

JSON を手動で編集する前に、バックアップをエクスポートしてください。直接復元するには、エンジンを終了して設定画面を閉じ、`config.json`をバックアップで置き換えてから、Mousetroke を開き直します。設定画面を閉じておけば、自動保存が復元したファイルを上書きしません。

## 再読み込みとリセット

エンジンは設定ファイルのタイムスタンプを監視します。Windows は約 1 秒に 1 回、Mac は 2 秒ごとにスケジュールされるメンテナンス処理で確認します。ジェスチャーの検出中に受け取った変更は、検出の終了後に適用されます。不正な JSON では、以前の有効な設定を使い続け、ログにエラーを記録します。

現在の設定画面には、初期設定へ戻すボタンはありません。内蔵の既定値からやり直すには、Mousetroke を終了して設定画面を閉じ、`config.json`をバックアップしたうえで削除かリネームをして、開き直してください。ファイルがなければ、プラットフォームごとの既定値で初期化されます。壊れたファイルはリセットの指示にはなりません。

## 更新

**環境設定 → 更新を自動的に確認**は既定でオンで、1 日 1 回 GitHub を確認します。自動確認を止めるには、ここでオフにしてください。手動での確認には**このアプリについて → 更新を確認**を、リリースノートには**更新内容**を使います。新バージョンのメニュー項目からも「このアプリについて」を開けます。

Windows では、**今すぐ更新**が実行ファイルをダウンロードし、SHA-256 を検証して、実行中のコピーを置き換えて再起動します。**ダウンロードページを開く**で手動インストールもできます。

Mac では、**今すぐ更新**が DMG をダウンロードし、SHA-256、バンドルの識別情報、バージョン、署名要件を確認して、アプリを置き換えて再起動します。古いバンドルは終了後にゴミ箱へ移り、置き換えや再起動の引き継ぎに失敗した場合は元に戻ります。インストールフォルダーに書き込めない場合や更新に失敗した場合は、**手動でダウンロード**を使えます。アプリ内からの更新は、ブラウザーの隔離プロンプトを再度受けずに済み、権限に使われるインストール識別情報も維持されます。ブラウザーからダウンロードし直した場合は、再度**このまま開く**が必要になることがあります。

## アンインストール

Windows：環境設定の**Windows 起動時にジェスチャを自動で有効にする**をオフにし、トレイから**終了**し、設定画面を閉じてから、実行ファイルと、設定やログが不要になった場合は `%APPDATA%\mousetroke` を削除してください。

Mac：メニューバーから**終了**し、設定画面を閉じて、`Mousetroke.app` を削除します。データも消すには、`~/Library/Application Support/mousetroke` と `~/Library/Logs/mousetroke` を削除してください。システム設定のログイン項目から Mousetroke を外します。再インストールする可能性がある場合は、エクスポートしたバックアップを保管してください。

設定のエラーやログがない場合は[トラブルシューティング](troubleshooting.md)を参照してください。
