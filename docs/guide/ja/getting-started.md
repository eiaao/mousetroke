# はじめに

## インストールと起動

Windows では、[最新のリリース](https://github.com/eiaao/mousetroke/releases/latest)から `mousetroke.exe` をダウンロードします。ポータブル版の実行ファイルなので、長く置いておきたい場所に保存してダブルクリックするだけです。ダウンロードの SHA-256 は、そのリリースページの `SHA256SUMS.txt` と照合できます。

対応環境は Windows 10 1809 以降と Windows 11（64 ビット）です。設定画面には Microsoft Edge WebView2 を使用し、Windows 11 には最初から含まれています。実行ファイルはまだコード署名されていません。初回起動時に SmartScreen にブロックされたら、公式のリリースからダウンロードしたことを確認したうえで、**詳細情報 → 実行**を選んでください。

Mac では `Mousetroke.dmg` をダウンロードして開き、**Mousetroke** を**アプリケーション**へドラッグします。ユニバーサルアプリで、macOS 11 以降の Apple silicon と Intel に対応しています。DMG 内から開いた場合は、**アプリケーションに移動**が提案され、インストール済みのコピーを開き直します。

Mac のベータ版は自己署名で、公証を受けていません。ブロックされた場合は、**システム設定 → プライバシーとセキュリティ → このまま開く**を使ってください。古い macOS では、**右クリック → 開く**も使えます。セットアップで**許可…**をクリックし、**アクセシビリティ**で Mousetroke をオンにします。**準備完了 — ジェスチャーを使えます**と表示されるまで待ちます。画面収録の権限は不要です。必要なシステムでキーの監視が失敗する場合、セットアップが**入力監視**を案内することがあるので、要求されたときに許可してください。

## 設定を開いてガイドを完了する

Windows では、通知領域のアイコンを左クリックすると設定を開きます。右クリックのメニューには**設定…**、**ジェスチャを一時停止**／**ジェスチャを再開**、**自動起動**、**設定フォルダーを開く**、**終了**があります。更新が利用可能なときは、新バージョンの項目が表示されることもあります。

Mac では、メニューバーのアイコンから**設定…**を開き、一時停止／再開や**終了**を選べます。権限や更新の項目は状況に応じて表示されます。**Mousetroke について**でこのアプリについてを開きます。

初回の「はじめに」ガイドでは、描き方、画面の端、アプリの除外、一時停止を説明します。終了する前にチェックされたアプリを確認してください。それらのアプリではジェスチャーがオフになります。あとから**このアプリについて → はじめにを読む**で開き直せます。設定の変更は自動保存されます。未完成の軌跡は、記録が終わるまで保存できません。

## 最初のジェスチャーを描く

1. 履歴のあるページをブラウザーで開きます。
2. マウスの右ボタンを押したまま左へ動かして `←` を描き、離します。ページが戻ります。
3. 使い捨てのタブで `↓→` を試して閉じたり、`↙` でウィンドウを最小化したりしてみてください。

内蔵の動作はプラットフォームに従います。たとえばブラウザーのショートカットは、Windows では Ctrl、Mac では適切な場面で Command を使います。完全な編集可能な一覧は**すべてのアプリ → マウスジェスチャ**にあります。一部の内蔵項目、とくに Mac で使えない動作は無効になっています。

通常の右クリックは、引き続きアプリケーションのコンテキストメニューを開きます。十分な長さだけ静止すると、通常のクリックやドラッグのためにボタンが渡されます。この時間は[環境設定](gestures.md#認識と外観)で調整できます。

## ジェスチャーを作成する

**すべてのアプリ → マウスジェスチャ → 新規ジェスチャ**を開き、トリガーを選んで描画を記録します。**アクションを選択**をクリックし、[動作ライブラリ](action-library.md)を検索するかカテゴリーから探して、プリセットを選び、パラメーターを入力します。ジェスチャーが有効になると変更は自動保存されます。設定画面の外で試してください。記録方法の詳細は[マウスジェスチャー](gestures.md)を参照してください。

## 一時停止

Windows では**ジェスチャを一時停止**を選び、**ジェスチャを再開**で元に戻します。Mac では常に**ジェスチャを一時停止**というラベルで、チェックが手動の一時停止を示し、もう一度クリックすると再開します。既定の一時停止／再開ショートカットは、Windows では **Win+Esc**、Mac では **Control+Option+Command+P** です。**環境設定 → 一時停止 / 再開のショートカット**で変更できます。

フルスクリーンのゲーム、動画、プレゼンテーションでは、前面ウィンドウがフルスクリーンと判定されているあいだ、ジェスチャーが自動的に抑止されます。除外は[アプリごとのルール](per-app.md)を、何も発動しない場合は[トラブルシューティング](troubleshooting.md)を参照してください。
