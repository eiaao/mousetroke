# ジェスチャライブラリ

ジェスチャライブラリは「どう描くか」と「何をするか」を分けます。ジェスチャーを一度定義すれば、アプリごとに違う動作を割り当てられます。共有ジェスチャーを描き直すと、使っているすべての箇所に反映されます。形のジェスチャーもサンプルは 1 組だけです。

## ライブラリを見る

サイドバーの**ジェスチャ**をクリックします。一覧は**マウスジェスチャ**と**画面の端**に分かれています。トリガーボタンで絞り込んだり、**未使用**で使われていないジェスチャーを探したり、名前・描き方・用途で検索したりできます。各カードには使用箇所の数が表示されます。

カードをクリックすると詳細が開きます。上部で描き直せます。**使用箇所**には使っているアプリ、ジェスチャー名、動作が並び、行をクリックするとその設定に移動します。新規インストールでは組み込みジェスチャーが最初からライブラリに入っています。旧バージョンから更新した場合、既存のジェスチャーは各アプリに分かれたままなので、次の手順で整理してください。

## 整理して取り込む

ライブラリが空のときは**ジェスチャを整理して取り込む…**をクリックします。その後も右上の**整理して取り込む…**からいつでも実行できます。まず範囲を選びます。

- **共通のジェスチャだけ（推奨）**：**すべてのアプリ**のジェスチャーを取り込み、ほかのアプリにある同じ・似たジェスチャーも関連付けます。アプリごとに個別設定したジェスチャーは専用のままです。
- **すべてのジェスチャ**：共通のジェスチャーと、アプリごとのジェスチャーをすべて取り込みます。

**次へ**で結果を確認します。確定するまで設定は変わりません。

- まったく同じ描き方は自動でまとめます。方向が同じで各区間の長さだけが違う軌跡も、既定でまとめます。
- **似ている形（確認してください）**：グループごとに、残したいものの**これを使う**をクリックするか、**サンプルをまとめる**をクリックします。推奨値より似ていないグループは既定ではまとめません。まとめた形は、認識結果が以前と少し変わることがあります。
- **そのまま追加**：展開してチェックを外せます。外したジェスチャーは取り込まれず、各アプリ専用のままです。

**取り込む**で完了します。通知から元に戻せます。同じアプリ内で似ていても用途が違う 2 つのジェスチャーはまとめません。

## ほかのアプリで使う

ジェスチャーの詳細で**ほかのアプリで使う…**をクリックし、アプリを選んでから動作を選びます。すでにこのジェスチャーを使っているアプリは選べません。同じ描き方がすでにあるアプリでは競合の警告が出ます。ジェスチャーをオフにしたアプリにも割り当てられますが、そこでは動きません。一覧の最後にある**アプリを追加…**で先にアプリを追加することもできます。割り当て後は詳細画面のままで、新しい行が強調表示されます。通知の**設定する**でその設定を開けます。

アプリの側から始めることもできます。エディタでは、現在のアプリだけのジェスチャーに**このアプリ専用**と表示されます。

- **ライブラリから選ぶ**でライブラリのジェスチャーに切り替えます。選択画面は検索できます。**ほかのアプリのジェスチャ**から選ぶと、まずライブラリに追加され、元の設定と共有されます。**新しく描く（このアプリ専用）**はライブラリに入りません。
- **その他の操作**メニューには**ライブラリに追加**と**ほかのアプリで使う…**があります。

## 共有ジェスチャーを編集する

エディタでは、ライブラリのジェスチャーに**ライブラリ**と使用箇所が表示されます。描き直すと使用箇所すべてに反映され、新しく生じた競合が一覧表示されます。

- **ここだけ変更**：変更を現在のアプリだけに残します。このアプリ専用になり、ライブラリとほかのアプリは元のままです。
- **完了**：共有の変更を保ったまま通知を閉じます。

**変更**でライブラリの別のジェスチャーに切り替えられます。↗ ボタン（**ライブラリで表示**）でジェスチャーの詳細を開きます。

## 作成と削除

**新規ジェスチャ**はライブラリで直接記録します。描き終えると追加されます。名前は省略できます。あとで**ほかのアプリで使う…**から割り当てます。

まだ使われているジェスチャーで**ジェスチャを削除**を選ぶと、次のどちらかを選べます。

- **削除する（各箇所は専用のコピーを保持）**
- **使用箇所ごと削除**

どちらも通知から元に戻せます。

## 設定ファイルと互換性

ライブラリは設定ファイルの `gestures` に保存され、それを使う各ジェスチャーにも描き方の完全なコピーが保存されます。そのため旧バージョンの Mousetroke でも新しい設定を読み込め、ジェスチャーはそのまま動きます。ただし旧バージョンで設定を保存するとライブラリは失われ、各ジェスチャーはアプリ専用に戻ります。更新後にもう一度整理してください。設定ファイルを手で編集して描き方がライブラリと食い違った場合、その箇所はアプリ専用に変わり、一度だけ通知されます。ファイルの場所とバックアップは[設定、バックアップ、更新](config.md)を参照してください。
