# ユーザーガイド

Mousetroke は、マウスボタンを押しながら描く、画面の隅へ押し付ける、画面の端を使う、といった操作で動作を実行します。まず内蔵のジェスチャーから始めれば、プログラミング言語を学ばなくても動作を変更できます。

このガイドは Windows と macOS を対象とします。Mac 対応はベータ段階で、動作やスクリプトに影響するプラットフォームの違いは該当箇所で説明します。以下の画面名は日本語 UI の実際の文言に合わせています。

## ジェスチャーを使い始める

- [はじめに](getting-started.md)：インストール、初回起動、既定のジェスチャー、一時停止。
- [マウスジェスチャー](gestures.md)：軌跡と形状の記録、ボタンやキーの追加、ジェスチャーの検索と編集。
- [画面の隅と端](screen-edges.md)：音量、明るさ、クリック、端のこすり。
- [動作](actions.md)：選択テキストのウェブ検索を含む、ジェスチャーの実行内容の選択。
- [アプリごとのルール](per-app.md)：上書き、除外、フルスクリーン時の挙動。

## ショートカットを送る、スクリプトを書く

- [キー送信の構文](key-sequences.md)：コピーして使えるショートカット例と完全なキー名一覧。
- [Lua 入門](lua-basics.md)：最初のスクリプト、エントリー関数、デバッグ。
- [Lua API](lua-api.md)：`ms` テーブルの全関数とプラットフォームごとの注意点。
- [Lua 使用例](lua-examples.md)：テキストの出力、クリップボードの利用、検索、ウィンドウ操作など。

## メンテナンスとトラブルシューティング

- [設定、バックアップ、更新](config.md)：ファイル、復元、自動再読み込み、更新、アンインストール。
- [トラブルシューティング](troubleshooting.md)：発動しないジェスチャー、権限、テキスト入力、ログ。

まず一歩として、[最初のジェスチャーを描いてみましょう](getting-started.md#最初のジェスチャーを描く)。ジェスチャーで文字を入力したいときは、[Lua 使用例](lua-examples.md#固定テキストを入力する)へ進んでください。
