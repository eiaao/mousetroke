# 動作ライブラリ

プリセットは、タブを閉じる、ウィンドウを中央に移動する、といった目的を表します。Mousetroke はプリセットの ID とパラメーターを保存し、実行時に Windows または Mac 用の処理を選びます。ブラウザーやエディターのショートカットは、入力を受け取るアプリが対応している必要があります。

## 動作を選ぶ

1. ジェスチャーを作成または選択し、**アクションを選択**をクリックします。既存の動作では**変更**をクリックします。
2. 名前、説明、別名、ショートカットの表記で検索します。たとえば Windows では `ctrl+w`、Mac では `cmd+w` / `⌘w` を使えます。検索はすべてのカテゴリーが対象です。検索しない場合は、**よく使う**、**ブラウザー**、**編集**、**文字**、**ウィンドウ**、**デスクトップとシステム**、**メディア**、**開く**、**Mousetroke**から探せます。
3. 結果を選びます。パラメーターがある動作では入力フォームが開きます。テキストの入力、日付形式や検索サービスの選択、URL の指定、ファイル・フォルダー・アプリの選択を行い、**このアクションを使う**で確定します。利用できない動作は無効になり、プラットフォームの制限や第 2 段階で対応予定であることが表示されます。
4. 設定画面の外でジェスチャーを試します。ジェスチャー名が空の場合は、選んだ動作の名前が使われます。メニュー項目も同じ選択画面を使います。

選択画面を開くと検索欄にフォーカスが移ります。上下キーで利用可能な結果を移動し、Enter で選択します。Esc は先にパラメーターフォームを閉じ、次に選択画面を閉じます。複数行のテキスト欄では Ctrl+Enter または Command+Enter でフォームを確定できます。

**高度なアクションに変換**は、プリセットを現在のプラットフォームで編集できるキー、ウィンドウ操作、URL、アプリ、コマンド、システムキーに置き換えます。確認画面にあるとおり、この変換は一方向です。変換後はプリセットのプラットフォームや言語ごとの既定値には追従しません。ネイティブのウィンドウ配置、電源、文字どおりのテキスト入力、日時、標準テキストでのコピー、一時停止、設定の動作はプリセットのまま残り、カードに変換できない理由が表示されます。一覧の末尾の**詳細**にはキー送信、コマンド、Lua、メニューがあります。既存のエディターの使い方は[詳細な動作のリファレンス](actions.md)も参照してください。

## テキスト、ウィンドウ、電源

- **テキストを入力**は、空白、改行、中国語、絵文字、`^+#{ENTER}` のような文字もそのまま出力します。既定の**ペーストしてクリップボードを復元**はクリップボードを一時的に使い、短い待ち時間の後で以前の**テキスト**を復元します。画像、HTML、ファイル一覧などのテキスト以外のデータが含まれる場合や、内容を確認できない場合は、クリップボードを変更せず直接入力します。`paste_delay_ms` は `paste` の場合だけ表示され、画面で設定できる範囲は 50–5000 ms、既定値は 150 ms です。**文字を順に入力**はクリップボードを使わず Unicode 入力を送ります。どちらもキーボード入力を受け取っているアプリに出力します。
- **日時を挿入**はシステムのローカル時刻と選択した出力方法を使います。ISO 日付、中国語の日付、米国式の日付、時刻、日時を選べます。独自の書式には `YYYY`、`MM`、`DD`、`HH`、`mm`、`ss` を使えます。大文字と小文字は区別されます。ほかの文字はそのまま出力され、単一引用符で囲んだ部分は文字どおりに扱われます。`''` は引用符を 1 つ出力します。たとえば `YYYY-MM-DD HH:mm:ss` で日時を出力できます。閉じていない引用符はエラーになります。
- **選択範囲を標準テキストでコピー**は Ctrl+C / Command+C を送り、クリップボードの更新を最大 500 ms 待ってから、コピーした内容をテキストだけに置き換えます。コピーが完了しない場合やテキストがない場合は失敗を通知し、クリップボードの内容を保持します。実行前にテキストを選択し、そのアプリにフォーカスを残してください。
- 配置の動作は、ほかのウィンドウ操作と同じジェスチャー対象を使い、**環境設定 → ジェスチャの対象**に従います。Windows では標準のウィンドウ配置機能、Mac ではアクセシビリティと画面の使用可能な領域を使います。ウィンドウの最小サイズやアプリの制限により、正確な半画面配置にならない場合があります。Mac では先に標準のフルスクリーンを終了してください。**次のディスプレイに移動**は一定の順序で画面を切り替え、相対位置と最大化状態を保ちます。画面が 1 つの場合は移動しません。
- **ディスプレイをスリープ**で画面を消した後は、入力操作で再び点灯できます。**スリープ**は通常のシステムスリープを要求しますが、アカウントやシステムの方針で拒否されることがあります。ネイティブ動作に失敗すると、ログに 1 行記録し、短い画面通知を表示します。**ジェスチャを一時停止・再開**はトレイやホットキーと同じ一時停止状態を使います。一時停止中はそれらから再開してください。**設定を開く**は通常の設定ウィンドウを開きます。
