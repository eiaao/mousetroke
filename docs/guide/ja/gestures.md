# マウスジェスチャー

## 方向ストロークを記録する

**すべてのアプリ → マウスジェスチャ → 新規ジェスチャ**を開きます。名前を付け、**始め方**で**右ボタンを押しながら**、**中ボタンを押しながら**、**サイドボタン 1 を押しながら**、**サイドボタン 2 を押しながら**のいずれかを選びます。サイドボタンは X1 と X2 に対応します。

描画エリアで、左か右のボタンを押しながら描いて離します。録画キャンバスは、選択したトリガーとは無関係にどちらのボタンも受け付けます。まっすぐな線は `←` や `↓→` のような方向ストロークになり、描き直すと置き換わります。[動作](actions.md)を選び、設定の外で実際のトリガーボタンで試してみてください。

## 形を記録する

C、O、S などの曲線は「形」のジェスチャーです。レコーダーは線か形かを自動判定します。必要なら、描いたあとに**形として使う**または**軌跡として使う**をクリックするか、**+ ステップを追加 → 形を描く**を選びます。

同じ形を 2～3 回、同じ始点と方向を保って描きます。1 回描くごとにボタンを離します。保存には有効なサンプルが 1 つ以上必要です。レコーダーは最大 5 個のサンプルを保持し、個別のサンプルを削除できます。一致度と競合のメッセージに注目してください。形のジェスチャーは、トリガーボタンを離したときに実行されます。

## ボタン、ホイール、キーを追加する

**次に**の**+ ステップを追加**をクリックします。**軌跡を描く**、**形を描く**、**マウスボタンをクリック**のマウスボタン、**ホイールを回す**の**上**／**下**、**キーを押しながら**を追加できます。最後の項目は、押したキーボードのキーを記録します。

たとえば、右ボタンで始めて左クリックを追加したり、トリガーを押しているあいだ音量の動作を繰り返すためにホイールアップを追加したりできます。ステップには順序があり、トリガーボタンを保ったまま表示順に実行されます。× ボタンでステップを削除できます。

方向ジェスチャーでは、**認識したらすぐ実行**をオンにすると、離すのを待たずに実行します。ホイールの繰り返し動作に向いています。形は常に離すまで待ちます。**描いている間はジェスチャ名を表示しない**は、その割り当てに限って名前を隠します。

## 認識と外観

**環境設定 → 認識**：

| 設定 | 効果 |
|---|---|
| 押したまま動かないとクリック扱いにする時間 | 既定 500 ms、スライダー範囲 150～1500 ms。この時間押したまま動かないと、通常のクリック／ドラッグとして渡されます。 |
| ストロークの感度 | 既定 30 px、スライダー範囲 10～80 px。小さいほど短い軌跡を認識しますが、誤発動も増えます。 |
| ジェスチャの対象 | **カーソルの下のウィンドウ**（既定）または**アクティブなウィンドウ**を選びます。 |

**外観**では、**軌跡を表示**、**軌跡の太さ**、**軌跡の色**、**認識できたとき**、**終わったらフェードアウト**、**描いている間はジェスチャ名を表示**、**ジェスチャ名の色**がフィードバックを制御します。ここに形認識のしきい値スライダーはありません。

## 検索、複製、オフ

Windows では **Ctrl+F**、Mac では **⌘+F** を押すと、名前・描き方・動作で現在の一覧を検索できます。**マウスジェスチャ**／**画面の端**の切り替えと、ボタン／位置の絞り込みも使えます。**オフ**は無効な項目を表示します。

ジェスチャーを選んで**複製**をクリックするとコピーが作成されます（Ctrl+D／⌘+D）。コピーには別の描き方を与えてください。同じスコープ内で同一の描き方は競合するため、一覧の順序で動作を選ぶことはできません。エディターの**オン**／**オフ**スイッチや、一覧の行を選んで Space を押すと、削除せずに無効化できます。無効にされた割り当てが自分でトリガーを占有することはなくなります。
