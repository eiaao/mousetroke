# アプリごとのルール

## アプリを追加する

サイドバーの**アプリを追加…**をクリックします。**このアプリ専用のジェスチャを設定**か**このアプリでジェスチャをオフ**を選び、次の方法で指定します。

- **実行中**の項目を選択します。
- **ウィンドウを指定**をクリックして、アプリのウィンドウをクリックします。Esc か右クリックでキャンセルできます。
- **参照…**でアプリを選びます。
- アプリやそのショートカットを設定ウィンドウにドロップします。Mac は `.app` バンドルと実行ファイルを受け付けます。スコープは可能な場合にバンドル ID を使います。

Windows のルールは、実行ファイル名か完全パスに大文字小文字を区別せずに一致します。Mac のアプリの識別情報は通常 `com.apple.Safari` のような形です。推測せず、ピッカーを使ってください。アプリのスコープはサイドバーに現れ、独自のマウスジェスチャーと画面の端を持てます。

## アプリ専用と共通のジェスチャー

**すべてのアプリ**には共通のジェスチャーが入っています。アプリ専用のジェスチャーは、対応する共通のジェスチャーより優先されます。**共通ジェスチャも使う**をチェックすると、アプリの割り当てが一致しないときも共通の割り当てが使えます。チェックを外すと、そのアプリのジェスチャーだけになります。

たとえば、ブラウザーを追加して右ボタンの `↓→` ジェスチャーを作り、そこに別の動作を割り当てます。他のアプリは共通の `↓→` 動作のままです。既存の設定を複製するには、そのスコープ内で[複製](gestures.md#検索複製オフ)を使い、割り当てを編集します。

## アプリでジェスチャーをオフにする

サイドバーでアプリを選び、**このアプリでジェスチャをオフ**を有効にします。そのアプリ自身のジェスチャー、共通のジェスチャー、画面の端のトリガーが無効になります。右・中・サイドボタンは通常どおり渡されます。保存された割り当ては残り、**ジェスチャをオンに戻す**で復元できます。**このアプリを削除**は、アプリ専用のスコープを削除します。

これは、右・中ボタンのドラッグを使うリモートデスクトップ、仮想マシン、3D モデリング、デザインツール、ゲームエディターに便利です。ピッカーの**オフ推奨**の一覧には、これらのカテゴリーの既知のアプリが含まれます。検出されたインストール済みアプリは、まとめて追加できます。

## フルスクリーンと初回ガイド

フルスクリーン自動一時停止は自動で動きます。前面のアプリがフルスクリーンと判定されているあいだ、エンジンはジェスチャーとエッジトリガーの開始を避けます。フルスクリーンのゲーム、動画、プレゼンに対応し、手動の一時停止状態とは別です。Windows では、モニターを覆う枠なしウィンドウかどうかを判定し、デスクトップ／シェルのウィンドウを除外します。Mac は、前面アプリのウィンドウを画面の範囲と照合します。そのため、フルスクリーンに見えるアプリでも、2 つのプラットフォームで挙動が異なることがあります。

ウィンドウモードのゲームやリモートデスクトップには、明示的な除外を追加してください。どこでも一時停止するには、[トレイ／メニューバーのコマンドか一時停止ショートカット](getting-started.md#一時停止)を使います。

初回の「はじめに」ガイドには、マウスドラッグを自分で使うことが多い検出済みアプリが表示されます。終了時にチェックされた項目のアプリはオフになります。続ける前に確認してください。Mac の内蔵設定には、提案する除外アプリの無効スコープも含まれます。これらにはアプリ専用の割り当てはありません。除外はあとからサイドバーで変更できます。
