# 動作

ジェスチャーを選択または作成し、**動作**の**アクションを選択**をクリックします。目的を検索するかカテゴリーから探し、必要なパラメーターを入力して**このアクションを使う**で確定します。[動作ライブラリ](action-library.md)には、テキストの入力、日時、ウィンドウ配置、電源操作を含む全プリセットと Windows・Mac の対応状況を掲載しています。

既存の動作には**変更**が表示されます。編集可能な詳細動作に対応するプリセットには**高度なアクションに変換**も表示されます。変換できないネイティブのプリセットには理由が表示されます。**詳細**カテゴリーではキー送信、コマンド、Lua、メニューを選べます。以下の既存エディターは、**アクションの種類を変更**からも引き続き利用できます。

## キーを送る

[キー列](key-sequences.md)を入力するか、**記録**をクリックしてショートカットを押し、**完了**をクリックします。たとえば Windows では `^c` がコピー、Mac では `#c` がコピーです。**構文ヘルプ**で構文ガイドを開けます。

**先にカーソル下のウィンドウを前面にしてから送る**をオンにすると、先にジェスチャーの対象をアクティブにします。オフのままでは、ショートカットはキーボード入力を受け取っているアプリに送られます。対象は**環境設定 → ジェスチャの対象**にも従います。文字をそのまま入力するには、[動作ライブラリ](action-library.md)の**テキストを入力**を選ぶか、Lua 経由で[テキスト優先モード](key-sequences.md#テキストとエスケープ)を使ってください。

## ウィンドウ操作

1 つの操作を選びます。ジェスチャーの対象に適用されます。

| 操作 | 動作内容 |
|---|---|
| 最小化 | ウィンドウを最小化します。 |
| 最大化 / 元に戻す | 最大化と元のサイズを切り替えます。 |
| 閉じる | ウィンドウに終了を要求します。 |
| 常に手前 / 解除 | Windows では最前面を切り替えます。Mac のエディターでは非対応のため無効です。 |

Mac のウィンドウ操作はアクセシビリティを使います。**最大化 / 元に戻す**はアプリのズームボタンを押すため、結果のサイズはそのアプリの挙動に従い、ネイティブのフルスクリーンは要求せず、最小化済みのウィンドウはスキップします。アプリによって公開されるウィンドウ操作は異なります。

## アプリを開く

**アプリ**には Windows の実行ファイルを指定します。**参照…**で選択できます。Mac では `com.apple.Safari` のようなバンドル ID、`.app` のパス、実行ファイルのパスを使います。**引数**は省略できます。Mac では引数は引用符を処理して分割されるため、コマンドライン実行ファイルには完全なパスを使ってください。

**すでに起動しているとき**は**切り替える**か**もう一枚開く**を選べます。Windows では**管理者として実行**も選べます。Mac は権限の昇格やウィンドウ条件付き起動に対応していません。現在の動作エディターにクラス／タイトル／正規表現の欄はありません。

## URL を開く

**URL**を入力し、必要なら**ブラウザー**も指定します。ブラウザーを空欄にすると既定のブラウザーを使います。Windows はブラウザーの実行ファイル、Mac はブラウザーのバンドル ID かアプリのパスを受け付けます。**挿入**ボタンは、選択テキスト、クリップボードのテキスト、アプリ名、プロセス ID、ウィンドウタイトルのプレースホルダーを追加します。

選択したテキストでウェブ検索するには、URL を次に設定します。

```text
https://www.google.com/search?q=%MS_SELECTED_TEXT%
```

アプリケーションでテキストを選択してからジェスチャーを実行してください。選択テキストは URL エンコードされてテンプレートに挿入されます。選択内容がアドレスでも、検索や翻訳のテンプレートは指定したサービスを使います。URL 欄が `%MS_SELECTED_TEXT%` だけの場合に限り、`http://`、`https://`、`www.` で始まる選択アドレスを直接開きます。`www.` には `https://` が付きます。

## コマンドを実行

テキスト欄にコマンドを入力します。**挿入**は変数を追加します。Windows は非表示の `cmd.exe /C` で実行し、Mac は `/bin/zsh -c` を使います。これはシェルの構文なので、引数は正しく引用符で囲んでください。置換されたテキストはシェルエスケープされないため、信頼できない選択テキストをコマンドに渡さないでください。

たとえば、次の Windows コマンドはタスク マネージャーを開きます。

```text
taskmgr.exe
```

Mac では代わりに**アプリを開く**で `com.apple.ActivityMonitor` を指定します。

## メディアとシステム

エディターは**再生 / 一時停止**、**次のトラック**、**前のトラック**、**音量を上げる**、**音量を下げる**、**ミュート**、**明るさを上げる**、**明るさを下げる**を用意しています。

Windows の明るさは、WMI フォールバック付きの DDC/CI で 10 パーセントポイント調整します。Mac の明るさは内蔵画面に明るさキーを送ります。外付け DDC/CI には対応していません。Lua の明るさ関数は Mac で使えませんが、これらの Mac のシステム動作は使えます。[画面の隅と端](screen-edges.md)を参照してください。

## メニューを表示

**+ メニュー項目を追加**をクリックし、**メニュー項目名**を入力して、各項目の中の動作を選びます。**上へ**、**下へ**、**メニュー項目を削除**で整理します。メニューはジェスチャーの位置に表示されます。エディターに列数の欄はなく、項目の中に別のメニュー種別もありません。Mac は 1 列のみで、複数列の設定は非対応として表示されます。

## Lua スクリプト

`ms_action` を定義する完全なスクリプトを貼り付けます。エディターは [Lua 入門](lua-basics.md)、[API リファレンス](lua-api.md)、[使用例](lua-examples.md)へのリンクを表示します。テキスト欄では Tab は 2 スペースとして入力されます。

## 変数

これらのプレースホルダーは **URL を開く → URL**、**コマンドを実行**、**アプリを開く → アプリ／引数**で使えます。キー送信の文字列、Lua のソース、メニュー名、ブラウザーでは展開されません。

| 変数 | 値 |
|---|---|
| `%MS_SELECTED_TEXT%` | 動作に必要なときに取得された選択テキスト。取得できない場合は空。 |
| `%MS_CLIPBOARD_TEXT%` | 現在のクリップボードのテキスト。要求時に取得されます。 |
| `%MS_PID%` | 対象のプロセス ID。 |
| `%MS_EXE%` | 対象の実行ファイル識別情報。Windows はパス、Mac はバンドル ID か実行ファイルのパス。 |
| `%MS_APP_NAME%` | 識別情報のファイル名部分。Mac ではバンドル ID のことがあります。 |
| `%MS_WID%` | プラットフォームのウィンドウ ID（10 進数の文字列）。 |
| `%MS_WIN_NAME%` | 対象のウィンドウタイトル。Mac は必要時にアクセシビリティ経由で取得します。 |
| `%MS_MOUSE_X%`, `%MS_MOUSE_Y%` | ジェスチャー開始時の画面座標。 |
| `%MS_MOUSE_Y_FLIP%` | 仮想画面の下端座標からジェスチャー開始時の Y 座標を引いた値。 |
| `%MS_TARGET_MODE%` | 対象の設定に応じた `UnderCursor` または `Focused`。 |

対象を取得できない場合、一部の変数は存在しないことがあり、不明なプレースホルダーはそのまま残ります。URL テンプレートで自動的に URL エンコードされるのは選択テキストだけで、他の置換はそのまま挿入されます。Lua ではプレースホルダーではなく[エントリー引数](lua-basics.md#エントリー引数)と `ms` 関数を使ってください。
