# 手势库

手势库把“怎么画”和“做什么”分开：一个手势只定义一次，可以在多个程序里各自执行不同的动作。重录共享手势时，用到它的地方一起更新；形状手势也只保留一份样本。

## 浏览手势库

侧栏点“手势”。列表分“鼠标手势”和“触发角”，可以按触发按钮筛选，用“未使用”找出没有被使用的手势，也可以搜索名称、画法或用途。每张卡片下方显示它用在几处。

点卡片打开详情：上半部分可以重画；“用在”列出每个使用它的程序、手势名和动作，点击跳到那一条。新安装的内置手势已经在手势库中。从旧版本升级时，已有手势仍分散在各程序里，先按下一节整理。

## 整理并导入

手势库为空时点“整理并导入手势…”，之后可以随时点右上角的“整理并导入…”。先选择范围：

- “只整理通用手势（推荐）”：收入“所有程序”里的手势，其他程序里相同或相似的一并关联；各程序单独设置的手势保持专用。
- “整理全部手势”：通用手势和各程序单独设置的手势全部收入。

点“下一步”查看结果。确认之前不会修改配置：

- 完全相同的画法自动合并；方向相同、只差各段长短的轨迹默认合并。
- “相似的形状，请确认”：逐组在要保留的那一份上点“以此为准”，或点“合并样本”。相似度低于建议值的默认不合并；合并后识别结果可能与原来略有不同。
- “直接收入手势库”：展开后可以取消勾选，不导入的手势仍是各程序专用。

点“导入”完成，提示条上可以撤销。同一个程序里两个相似、但用途不同的手势不会被合并。

## 在其他程序中使用

在手势详情点“在其他程序中使用…”，选择程序，再选择动作。已经使用这个手势的程序不能再选；程序里已有同样画法时会提示冲突；已禁用手势的程序可以分配，但不会生效。列表末尾的“添加程序…”可以先添加程序。分配后停留在手势详情，新的一行会高亮，点提示条上的“去设置”可以直接打开这一条。

也可以从程序这边出发。编辑器里，只属于当前程序的手势显示“本程序专用”：

- 点“从手势库选择”改用手势库里的手势。选择器可以搜索；“其他程序里的手势”选中后会先加入手势库，再与原来那条共享；“录制新手势（本程序专用）”不会进入手势库。
- “更多操作”菜单里有“加入手势库”和“在其他程序中使用…”。

## 修改共享手势

编辑器里，来自手势库的手势显示“手势库”和使用位置。重画后修改会同步到所有使用它的地方，并列出新产生的冲突：

- “只改这里”：修改只留给当前程序，它改为本程序专用；手势库和其他程序保持原样。
- “改好了”：保留同步，收起提示。

“更换”可以换成手势库里的另一个手势；↗ 按钮（“在手势库中查看”）跳到手势详情。

## 新建与删除

“新建手势”直接在手势库中录制，画完才会加入，名称可以不填，之后再用“在其他程序中使用…”分配。

“删除手势”时，如果还有地方在用，可以选择：

- “删除，各处保留一份（改为本程序专用）”
- “连同用到它的手势一起删除”

两种操作都可以在提示条上撤销。

## 配置与兼容

手势库保存在配置文件的 `gestures` 中，引用它的手势同时保存一份完整画法。因此旧版本 Mousetroke 仍能读取新配置，手势照常工作；但在旧版本里保存设置会丢掉手势库，各处手势变回本程序专用，升级后再整理一次即可。手动修改配置文件导致某处画法与手势库不一致时，那一处会改为本程序专用，并提示一次。文件位置和备份见[配置、备份与更新](config.md)。
