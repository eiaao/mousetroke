# 按程序设置

## 添加程序

侧栏点“添加程序…”，选择“为它单独设置手势”或“在它里面禁用手势”，然后可以：

- 在“正在运行”列表中选择程序。
- 点击“点选窗口”，再点程序窗口；Esc 或右键取消。
- 点“浏览…”选择程序文件。
- 将程序或其快捷方式拖进设置窗口。Mac 接受 `.app` 和可执行文件，能取得 bundle id 时用它作为作用域身份。

Windows 规则支持按可执行文件名或完整路径匹配，忽略大小写。Mac 程序身份通常类似 `com.apple.Safari`。建议用选择器获取，避免猜错。添加后，侧栏会出现该程序，可分别设置鼠标手势和触发角。

## 专用手势与通用手势

“所有程序”保存通用手势。程序专用的对应手势优先。勾选“也使用通用手势”时，程序自己的绑定未命中，会继续尝试通用绑定；取消后，只使用该程序自己的手势。

例如，添加浏览器，在它里面新建按住右键画 `↓→` 的手势，改成另一个动作。其他程序仍使用通用的 `↓→` 动作。想在同一作用域内复用已有配置，可用[复制一份](gestures.md#查找复制和停用)后编辑。

## 在程序中禁用

侧栏选中程序，开启“禁用手势”。这会禁用该程序专用手势、通用手势和屏幕边角，右键、中键、侧键原样交给程序。已有绑定仍保留，点“恢复手势”即可重新使用。“移除此程序”会删除该程序的专用作用域。

远程桌面、虚拟机、3D 建模、设计软件和游戏编辑器经常需要右键／中键拖拽，适合排除。选择器中的“建议禁用”提供这些类别的已知程序，也可批量添加检测到的已安装程序。

## 全屏与首次引导

全屏自动暂停无需配置：前台程序被检测为全屏时，引擎不启动手势或边角动作，适用于全屏游戏、视频和演示。它与手动暂停状态相互独立。Windows 检查无标题栏且覆盖显示器的窗口，并排除桌面／外壳窗口；Mac 检查前台程序窗口是否覆盖屏幕。因此看起来全屏的程序，在两个平台的表现可能不同。

窗口模式游戏或远程桌面建议添加明确的排除规则。需要所有程序暂停时，使用[托盘／菜单栏命令或暂停快捷键](getting-started.md#暂停)。

首次引导会列出检测到、通常需要自己处理鼠标拖拽的程序。完成引导时禁用勾选项，请先检查。Mac 内置配置也为建议排除的程序预置了禁用作用域，其中没有专用绑定。以后都可从侧栏修改。
