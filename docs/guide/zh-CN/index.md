# 使用指南

Mousetroke 可以在按住鼠标键画出手势、推到屏幕角落或操作屏幕边缘时执行动作。先用内置手势，再按自己的习惯修改动作；大多数操作不需要编程。

本指南覆盖 Windows 和 macOS。Mac 版仍处于测试阶段，影响动作或脚本使用的平台差异会在对应位置说明。下文界面名称采用简体中文界面的实际文字。

## 开始使用手势

- [安装与首次使用](getting-started.md)：安装、首次引导、默认手势和暂停。
- [鼠标手势](gestures.md)：录制轨迹和形状，添加鼠标键或键盘键，搜索与编辑手势。
- [屏幕边角](screen-edges.md)：音量、亮度、边缘点击与摩擦。
- [动作](actions.md)：选择手势执行的内容，包括选中文字后搜索网页。
- [按程序设置](per-app.md)：程序专用手势、排除程序和全屏行为。

## 发送快捷键与编写脚本

- [按键序列语法](key-sequences.md)：可直接复制的快捷键和完整键名表。
