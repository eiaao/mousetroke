# 动作库

预置动作按“想做什么”命名，例如关闭标签页、窗口居中。Mousetroke 只保存预置 ID 和参数，运行时选用 Windows 或 Mac 的实现。浏览器和编辑类快捷键仍需接收按键的程序支持。

## 选择动作

1. 新建或选中手势，在“执行”区域点击“选择动作”，已有动作则点“更换”。
2. 搜索名称、说明、别名或快捷键写法，例如 Windows 的 `ctrl+w`、Mac 的 `cmd+w`／`⌘w`。搜索会跨越所有分类。没有搜索词时，可按“常用”“浏览器”“编辑”“文字”“窗口”“桌面与系统”“媒体”“打开”“Mousetroke”浏览。
3. 点击结果。带参数的动作会展开表单：填写文字、选择日期格式或搜索服务、输入网址，或选择文件、文件夹、程序，再点“选用此动作”。当前平台不可用的动作灰显，并说明平台限制或第二期状态。
4. 到设置窗口以外试用手势。手势名称为空时会随所选动作自动填写。弹出菜单中的菜单项也使用同一个选择器。

打开选择器后焦点位于搜索框。上下键在可用结果中移动，回车选中；Esc 先收起参数表单，再关闭选择器。多行文字框中用 Ctrl+Enter 或 Command+Enter 确认表单。

“转为高级动作”把预置动作替换成当前平台可编辑的按键、窗口操作、网址、程序、命令或系统功能键。确认后是单向转换，结果不再跟随预置动作的平台或语言默认值。原生布局、电源、字面文字、日期时间、纯文本复制、暂停与设置动作继续保留为预置动作，卡片会简短说明无法转换的原因。列表末尾的“高级”分组保留发送按键、运行命令、Lua 和弹出菜单；已有编辑器的用法见[高级动作说明](actions.md)。

## 文字、窗口与电源

- “输入一段文字”原样输出文字，包括空格、换行、中文、emoji 和 `^+#{ENTER}` 这样的语法字符。默认“粘贴”会短暂使用剪贴板，稍候恢复先前的**文本**；图片、HTML、文件列表等格式不会恢复。“逐字输入”通过 Unicode 输入，不使用剪贴板。两种方式都向当前接收键盘输入的程序输出。
- “插入日期时间”使用系统本地时间，按选择的方式输出。可选 ISO 日期、中文日期、美式日期、时间、日期加时间；自定义模式支持 `YYYY`、`MM`、`DD`、`HH`、`mm`、`ss`，区分大小写。其他字符原样输出，单引号包围字面文本，`''` 输出一个单引号。例如 `YYYY-MM-DD HH:mm:ss` 输出完整时间；未闭合的单引号会被拒绝。
- “复制选中文字的纯文本”发送 Ctrl+C／Command+C，最多等待 500 毫秒检测剪贴板版本变化，再仅保留复制内容的文本。复制未完成或没有文本时提示失败，保留剪贴板内容。使用前选中文字，并保持该程序获得焦点。
- 布局动作与其他窗口操作使用同一个手势目标，遵循“偏好设置 → 手势作用于”。Windows 使用原生窗口定位，Mac 使用辅助功能和屏幕可用区域。程序的最小尺寸或窗口限制可能阻止精确半屏布局；Mac 需先退出原生全屏。“移到下一个显示器”按稳定顺序循环，保持相对位置及最大化状态；只有一块屏幕时不移动。
- “关闭显示器”后可通过输入唤醒显示器。“睡眠”请求普通系统睡眠，可能被账户权限或系统策略拒绝。原生动作失败时记一行日志，并显示简短屏幕提示。“暂停／恢复手势”与托盘、热键使用同一暂停状态，暂停后可用托盘或热键恢复。“打开设置”使用平时的设置窗口。
