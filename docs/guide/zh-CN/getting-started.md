# 安装与首次使用

## 安装并打开

Windows 用户从[最新版本](https://github.com/eiaao/mousetroke/releases/latest)下载 `mousetroke.exe`。这是便携版程序：放到准备长期保留的位置，双击即可运行。可将下载文件的 SHA-256 与该版本的 `SHA256SUMS.txt` 对照。

支持 Windows 10 1809 及以上、Windows 11，均为 64 位。设置窗口需要 Microsoft Edge WebView2，Windows 11 已内置。程序暂未做代码签名；首次启动若被 SmartScreen 拦截，确认来自官方发布页后，选择“更多信息 → 仍要运行”。

Mac 用户下载 `Mousetroke.dmg`，打开后将 **Mousetroke** 拖到“应用程序”。通用应用支持 macOS 11 及以上的 Apple 芯片和 Intel 机型。如果直接从 DMG 打开，会提供**移到“应用程序”**并重新打开已安装副本。

Mac 测试版采用自签名，尚未公证。首次打开被拦截时，到“系统设置 → 隐私与安全性 → 仍要打开”；较旧系统可用“右键 → 打开”。引导中点“授权…”，在“辅助功能”中开启 Mousetroke，等待“准备就绪，可以使用手势了”。不需要屏幕录制权限。如果系统仍无法监听，引导会按需显示“输入监控”，出现提示时再开启。

## 打开设置并完成引导

Windows 通知区域图标：左键打开设置；右键菜单包含“设置…”、“暂停手势”／“恢复手势”、“开机自启动”、“打开配置文件夹”和“退出”。发现更新时还可能显示新版本入口。

Mac 使用菜单栏图标打开“设置…”、暂停／恢复或“退出”。权限和更新入口会按当前状态显示。“关于 Mousetroke”打开关于页面。

首次引导介绍画手势、屏幕边角、排除程序和暂停。完成前检查勾选的程序：这些程序中会禁用手势。以后可以通过“关于 → 查看使用引导”重看。设置修改会自动保存；尚未录完的笔画需要完成录制后才能保存。

## 画出第一个手势

1. 在浏览器中打开一个有后退历史的页面。
2. 按住右键，向左画 `←`，松开右键，页面后退。
3. 在临时标签页试试 `↓→` 关闭标签页，或画 `↙` 最小化窗口。

内置动作遵循平台习惯，例如浏览器快捷键在 Windows 使用 Ctrl，在 Mac 按需使用 Command。完整列表在“所有程序 → 鼠标手势”，每一条都可编辑。部分内置手势处于停用状态，尤其是 Mac 尚不支持的动作。

普通右键单击仍会弹出程序菜单。按住不动达到一定时间，也会放行按钮，允许正常单击或拖拽；时间可在[偏好设置](gestures.md#识别与外观)中调整。

## 新建手势

打开“所有程序 → 鼠标手势 → 新建手势”，选择触发按钮并录制图形。点击“选择动作”，搜索或浏览[动作库](action-library.md)，选择预置动作并填写参数。手势完整有效后自动保存，到设置窗口以外试用即可。录制方法详见[鼠标手势](gestures.md)。

## 暂停

Windows 托盘选择“暂停手势”，之后选“恢复手势”。Mac 的菜单项始终叫“暂停手势”，勾选表示手动暂停，再点一次恢复。默认暂停／恢复快捷键：Windows 为 **Win+Esc**，Mac 为 **Control+Option+Command+P**。可在“偏好设置 → 暂停 / 恢复快捷键”修改。

前台窗口被识别为全屏时，全屏游戏、视频和演示会自动暂停手势。排除程序见[按程序设置](per-app.md)；手势始终不触发时见[常见问题](troubleshooting.md)。
