# 屏幕边角

## 试用默认动作

“所有程序 → 触发角”中的每个边角绑定都可以修改。

| 触发方式 | Windows 默认动作 | Mac 默认动作 |
|---|---|---|
| 推到左下角 | 开始菜单 | Spotlight |
| 推到右下角 | 显示桌面 | 显示桌面（F11） |
| 推到左上角 | 切换程序（Alt+Tab） | 调度中心（Control+↑） |
| 推到右上角 | 任务视图（Win+Tab） | 绑定初始停用 |
| 贴着上边滚轮 | 音量增减 | 音量增减 |
| 上边点击中键 | 静音 | 静音 |
| 上边点击右键 | 播放／暂停 | 播放／暂停 |
| 贴着下边滚轮 | 亮度增减 | 亮度绑定初始停用 |
| 贴右边上下摩擦两次 | 已绑定任务管理器，需先开启“识别出来就立即执行” | 活动监视器 |

角落动作无需按键，直接把鼠标推到角落。边缘滚轮和点击需要鼠标贴着相应边缘。摩擦是沿着边缘按录制方向来回移动，不是滚动滚轮。

## 配置边角触发

1. 在“所有程序”或指定程序中，选择“触发角 → 新建触发角”。
2. “怎么开始”选“屏幕边角”，在示意图中选一条边或一个角。
3. 角落动作可将“然后”留空；也可用“+ 添加一步”加入向上／向下滚轮、鼠标点击或沿边缘的轨迹。
4. 选择[动作](actions.md)。调音量可选“媒体与系统 → 音量 +”或“音量 −”。连续滚轮和不按按钮的摩擦应开启“识别出来就立即执行”。

摩擦动作添加“画轨迹”，录下交替方向。例如贴右边画 `↑↓↑↓`。建议先用 Lua 提示文字试用，再绑定影响较大的动作。

## 亮度与平台差异

Windows 的“亮度 +”／“亮度 −”首先选择鼠标所在屏幕，每次调整 10 个百分点并显示结果。先尝试 DDC/CI，再回退 WMI。外接显示器需要支持并开启 DDC/CI；WMI 回退取第一个 WMI 亮度设备，通常为内置屏幕，并未按鼠标所在显示器匹配。两条路径均失败才会出现不支持提示。小步调节见 [Lua 示例](lua-examples.md#调整鼠标所在屏幕亮度)。

Mac 的“媒体与系统 → 亮度 +”／“亮度 −”发送系统亮度键事件，面向内置屏幕，不会根据鼠标位置选择屏幕，也不支持外接显示器 DDC/CI。默认下边缘亮度绑定处于停用状态。Mac 的 Lua 亮度 API 同样尚未实现。

Mac 系统触发角与 Mousetroke 角落重叠时，设置会提醒。修改其中一方的绑定，避免同时触发。F11、Control+↑ 等系统快捷键是否生效，也取决于 macOS 快捷键设置。

程序排除规则和全屏检测同样会抑制边角动作。只在某个程序中失效时，见[按程序设置](per-app.md)。
