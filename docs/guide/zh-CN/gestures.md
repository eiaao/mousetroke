# 鼠标手势

## 录制方向轨迹

打开“所有程序 → 鼠标手势 → 新建手势”。输入名称，在“怎么开始”选择“按住右键”、“按住中键”、“按住侧键 1”或“按住侧键 2”。侧键 1、2 分别对应 X1、X2。

在绘图区按住左键或右键画一下，松开完成录制。绘图区接受的按钮与刚才选择的实际触发按钮相互独立。直线段会录成 `←`、`↓→` 这样的方向轨迹；重画即可覆盖。选好[动作](actions.md)后，到设置窗口以外用实际触发按钮试用。

## 录制形状

C、O、S 这样的曲线属于形状手势。录制器会自动区分轨迹和形状。判断不合适时，画完点击“改用形状”或“改用轨迹”，也可以从“+ 添加一步 → 画形状”开始。

按平时习惯将同一形状画 2–3 次，保持相同起点和方向，每次松开加入一个样本。至少有一个有效样本才能保存；最多保留五个，可单独删除。注意样本一致度和形状冲突提示。形状手势在松开触发按钮时执行。

## 添加鼠标键、滚轮或键盘键

在“然后”下面点击“+ 添加一步”。可以添加“画轨迹”、“画形状”、“点击鼠标键”中的按钮、“滚动滚轮”中的“向上”／“向下”，或“按住键盘键”。最后一个选项会记录随后按下的键盘键。

例如，按住右键后再点左键，或者加上向上滚轮，在保持触发按钮的同时重复调音量。步骤有顺序，使用时按显示顺序操作，并始终保持触发按钮按下。每步的 × 可以移除该步。

方向手势可勾选“识别出来就立即执行”，不等松开按钮，适合需要反复触发的滚轮动作。形状始终等松开再执行。“画的时候不显示手势名”只隐藏这一条手势的名称。

## 识别与外观

“偏好设置 → 识别”提供：

| 设置 | 作用 |
|---|---|
| 按住多久不动算普通点击 | 默认 500 ms，滑块范围 150–1500 ms。按住不移动达到该时间后，放行普通单击／拖拽。 |
| 笔画灵敏度 | 默认 30 px，滑块范围 10–80 px。越小越容易识别短笔画，也越容易误触。 |
| 手势作用于 | 选择“鼠标下的窗口”（默认）或“当前活动窗口”。 |

“外观”中有“显示轨迹”、“轨迹粗细”、“轨迹颜色”、“识别成功时”、“完成后淡出”、“画的时候显示手势名”和“手势名颜色”。这里没有形状识别阈值滑块。

## 查找、复制和停用

Windows 按 **Ctrl+F**，Mac 按 **⌘+F**，可按名称、画法或动作搜索当前列表。通过“鼠标手势”／“触发角”和按钮／位置筛选缩小范围；“已停用”筛选显示关闭的条目。

选择手势后点“复制一份”（Ctrl+D／⌘+D）。给副本换个画法：同一作用域内完全相同的画法会冲突，不要依赖列表顺序选择动作。编辑器的“启用”／“已停用”开关，或选中列表行后按空格，都能停用而不删除。已停用绑定自身不再占用触发按钮。
