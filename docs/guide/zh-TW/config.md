# 設定、備份與更新

## 檔案位置

| 檔案 | Windows | Mac |
|---|---|---|
| 設定 | `%APPDATA%\mousetroke\config.json` | `~/Library/Application Support/mousetroke/config.json` |
| 執行日誌 | `%APPDATA%\mousetroke\mousetroke.log` | `~/Library/Logs/mousetroke/mousetroke.log` |

日誌超過 1 MB 後輪替為 `mousetroke.log.old`。「關於 → 檔案位置」顯示實際路徑，「開啟資料夾」開啟設定目錄，「開啟日誌」開啟執行日誌。「匯入與匯出」中，Windows 的「在資源管理器中顯示」或 Mac 的「在 Finder 中顯示」可定位設定。

## 全螢幕暫停設定

`settings.pause_on_fullscreen` 為布林值，預設為 `true`。程式作用域的 `fullscreen_policy` 可取 `"inherit"`（預設，跟隨全域）、`"allow"`（全螢幕保持啟用）或 `"pause"`（全螢幕暫停）。這兩個設定同時作用於滑鼠手勢和觸發角，舊設定缺欄位時保持原來的全螢幕暫停行為。

`settings.scribble_bomb` 為布林值，預設為 `true`：手勢超過 50 段被取消時，在游標處丟一顆炸彈（30 秒內最多一次，前景為全螢幕程式時不丟）。

## 匯出、匯入與還原

「匯入與匯出 → Mousetroke 設定檔案」中點「匯出…」，儲存 JSON 備份。「從檔案匯入…」讀取 Mousetroke 設定 JSON，替換包含偏好設定的整份目前設定，不會將檔案中的綁定合併進來。這個流程沒有原生設定合併選項。設定視窗仍開啟時，可用 Windows 的 Ctrl+Z 或 Mac 的 ⌘+Z 復原匯入。

手改 JSON 前先匯出備份。直接還原檔案時，結束引擎並關閉設定，用備份替換 `config.json`，再開啟 Mousetroke。還原期間保持設定關閉，避免自動儲存覆蓋剛還原的檔案。

## 即時載入與重設

引擎根據檔案時間戳記偵測設定變更。Windows 約每秒檢查一次，Mac 在每兩秒排程的維護分支中檢查。畫手勢過程中收到的修改，會在手勢擷取結束後套用。JSON 無效時保留此前生效的設定，並在日誌記錄錯誤。

目前設定介面沒有還原預設值的按鈕。需要重新使用內建設定時，結束 Mousetroke 並關閉設定，備份後移除或重新命名 `config.json`，再開啟。檔案不存在才會從統一預設設定初始化，預置動作按目前平台執行。損毀的檔案會原樣保留：啟動時僅在記憶體使用預設值，設定程式拒絕覆蓋它。還原或重新命名該檔案後才能繼續儲存。

現有版本 1 的設定仍可讀取，啟動時不會自動改寫。儲存含預置動作的設定時版本升為 2；首次用版本 2 覆蓋版本 1 檔案之前，會在旁邊建立 `config.v1.bak.json`，保留原始位元組，現有備份不會被覆蓋。不認識的動作型別或預置 ID 在儲存時保留，執行時跳過。

## 更新

「偏好設定 → 自動檢查更新」預設開啟，每天向 GitHub 檢查一次。關閉即可停止自動檢查。也可在「關於 → 檢查更新」手動檢查，用「更新內容」檢視說明。選單中的新版本入口同樣會開啟關於頁面。

Windows 點「立即更新」後下載程式，驗證 SHA-256，替換並重啟。也可用「開啟下載頁」手動安裝。

Mac 點「立即更新」後下載 DMG，驗證 SHA-256、應用程式身分、版本和簽署要求，替換應用程式並重啟。關閉後舊副本進入垃圾桶，替換或重啟交接失敗會還原舊副本。目錄不可寫或更新失敗時可用「手動下載」。在應用程式內更新避免再次觸發瀏覽器下載的隔離提示，並保留權限對應的安裝身分。重新用瀏覽器下載可能需要再點「仍要打開」。

## 解除安裝

Windows：在偏好設定關閉「開機時自動啟用手勢」，從系統匣「結束」，關閉設定，再刪除程式檔案；不再需要設定和日誌時也可刪除 `%APPDATA%\mousetroke`。

Mac：從選單列「結束」，關閉設定，刪除 `Mousetroke.app`。需要清理資料時，刪除 `~/Library/Application Support/mousetroke` 和 `~/Library/Logs/mousetroke`，並從系統設定登入項中移除 Mousetroke。可能重新安裝時請保留匯出備份。

設定出現錯誤或找不到日誌時，見[常見問題](troubleshooting.md)。
