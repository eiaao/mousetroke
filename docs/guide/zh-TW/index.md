# 使用指南

Mousetroke 可以在按住滑鼠鍵畫出手勢、推到螢幕角落或操作螢幕邊緣時執行動作。先用內建手勢，再按自己的習慣修改動作；大多數操作不需要寫程式。

本指南涵蓋 Windows 和 macOS。Mac 版仍處於測試階段，影響動作或指令碼使用的平台差異會在相關章節說明。下文介面名稱採用繁體中文介面的實際文字。

## 開始使用手勢

- [安裝與首次使用](getting-started.md)：安裝、首次引導、預設手勢和暫停。
- [滑鼠手勢](gestures.md)：錄製軌跡和形狀，新增滑鼠鍵或鍵盤鍵，搜尋與編輯手勢。
- [手勢庫](gesture-library.md)：同一個手勢在多個程式裡執行不同動作，整理並匯入現有手勢。
- [螢幕邊角](screen-edges.md)：音量、亮度、邊緣點擊與摩擦。
- [動作庫](action-library.md)：搜尋預置動作、填寫參數、檢視平台支援狀況。
- [動作](actions.md)：選擇手勢執行的內容，包括選取文字後搜尋網頁。
- [按程式設定](per-app.md)：程式專用手勢、排除程式和全螢幕行為。

## 傳送快速鍵與撰寫指令碼

- [按鍵序列語法](key-sequences.md)：可直接複製的快速鍵和完整鍵名表。
- [Lua 入門](lua-basics.md)：第一個指令碼、入口參數和除錯方法。
- [Lua API](lua-api.md)：`ms` 表的全部函式、用法和平台說明。
- [Lua 實用範例](lua-examples.md)：輸出文字、操作剪貼簿、搜尋、控制視窗等。

## 設定與疑難排解

- [設定、備份與更新](config.md)：檔案位置、還原、即時載入、更新和解除安裝。
- [常見問題](troubleshooting.md)：手勢不觸發、權限、文字輸入和日誌。

第一次使用可以從[畫出第一個手勢](getting-started.md#畫出第一個手勢)開始。如果想用滑鼠手勢輸出文字，在[動作庫](action-library.md)選擇「輸入一段文字」。
