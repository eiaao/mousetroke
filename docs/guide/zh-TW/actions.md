# 動作

新增或選取手勢，在「執行」區域點選「選擇動作」。搜尋想做的事或按分類瀏覽，填寫所需參數，再點「選用」。[動作庫](action-library.md)列出全部預置動作及 Windows／Mac 支援狀況，包括輸入文字、日期時間、視窗配置與電源動作。

現有動作可點「更換」。能展開為現有高階動作的預置動作還提供「轉為高階動作」；原生預置會顯示無法轉換的原因。選擇器頂部的「傳送快速鍵…」可以就地錄製組合鍵；「高階」分類保留執行命令、Lua 和彈出選單，下方的高階動作編輯器也仍可透過「更改動作型別」使用。

## 傳送按鍵

在選擇器頂部點「傳送快速鍵…」，錄製或輸入組合鍵後點「選用」，就會建立這類動作；之後在編輯器裡修改。輸入[按鍵序列](key-sequences.md)，或點選「錄製」，按下快速鍵後點「完成」。例如 Windows 複製是 `^c`，Mac 複製是 `#c`。「語法說明」可開啟語法指南。

「先啟用滑鼠下的視窗再傳送」會先啟用手勢目標，否則按鍵由目前接收鍵盤輸入的程式接收。目標也受「偏好設定 → 手勢作用於」影響。需要原樣輸入文字時，在[動作庫](action-library.md)選擇「輸入一段文字」，也可透過 Lua 使用[文字優先模式](key-sequences.md#文字與轉義)。

## 視窗操作

選擇一項，作用於手勢目標：

| 操作 | 行為 |
|---|---|
| 最小化 | 最小化視窗。 |
| 最大化 / 還原 | 切換最大化與還原大小。 |
| 關閉 | 請求視窗關閉。 |
| 置頂 / 取消置頂 | Windows 切換置頂；Mac 尚不支援，編輯器中不可選。 |

Mac 視窗操作依賴輔助功能。「最大化 / 還原」點選程式的縮放按鈕，視窗大小遵循該程式行為，不請求原生全螢幕，已最小化視窗會跳過。不同程式開放的視窗操作可能不同。

## 開啟程式

Windows 的「程式」填寫可執行檔，可點「瀏覽…」選擇。Mac 可填寫 `com.apple.Safari` 這樣的 bundle id、`.app` 路徑或可執行檔路徑。「參數」可選。Mac 參數按引號規則拆分，命令列程式請用完整路徑。

「已經在執行時」可選「切換到它」或「再開啟一個」。Windows 還有「以管理員身份執行」。Mac 不支援提升權限或按視窗篩選的啟動選項。目前動作編輯器沒有視窗類別名稱、標題或正規表示式欄位。

## 開啟網址

填寫「網址」，視需要填寫「瀏覽器」；留空使用預設瀏覽器。Windows 可指定瀏覽器可執行檔，Mac 可指定瀏覽器 bundle id 或應用程式路徑。「插入」按鈕可插入選取文字、剪貼簿、程式名、程序識別碼或視窗標題變數。

選取文字後搜尋網頁，可將網址設為：

```text
https://www.google.com/search?q=%MS_SELECTED_TEXT%
```

在程式中選取文字，再畫手勢。選取文字會經過 URL 編碼後代入範本；即使選取範圍是網址，搜尋和翻譯範本也繼續使用指定服務。只有「網址」欄位單獨填寫 `%MS_SELECTED_TEXT%` 時，才會直接開啟以 `http://`、`https://` 或 `www.` 開頭的選取的網址，其中 `www.` 會自動補 `https://`。

## 執行命令

在文字方塊填寫命令，「插入」可加入變數。Windows 使用隱藏的 `cmd.exe /C`，Mac 使用 `/bin/zsh -c`。這是 Shell 語法，參數需要正確加引號。變數替換不會做 Shell 轉義，不要把不可信的選取文字直接接到命令中。

例如 Windows 開啟工作管理員：

```text
taskmgr.exe
```

Mac 可以改用「開啟程式」，填寫 `com.apple.ActivityMonitor`。

## 媒體與系統

編輯器提供「播放 / 暫停」、「下一曲」、「上一曲」、「音量 +」、「音量 −」、「靜音」、「亮度 +」和「亮度 −」。

Windows 亮度每次增減 10 個百分點，使用 DDC/CI，失敗時改用 WMI。Mac 亮度動作傳送適用於內建螢幕的系統亮度鍵，不支援外接顯示器 DDC/CI。Mac 可以使用這些系統動作，但 Lua 亮度函式尚不支援。詳見[螢幕邊角](screen-edges.md)。

## 彈出選單

點選「+ 新增選單項」，輸入「選單項名稱」，再為每項選擇動作。使用「上移」、「下移」和「刪除選單項」整理順序。選單顯示在手勢位置。編輯器不提供欄數欄位，選單項目內也不再提供選單型別。Mac 支援單欄，多欄設定會顯示不支援的提示。

## Lua 指令碼

貼上定義了 `ms_action` 的完整指令碼。編輯器提供 [Lua 入門](lua-basics.md)、[API 參考](lua-api.md)和[範例](lua-examples.md)連結。文字方塊中按 Tab 會插入兩個空格。

## 變數

下列預留位置用於「開啟網址」的「網址」、「執行命令」，以及「開啟程式」的「程式」和「參數」。傳送按鍵字串、Lua 原始碼、選單名稱和「瀏覽器」欄位不會展開這些變數。

| 變數 | 內容 |
|---|---|
| `%MS_SELECTED_TEXT%` | 動作需要時擷取的選取文字，無法取得時為空。 |
| `%MS_CLIPBOARD_TEXT%` | 視需要讀取的目前剪貼簿文字。 |
| `%MS_PID%` | 目標程序識別碼。 |
| `%MS_EXE%` | 目標程式身分：Windows 路徑；Mac bundle id 或可執行檔路徑。 |
| `%MS_APP_NAME%` | 程式身分的檔名部分，Mac 上可能就是 bundle id。 |
| `%MS_WID%` | 十進位文字形式的平台的視窗識別碼。 |
| `%MS_WIN_NAME%` | 目標視窗標題，Mac 視需要透過輔助功能讀取。 |
| `%MS_MOUSE_X%`、`%MS_MOUSE_Y%` | 手勢開始時的螢幕座標。 |
| `%MS_MOUSE_Y_FLIP%` | 虛擬螢幕底部座標減去手勢開始時的 Y 座標。 |
| `%MS_TARGET_MODE%` | 根據目標設定取 `UnderCursor` 或 `Focused`。 |

沒有目標時部分變數可能不存在，未定義的預留位置原樣保留。網址範本只有選取文字會自動 URL 編碼，其他變數直接插入。Lua 請使用[入口參數](lua-basics.md#入口參數)和 `ms` 函式，不使用預留位置替換。
