# 滑鼠手勢

## 錄製方向軌跡

開啟「所有程式 → 滑鼠手勢 → 新增手勢」。輸入名稱，在「怎麼開始」選擇「按住右鍵」、「按住中鍵」、「按住側鍵 1」或「按住側鍵 2」。側鍵 1、2 分別對應 X1、X2。

在繪圖區按住左鍵或右鍵畫一下，鬆開完成錄製。繪圖區接受的按鈕與剛才選擇的實際觸發按鈕相互獨立。直線段會錄成 `←`、`↓→` 這樣的方向軌跡；重畫即可覆蓋。點選「選擇動作」，搜尋或瀏覽[動作庫](action-library.md)，選擇預置動作並填寫所需參數。自訂快速鍵用選擇器頂部的「傳送快速鍵…」錄製；命令、Lua 或選單可從「高階」分類進入，詳見[動作說明](actions.md)。之後到設定視窗以外用實際觸發按鈕試用。

## 錄製形狀

C、O、S 這樣的曲線屬於形狀手勢。錄製工具會自動區分軌跡和形狀。判斷不合適時，畫完點選「改用形狀」或「改用軌跡」，也可以從「+ 新增一步 → 畫形狀」開始。

按平時習慣將同一形狀畫 2–3 次，保持相同起點和方向，每次鬆開加入一個樣本。至少有一個有效樣本才能儲存；最多保留五個，可單獨刪除。注意樣本一致度和形狀衝突提示。形狀手勢在鬆開觸發按鈕時執行。

## 新增滑鼠鍵、滾輪或鍵盤鍵

在「然後」下面點選「+ 新增一步」。可以新增「畫軌跡」、「畫形狀」、「點選滑鼠鍵」中的按鈕、「轉動滾輪」中的「向上」／「向下」，或「按住鍵盤鍵」。最後一個選項會記錄隨後按下的鍵盤鍵。

例如，按住右鍵後再點左鍵，或者加上向上滾輪，在持續按住觸發按鈕的同時重複調音量。步驟有順序，使用時按顯示順序操作，並始終讓觸發按鈕處於按下狀態。每步的 × 可以移除該步。

方向手勢可勾選「識別出來就立即執行」，不等鬆開按鈕，適合需要反覆觸發的滾輪動作。形狀始終等鬆開再執行。「畫的時候不顯示手勢名」只隱藏這個手勢的名稱。

## 識別與外觀

「偏好設定 → 識別」提供：

| 設定 | 作用 |
|---|---|
| 按住後多久不動視為一般點擊 | 預設 500 ms，滑桿範圍 150–1500 ms。按住不移動達到該時間後，讓一般點擊或拖曳照常運作。 |
| 筆畫靈敏度 | 預設 30 px，滑桿範圍 10–80 px。越小越容易識別短筆畫，也越容易誤觸。 |
| 手勢作用於 | 選擇「滑鼠下的視窗」（預設）或「目前活動視窗」。 |

「外觀」中有「介面主題」（跟隨系統、淺色、深色，切換後設定視窗立即生效）、「顯示軌跡」、「軌跡粗細」、「軌跡顏色」、「識別成功時」、「完成後淡出」、「畫的時候顯示手勢名」、「提示文字大小」（16–96 px，預設 24 px，高解析度螢幕可調大）、「手勢名顏色」和「亂畫時丟炸彈（彩蛋）」。最後一項預設開啟：手勢畫得太長被取消時，會在游標處丟一顆炸彈，30 秒內最多一次，全螢幕程式裡不會出現。這裡沒有形狀識別門檻滑桿。

## 尋找、複製和停用

Windows 按 **Ctrl+F**，Mac 按 **⌘+F**，可按名稱、畫法或動作搜尋目前清單。透過「滑鼠手勢」／「觸發角」和按鈕／位置篩選縮小範圍；「已停用」篩選顯示停用的項目。

在清單中的手勢上按一下右鍵，選擇「複製一份」；也可選取後按 Ctrl+D／⌘+D。右鍵選單中的「複製到／移動到…」可把手勢放到其他程式，見[按程式設定](per-app.md)。給副本換個畫法：同一作用域內完全相同的畫法會衝突，不要依賴清單順序選擇動作。編輯器的「啟用」／「已停用」開關，或選取清單項目後按空格，都能停用而不刪除。已停用綁定自身不再占用觸發按鈕。
