# 動作庫

預置動作按「想做什麼」命名，例如關閉分頁、視窗置中。Mousetroke 只儲存預置 ID 和參數，執行時選用 Windows 或 Mac 的實作。瀏覽器和編輯類快速鍵仍需接收按鍵的程式支援。

## 選擇動作

1. 新增或選取手勢，在「執行」區域點選「選擇動作」，現有動作則點「更換」。
2. 搜尋名稱、說明、別名或快速鍵寫法，例如 Windows 的 `ctrl+w`、Mac 的 `cmd+w`／`⌘w`。搜尋會跨越所有分類。沒有搜尋詞時，可按「常用」「瀏覽器」「編輯」「文字」「視窗」「桌面與系統」「媒體」「開啟」「Mousetroke」瀏覽。
3. 點選結果。帶參數的動作會展開表單：填寫文字、選擇日期格式或搜尋服務、輸入網址，或選擇檔案、資料夾、程式，再點「選用」。目前平台不可用的動作會以灰色顯示，並說明平台限制。
4. 到設定視窗以外試用手勢。手勢名稱為空時會隨所選動作自動填寫。彈出選單中的選單項目也使用同一個選擇器。

開啟選擇器後焦點位於搜尋欄。上下鍵在可用結果中移動，按 Enter 選取；Esc 先收起參數表單，再關閉選擇器。多行文字方塊中用 Ctrl+Enter 或 Command+Enter 確認表單。

「轉為高階動作」把預置動作替換成目前平台可編輯的按鍵、視窗操作、網址、程式、命令或系統功能鍵。確認後是單向轉換，結果不再跟隨預置動作的平台或語言預設值。原生視窗配置、電源、字面文字、日期時間、純文字複製、暫停與設定動作繼續保留為預置動作，卡片會簡要說明無法轉換的原因。選擇器頂部的「傳送快速鍵…」可以就地錄製組合鍵；清單末尾的「高階」分組保留執行命令、Lua 和彈出選單；現有編輯器的用法見[高階動作說明](actions.md)。

## 文字、視窗與電源

- 「輸入一段文字」原樣輸出文字，包括空格、換行、中文、emoji 和 `^+#{ENTER}` 這樣的語法字元。預設「貼上」會短暫使用剪貼簿，稍後還原先前的**文字**；剪貼簿含有圖片、HTML、檔案清單等非文字資料，或無法檢查內容時，會改為直接輸入，保留剪貼簿。`paste_delay_ms` 僅在 `paste` 方式下顯示，介面允許 50–5000 毫秒，預設 150 毫秒。「逐字輸入」透過 Unicode 輸入，不使用剪貼簿。兩種方式都向目前接收鍵盤輸入的程式輸出。
- 「插入日期時間」使用系統的本機時間，依選擇的格式輸出。可選 ISO 日期、中文日期、美式日期、時間、日期加時間；自訂模式支援 `YYYY`、`MM`、`DD`、`HH`、`mm`、`ss`，區分大小寫。其他字元原樣輸出，單引號包圍字面文字，`''` 輸出一個單引號。例如 `YYYY-MM-DD HH:mm:ss` 輸出完整時間；未成對的單引號會被拒絕。
- 「複製選取文字的純文字」傳送 Ctrl+C／Command+C，最多等待 500 毫秒偵測剪貼簿版本變化，再僅保留複製內容的文字。複製未完成或沒有文字時提示失敗，保留剪貼簿內容。使用前選取文字，並保持該程式獲得焦點。
- 視窗配置動作與其他視窗操作使用同一個手勢目標，遵循「偏好設定 → 手勢作用於」。Windows 使用原生視窗定位，Mac 使用輔助功能和螢幕可用區域。程式的最小尺寸或視窗限制可能阻止精確半螢幕配置；Mac 需先結束原生全螢幕。「移到下一個顯示器」依固定順序循環，保持相對位置及最大化狀態；只有一塊螢幕時不移動。
- 「關閉顯示器」後可透過輸入喚醒顯示器。「睡眠」要求系統進入一般睡眠狀態，可能被帳戶權限或系統原則拒絕。原生動作失敗時記一行日誌，並顯示簡短螢幕提示。「暫停 / 恢復手勢」與系統匣、快速鍵使用同一暫停狀態，暫停後可用系統匣或快速鍵恢復。「開啟設定」使用平時的設定視窗。
