# 按鍵序列語法

## 從一個快速鍵開始

在「傳送按鍵」中貼上 `^c`，Windows 會傳送 Ctrl+C；Mac 複製使用 `#c`，即 Command+C。也可以點選「錄製」，按下組合鍵後點「完成」。Lua 的 `ms.keys(sequence)` 使用同一套語法。

一般字元表示美式鍵盤位置。`abc` 依次按 A、B、C，寫成大寫 `ABC` 也不會自動按 Shift。需要 Shift+A 時用 `+a`。Unicode 或固定文字見[文字與轉義](#文字與轉義)及[剪貼簿範例](lua-examples.md)。

## 修飾符號與分組

| 字首 | Windows | Mac |
|---|---|---|
| `^` | Ctrl | Control ⌃ |
| `%` | Alt | Option ⌥ |
| `+` | Shift | Shift ⇧ |
| `#` | Win | Command ⌘ |

字首作用於下一個鍵或括號分組。`^+t` 傳送 Ctrl+Shift+T；`^(ac)` 對 A 和 C 都加 Ctrl；`^ac` 只有 A 帶 Ctrl。分組可以巢狀，請配對括號。分組修飾符號會附加到每個按鍵動作，不要依賴它在兩個鍵之間始終保持按下。末尾單獨一個修飾符號不會傳送按鍵；需要修飾鍵本身時，例如使用 `{CTRL}`。

Lua `ms.is_keys_pressed` 在兩平台查詢所有鍵和修飾鍵的聯集：`^ac` 要求 Control、A、C 同時按下。字首接受任意一側，明確指定的 `{LCTRL}`／`{RCTRL}` 名稱保留側別。重複次數忽略；延遲、文字、滑鼠或滾輪步驟使結果為 false。此介面不識別過去按下的順序。

## 鍵名、重複與延遲

`{ENTER}` 表示 Enter，鍵名不區分大小寫。`{LEFT 3}` 連按三次左方向鍵。正整數表示重複次數，0 或負數會以一次處理。`{SLEEP 100}` 等待 100 毫秒，必須提供非負整數。鍵名與參數之間用空格分隔。

例如 Windows 的 `^c{SLEEP 100}^v` 會複製、稍等、貼上；Mac 對應 `#c{SLEEP 100}#v`。

下表列出解析器接受的名稱，包括別名和全部編號功能鍵／小鍵盤鍵。單一 ASCII 字母、數字或支援的美式標點也可以放入花括號，如 `{a}`、`{+}`。

| 鍵名 | 意義 |
|---|---|
| `{ENTER}`, `{RETURN}` | Enter |
| `{ESC}` | 結束 |
| `{TAB}` | 定位鍵 |
| `{BACKSPACE}` | 退格鍵 |
| `{SPACE}` | 空格 |
| `{CAPSLOCK}` | 大寫鎖定 |
| `{INSERT}`, `{INS}` | 插入（僅 Windows） |
| `{DELETE}`, `{DEL}` | 刪除／向前刪除 |
| `{HOME}`, `{END}` | 開頭／末尾 |
| `{PGUP}`, `{PGDN}` | 上一頁／下一頁 |
| `{UP}`, `{DOWN}`, `{LEFT}`, `{RIGHT}` | 方向鍵 |
| `{PRTSC}` | 螢幕擷取（僅 Windows） |
| `{BREAK}` | 中斷（僅 Windows） |
| `{MEDIA_NEXT}`, `{MEDIA_PREV}`, `{MEDIA_STOP}`, `{MEDIA_PLAY}`, `{MEDIA_PLAY_PAUSE}` | 媒體鍵（按鍵序列中僅 Windows） |
| `{VOLUME_MUTE}`, `{VOLUME_DOWN}`, `{VOLUME_UP}` | 音量鍵（按鍵序列中僅 Windows） |
| `{CTRL}`, `{ALT}`, `{SHIFT}` | Control／Alt（Mac 為 Option）／Shift |
| `{LCTRL}`, `{RCTRL}`, `{LSHIFT}`, `{RSHIFT}`, `{LALT}`, `{RALT}` | 左右修飾鍵，Mac 的 Alt 為 Option |
| `{LWIN}`, `{WIN}`, `{RWIN}` | Windows 鍵，Mac 為 Command |
| `{F1}`, `{F2}`, `{F3}`, `{F4}`, `{F5}`, `{F6}`, `{F7}`, `{F8}`, `{F9}`, `{F10}`, `{F11}`, `{F12}`, `{F13}`, `{F14}`, `{F15}`, `{F16}`, `{F17}`, `{F18}`, `{F19}`, `{F20}`, `{F21}`, `{F22}`, `{F23}`, `{F24}` | 功能鍵，Mac 支援 F1–F20 |
| `{N0}`, `{N1}`, `{N2}`, `{N3}`, `{N4}`, `{N5}`, `{N6}`, `{N7}`, `{N8}`, `{N9}` | 小鍵盤數字 0–9 |
| `{MOUSE_LEFT}`, `{MOUSE_RIGHT}`, `{MOUSE_MIDDLE}`, `{MOUSE_X1}`, `{MOUSE_X2}` | 滑鼠點選（僅 Windows） |
| `{MOUSE_WHEEL}`, `{MOUSE_HWHEEL}` | 滾輪，例如 {MOUSE_WHEEL 120}、{MOUSE_HWHEEL -120}（僅 Windows） |
| `{SLEEP}` | 等待，例如 {SLEEP 100}，單位毫秒 |

## 滑鼠按鈕與滾輪

Windows 支援 `{MOUSE_LEFT}`、`{MOUSE_RIGHT}`、`{MOUSE_MIDDLE}`、`{MOUSE_X1}` 和 `{MOUSE_X2}` 點選。`{MOUSE_LEFT 2}` 點選兩次，不會移動滑鼠位置。

`{MOUSE_WHEEL 120}` 向上滾一格，`-120` 向下；`{MOUSE_HWHEEL 120}` 向右，`-120` 向左。參數是帶符號的滾輪位移，不是重複次數。這是模擬輸入的正負約定，與錄製手勢滾輪步驟的方向符號不同。

Mac 能解析這些記號，但執行按鍵時會跳過滑鼠與滾輪動作，不能透過 `ms.keys` 模擬 Mac 點選或滾動。

## 文字與轉義

文字優先模式只透過 Lua 的 `ms.keys(s, true)` 使用，「傳送按鍵」編輯器始終使用按鍵模式。一般字元會作為 Unicode 文字輸出，但 `^`、`%`、`+`、`#`、括號和左花括號仍會被解釋為語法。花括號中的單字元在文字優先模式下仍是按鍵動作。

在文字優先模式裡傳送快速鍵，要給鍵加花括號：`^{c}` 傳送 Ctrl+C，`#{c}` 傳送 Command+C。這個模式中的 `^c` 會輸出文字 `c`，丟棄修飾符號。也可以另用一般按鍵模式呼叫 `ms.keys("^c")`。

| 想輸入的字元 | 序列寫法 |
|---|---|
| `^` | `{^}` |
| `%` | `{%}` |
| `+` | `{+}` |
| `#` | `{#}` |
| `(` | `{(}` |
| `)` | `{)}` |
| `{` | `{{}` |
| `}` | `}`（不加括號） |

反斜線不是按鍵序列轉義符。Lua 一般引號字串中，一個反斜線要寫成 `"\\"`，也可用長括號字串。含語法符號的任意文字建議用[剪貼簿方法](lua-examples.md#貼上後還原剪貼簿文字)，避免兩層轉義。

## 常用快速鍵

是否生效取決於目標程式和系統的快速鍵設定。

| 用途 | Windows 序列 | Mac 序列 |
|---|---|---|
| 複製 | `^c` | `#c` |
| 貼上 | `^v` | `#v` |
| 剪下 | `^x` | `#x` |
| 全選 | `^a` | `#a` |
| 復原 | `^z` | `#z` |
| 新增分頁 | `^t` | `#t` |
| 關閉分頁 | `^w` | `#w` |
| 重新開啟已關閉的分頁 | `^+t` | `#+t` |
| 下一個分頁 | `^{TAB}` | `^{TAB}` |
| 上一個分頁 | `^+{TAB}` | `^+{TAB}` |
| 切換程式 | `%{TAB}` | `#{TAB}` |
| 上一個／下一個桌面 | `#^{LEFT}` / `#^{RIGHT}` | `^{LEFT}` / `^{RIGHT}` |
| 區域螢幕擷取 | `#+s` | `#+4` |
| 顯示桌面 | `#d` | `{F11}` |
| 工作管理員／活動監視器 | `^+{ESC}` | 使用「開啟程式」：`com.apple.ActivityMonitor` |
| 鎖定螢幕 | `#l` | `^#q` |

## 為什麼不能傳送 Ctrl+Alt+Del

Ctrl+Alt+Del 是 Windows 的安全注意序列（Secure Attention Sequence）。Windows 會忽略用於該序列的一般模擬輸入，所以 `^%{DEL}` 無法開啟安全介面。可用 `^+{ESC}` 開啟工作管理員，`#l` 鎖定螢幕；需要登出時，用「執行命令」執行 `shutdown /l`，它會結束目前的工作階段。

## 限制與平台說明

共享解析器沒有整體字串長度或重複次數上限。重複次數和延遲以32 位元無號整數儲存，滾輪位移以32 位元有號整數儲存；超範圍轉換可能回繞，請使用實際需要的較少的次數和較短的延遲。未知鍵名或缺少必要參數會回報解析錯誤，編輯器會在輸入時驗證。

Windows 在執行緒中傳送序列，`{SLEEP ms}` 會等待。Mac 使用計時器分批傳送：動作字串超過 16,384 位元組會拒絕；Lua 已解析序列限制為 16,384 個動作，單一文字動作最多 16,384 位元組。等待佇列最多容納 64 項，超出會丟棄並記日誌。

Mac 支援 F1–F20、小鍵盤數字和已有對應的導覽鍵；Insert／INS、PRTSC、BREAK、F21–F24、媒體／音量及滑鼠／滾輪記號尚不支援，會跳過。媒體和音量請使用「媒體與系統」。`ms.keys_down` 和 `ms.keys_up` 僅 Windows 支援，詳見 [Lua API](lua-api.md)。
