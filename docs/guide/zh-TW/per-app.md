# 按程式設定

## 新增程式

側欄點「新增程式…」，選擇「為它單獨設定手勢」或「在它裡面停用手勢」，然後可以：

- 在「正在執行」清單中選擇程式。
- 點選「點選視窗」，再點程式視窗；Esc 或右鍵取消。
- 點「瀏覽…」選擇程式檔案。
- 將程式或其捷徑拖進設定視窗。Mac 接受 `.app` 和可執行檔，能取得 bundle id 時用它作為作用域身分。

Windows 規則支援按可執行檔名或完整路徑符合，忽略大小寫。Mac 程式身分通常類似 `com.apple.Safari`。建議用選擇器取得，避免猜錯。新增後，側欄會出現該程式，可分別設定滑鼠手勢和觸發角。

## 專用手勢與通用手勢

「所有程式」儲存通用手勢。程式專用的對應手勢優先。開啟「也使用通用手勢」時，程式沒有符合的專用綁定，會接著嘗試通用綁定；關閉後，只使用該程式自己的手勢。

例如，新增瀏覽器，在其中新增按住右鍵畫 `↓→` 的手勢，改成另一個動作。其他程式仍使用通用的 `↓→` 動作。想在同一作用域內重複使用現有設定，可用[複製一份](gestures.md#尋找複製和停用)後編輯。想讓同一個畫法只錄一次、在不同程式裡做不同的事，用[手勢庫](gesture-library.md)。

編輯手勢時會顯示它儲存在哪個作用域。在清單中的手勢上按一下右鍵，選擇「複製到／移動到…」，勾選目標程式後點「複製」或「移動」。可一次選擇多個已新增的程式，也可從視窗中新增程式。複製會建立各自獨立的手勢設定；移動會從原作用域移除。目標作用域若現有相同畫法，可逐一選擇跳過或取代。整次操作可透過提示列復原。複製到已停用手勢的程式後，設定會保留，但須重新啟用該程式的手勢才會生效。

## 在程式中停用

側欄選取程式，關閉「使用手勢」。這會停用該程式專用手勢、通用手勢和螢幕邊角，右鍵、中鍵、側鍵原樣交給程式。現有綁定仍保留，重新開啟「使用手勢」即可恢復。程式頁右上角的刪除按鈕「移除此程式」會刪除該程式的專用作用域。

遠端桌面、虛擬機器、3D 建模、設計軟體和遊戲編輯器經常需要右鍵／中鍵拖曳，適合排除。選擇器中的「建議停用」提供這些類別的已知程式，也可批次新增偵測到的已安裝程式。

## 全螢幕與首次引導

預設情況下，全螢幕時自動暫停：前景程式被偵測為全螢幕時，引擎不啟動手勢或邊角動作，適用於全螢幕遊戲、影片和簡報。它與手動暫停狀態相互獨立。Windows 檢查無標題列且覆蓋顯示器的視窗，並排除桌面／Shell 視窗；Mac 檢查前景程式視窗是否覆蓋螢幕。因此看起來全螢幕的程式，在兩個平台的表現可能不同。

在「偏好設定」中可關閉「全螢幕時暫停手勢」。每個程式的「全螢幕時」可選擇「跟隨全域（暫停）」或「跟隨全域（保持啟用）」「保持啟用」或「暫停手勢」，程式的個別設定優先。若只想讓 Chrome 全螢幕時繼續使用通用手勢，新增 Chrome，保留「也使用通用手勢」，選擇「保持啟用」即可，無需新增專用手勢。手動暫停和程式停用仍然有效。

視窗模式遊戲或遠端桌面建議新增明確的排除規則。需要所有程式暫停時，使用[系統匣／選單列命令或暫停快速鍵](getting-started.md#暫停)。

首次引導會列出偵測到、通常需要自己處理滑鼠拖曳的程式。完成引導時停用勾選項，請先檢查。Mac 內建設定也為建議排除的程式預先設好停用的作用域，其中沒有專用綁定。以後都可從側欄修改。
