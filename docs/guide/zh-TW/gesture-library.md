# 手勢庫

手勢庫把「怎麼畫」和「做什麼」分開：一個手勢只定義一次，可以在多個程式裡各自執行不同的動作。重錄共享手勢時，用到它的地方一起更新；形狀手勢也只保留一份樣本。

## 瀏覽手勢庫

側欄點「手勢」。清單分「滑鼠手勢」和「觸發角」，可以按觸發按鈕篩選，用「未使用」找出沒有被使用的手勢，也可以搜尋名稱、畫法或用途。每張卡片下方顯示它用在幾處。

點卡片開啟詳細資料：上半部分可以重畫；「用在」列出每個使用它的程式、手勢名和動作，點選後可跳到該項。新安裝的內建手勢已經在手勢庫中。從舊版本升級時，現有手勢仍分散在各程式裡，先按下一節整理。

## 整理並匯入

手勢庫為空時點「整理並匯入手勢…」，之後可以隨時點右上角的「整理並匯入…」。先選擇範圍：

- 「只整理通用手勢（推薦）」：收入「所有程式」裡的手勢，其他程式裡相同或相似的一併關聯；各程式單獨設定的手勢保持專用。
- 「整理全部手勢」：通用手勢和各程式單獨設定的手勢全部收入。

點「下一步」檢視結果。確認之前不會修改設定：

- 完全相同的畫法自動合併；方向相同、只差各段長短的軌跡預設合併。
- 「相似的形狀，請確認」：逐組在要保留的那一份上點「以此為準」，或點「合併樣本」。相似度低於建議值時，預設不合併；合併後識別結果可能與原來略有不同。
- 「直接收入手勢庫」：展開後可以取消勾選，不匯入的手勢仍是各程式專用。

點「匯入」完成，提示列上可以復原。同一個程式裡兩個相似、但用途不同的手勢不會被合併。

## 在其他程式中使用

在手勢詳細資料點「在其他程式中使用…」，選擇程式，再選擇動作。已經使用這個手勢的程式不能再選；程式裡現有同樣畫法時會提示衝突；已停用手勢的程式可以分配，但不會生效。清單末尾的「新增程式…」可以先新增程式。分配後停留在手勢詳細資料，新的一行會醒目標示，點提示列上的「去設定」可以直接開啟這項設定。

也可以從程式這邊出發。編輯器裡，只屬於目前程式的手勢顯示「本程式專用」：

- 點「從手勢庫選擇」改用手勢庫裡的手勢。選擇器可以搜尋；「其他程式裡的手勢」選取後會先加入手勢庫，再與原來的那一項共享；「錄製新手勢（本程式專用）」不會進入手勢庫。
- 「更多操作」選單裡有「加入手勢庫」和「在其他程式中使用…」。

## 修改共享手勢

編輯器裡，來自手勢庫的手勢顯示「手勢庫」和使用位置。重畫後修改會同步到所有使用它的地方，並列出新產生的衝突：

- 「只改這裡」：修改只留給目前程式，它改為本程式專用；手勢庫和其他程式保持原樣。
- 「改好了」：保留同步，收起提示。

「更換」可以換成手勢庫裡的另一個手勢；↗ 按鈕（「在手勢庫中檢視」）跳到手勢詳細資料。

## 新增與刪除

「新增手勢」直接在手勢庫中錄製，畫完才會加入，名稱可以不填，之後再用「在其他程式中使用…」分配。

「刪除手勢」時，如果還有地方在用，可以選擇：

- 「刪除，各處保留一份（改為本程式專用）」
- 「連同用到它的手勢一起刪除」

兩種操作都可以在提示列上復原。

## 設定與相容

手勢庫儲存在設定檔的 `gestures` 中，引用它的手勢同時儲存一份完整畫法。因此舊版本 Mousetroke 仍能讀取新設定，手勢照常工作；但在舊版本裡儲存設定會丟掉手勢庫，各處手勢變回本程式專用，升級後再整理一次即可。手動修改設定檔導致某處畫法與手勢庫不一致時，那一處會改為本程式專用，並提示一次。檔案位置和備份見[設定、備份與更新](config.md)。
