# 螢幕邊角

## 試用預設動作

「所有程式 → 觸發角」中的每個邊角綁定都可以修改。

| 觸發方式 | Windows 預設動作 | Mac 預設動作 |
|---|---|---|
| 推到左下角 | 開始選單 | Spotlight |
| 推到右下角 | 顯示桌面 | 顯示桌面（F11） |
| 推到左上角 | 切換程式（Alt+Tab） | 指揮中心（Control+↑） |
| 推到右上角 | 工作檢視（Win+Tab） | 綁定初始停用 |
| 貼著上邊滾輪 | 音量增減 | 音量增減 |
| 在上邊緣按一下中鍵 | 靜音 | 靜音 |
| 在上邊緣按一下右鍵 | 播放／暫停 | 播放／暫停 |
| 貼著下邊滾輪 | 亮度增減 | 亮度綁定初始停用 |
| 貼右邊上下摩擦兩次 | 已綁定工作管理員，需先開啟「識別出來就立即執行」 | 活動監視器 |

角落動作無需按鍵，直接把滑鼠推到角落。邊緣滾輪和點擊需要滑鼠貼著相應邊緣。摩擦是沿著邊緣依錄製方向來回移動，不是滾動滾輪。

## 設定邊角觸發

1. 在「所有程式」或指定程式中，選擇「觸發角 → 新增觸發角」。
2. 「怎麼開始」選「螢幕邊角」，在示意圖中選一條邊或一個角。
3. 角落動作可將「然後」留空；也可用「+ 新增一步」加入向上／向下滾輪、滑鼠點擊或沿邊緣的軌跡。
4. 選擇[動作](actions.md)。調音量可選「媒體與系統 → 音量 +」或「音量 −」。連續滾輪和不按按鈕的摩擦應開啟「識別出來就立即執行」。

摩擦動作新增「畫軌跡」，錄下交替方向。例如貼右邊畫 `↑↓↑↓`。建議先用 Lua 提示文字試用，再綁定影響較大的動作。

## 多顯示器

每台顯示器的外側邊緣和角都可以觸發，也就是滑鼠推過去會停住的地方。兩台顯示器的交界處不算邊緣，避免滑鼠移到另一個螢幕時誤觸。緊鄰另一個螢幕的角也不算角，例如右側接著另一個螢幕的右上角，只按上邊處理。

## 亮度與平台差異

Windows 的「亮度 +」／「亮度 −」首先選擇滑鼠所在螢幕，每次調整 10 個百分點並顯示結果。先嘗試 DDC/CI，再改用 WMI。外接顯示器需要支援並開啟 DDC/CI；改用 WMI 時會取用第一個 WMI 亮度裝置，通常為內建螢幕，並未依滑鼠所在位置選擇顯示器。兩條路徑均失敗才會出現不支援提示。小步調整見 [Lua 範例](lua-examples.md#調整滑鼠所在螢幕亮度)。

Mac 的「媒體與系統 → 亮度 +」／「亮度 −」傳送系統亮度鍵事件，適用於內建螢幕，不會根據滑鼠位置選擇螢幕，也不支援外接顯示器 DDC/CI。預設下邊緣亮度綁定處於停用狀態。Mac 的 Lua 亮度 API 同樣尚未實作。

Mac 系統觸發角與 Mousetroke 角落重疊時，設定會提醒。修改其中一方的綁定，避免同時觸發。F11、Control+↑ 等系統快速鍵是否生效，也取決於 macOS 快速鍵設定。

程式排除規則同樣會讓邊角動作暫停；預設情況下，全螢幕偵測也會。只在某個程式中失效時，見[按程式設定](per-app.md)。
