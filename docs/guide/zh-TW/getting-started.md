# 安裝與首次使用

## 安裝並開啟

Windows 使用者從[最新版本](https://github.com/eiaao/mousetroke/releases/latest)下載 `mousetroke.exe`。這是免安裝版程式：放到準備長期保留的位置，按兩下即可執行。可將下載檔案的 SHA-256 與該版本的 `SHA256SUMS.txt` 對照。

支援 Windows 10 1809 及以上、Windows 11，均為 64 位。設定視窗需要 Microsoft Edge WebView2，Windows 11 已內建。程式暫未做程式碼簽署；首次啟動若被 SmartScreen 攔截，確認來自官方發布頁後，選擇「其他資訊 → 仍要執行」。

Mac 使用者下載 `Mousetroke.dmg`，開啟後將 **Mousetroke** 拖到「應用程式」。通用版應用程式支援 macOS 11 及以上的 Apple 晶片和 Intel 機型。如果直接從 DMG 開啟，會提供**移到「應用程式」**並重新開啟已安裝副本。

Mac 測試版採用自行簽署，尚未公證。首次開啟被攔截時，到「系統設定 → 隱私權與安全性 → 仍要打開」；較舊系統可用「右鍵 → 打開」。引導中點「授權…」，在「輔助功能」中開啟 Mousetroke，等待「準備就緒，可以使用手勢了」。不需要螢幕錄製權限。如果系統仍無法監聽，引導會視需要顯示「輸入監控」，出現提示時再開啟。

## 開啟設定並完成引導

Windows 通知區域圖示：左鍵開啟設定；右鍵選單包含「設定…」、「暫停手勢」／「恢復手勢」、「開機自啟動」、「開啟設定資料夾」和「結束」。發現更新時還可能顯示新版本入口。

Mac 使用選單列圖示開啟「設定…」、暫停／恢復或「結束」。權限和更新入口會按目前狀態顯示。「關於 Mousetroke」開啟關於頁面。

首次引導介紹畫手勢、螢幕邊角、排除程式和暫停。完成前檢查勾選的程式：這些程式中會停用手勢。以後可以透過「關於 → 檢視使用引導」重看。設定修改會自動儲存；尚未錄完的筆畫需要完成錄製後才能儲存。

## 畫出第一個手勢

1. 在瀏覽器中開啟一個可以返回上一頁的網頁。
2. 按住右鍵，向左畫 `←`，鬆開右鍵，瀏覽器會返回上一頁。
3. 在臨時分頁試試 `↓→` 關閉分頁，或畫 `↙` 最小化視窗。

內建動作遵循平台習慣，例如瀏覽器快速鍵在 Windows 使用 Ctrl，在 Mac 視需要使用 Command。完整清單在「所有程式 → 滑鼠手勢」，每一項都可編輯。部分內建手勢處於停用狀態，尤其是 Mac 尚不支援的動作。

直接按一下右鍵，仍會彈出程式選單。按住不動達到一定時間，也會讓一般點擊或拖曳照常運作；時間可在[偏好設定](gestures.md#識別與外觀)中調整。

## 新增手勢

開啟「所有程式 → 滑鼠手勢 → 新增手勢」，選擇觸發按鈕並錄製圖形。點選「選擇動作」，搜尋或瀏覽[動作庫](action-library.md)，選擇預置動作並填寫參數。手勢完整有效後自動儲存，到設定視窗以外試用即可。錄製方法詳見[滑鼠手勢](gestures.md)。

## 暫停

Windows 系統匣選擇「暫停手勢」，之後選「恢復手勢」。Mac 的選單項目始終叫「暫停手勢」，勾選表示手動暫停，再點一次恢復。預設暫停／恢復快速鍵：Windows 為 **Win+Esc**，Mac 為 **Control+Option+Command+P**。可在「偏好設定 → 暫停 / 恢復快速鍵」修改。

預設情況下，前景視窗被識別為全螢幕時，全螢幕遊戲、影片和簡報會自動暫停手勢。排除程式見[按程式設定](per-app.md)；手勢始終不觸發時見[常見問題](troubleshooting.md)。
