# macOS M5a Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付 macOS 11+ 通用、自签名 DMG，以及共享更新检查和十语言下载说明。

**Architecture:** core 承载发布解析、版本、URL 规则与每日状态；平台层保留网络和文件系统实现。Windows 安装事务不改，Mac 只检查并打开浏览器下载。双平台构建成功后统一发布两个资产与一份校验和。

**Tech Stack:** Rust、系统 curl、Bash、codesign/hdiutil、GitHub Actions、React、Python 静态站点生成。

**Spec:** `docs/MAC-PLAN.md` M5a 和本次任务要求。

## Global Constraints

- 仅 feat/mac-m5a worktree，一次本地提交；不推送、不打标签、不发布。
- 不改版本与 CHANGELOG，不加第三方 crate；macOS 最低 11.0。
- 本机每次 cargo 设置指定 CARGO_TARGET_DIR 与 CARGO_BUILD_JOBS=4。
- 注释中文，新增用户文案覆盖十种语言；Windows 安装和 CLI 行为保持。
- 密钥与密码不进仓库、不打印；真实签名/权限验证交由 Mac 审查。

## Review Focus

- 混合 DMG/exe 资产及校验和仍精确选择 exe，重复或错误校验和继续失败。
- 非 HTTPS、伪装主机、重定向、超大/超时响应不能绕过 Mac 请求限制。
- 自动检查关闭、重启、时钟回退不产生额外请求；通知按版本持久化。
- translocation 与 /Volumes 路径提示，正常 /Applications 路径不误判。
- 发布缺证书必失败，签名 requirement 在二次构建中保持标识符与证书根。
