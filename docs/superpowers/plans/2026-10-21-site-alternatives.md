# 鼠标手势工具对比页实施计划

**Goal:** 交付中文和英文的选择指南及六组对比页，静态部署，保留主站 canonical。

**Architecture:** 双语内容数据、单一模板和独立 Python 生成器；复用首页品牌、下载组合按钮及公共样式和交互。检查器同时验证生成结果、链接、结构化数据和站点地图。

**Tech Stack:** Python 标准库、HTML/CSS、现有 site.js、Puppeteer 与 Edge。

**Spec:** 本次任务中的页面矩阵、内容要求、事实核验与单次本地提交约束。

## 全局约束

- 仅修改当前工作树；一个本地提交，不推送。
- 竞品只采用本次读到的官方事实；未知项明确标注，来源和核查日期可见。
- 新页面只提供 zh-CN/en，目录链接带尾斜杠，x-default 指向英文。
- 不使用竞品图片，不收录热度指标或竞品资源占用。

## 验收重点

- Mac/Windows 默认下载及备用平台菜单都能点击。
- 深层目录与镜像子路径中的资源和语言切换可用。
- 手机宽度和两种配色无溢出或重叠。
- FAQ 正文与 JSON-LD 完全一致；生成结果可重复。
- 未验证事实、过期版本与禁用名称不能混入成品。

- [x] 新建 site/alternatives_data.py、site/alternatives_template.html、site/gen_alternatives.py，生成十四页及站点地图条目。
- [x] 增补公共样式、十种首页页脚翻译、llms.txt、部署清理及 site/README.md；保留入口重定向逻辑。

执行方式：由当前会话直接完成；用户已授权实现与验证，不另设计划审批。
